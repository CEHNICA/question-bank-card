# 教辅结构提取：由外部助手归纳，再交可核对候选

适用于教材／讲义只提取题目、按章节版式重提取，或题卡混入思路、解析、章节介绍的任务。普通试卷核对仍走逐题工作流。

## 取得指定资料的只读快照

核实 `tiyouju status --json` 和 `papers --json`，用完整资料 UUID 定位，避免重复书名或 `latest` 指错资料。动手修改前用 `whereami` 绕开用户正在编辑的题目。授权范围明确后继续执行；未明确的资料、云调用或正式替换不从说明文件推定。

有 Python 3 的执行环境可运行附带脚本，路径换成实际绝对路径：

```powershell
python "<本技能目录>\scripts\book_structure_snapshot.py" --paper <完整资料UUID> --out "<新的绝对输出目录>" --pages 3-8,40-43
```

`--pages` 为 PDF 的 **1 基页码**，仅控制导出的原页；省略则导出该资料全部原页。详情包含该资料全部题卡。`--url` 可指定本机题有据地址，默认取 `TIYOUJU_URL`，否则用 `http://127.0.0.1:8768`。脚本只发送 GET，不读配置或密钥，不提交识读、审批或入库；原页预览接口可能补写软件自己的派生页图缓存。

若用户授权读取指定资料的本机缓存，可加 `--data-dir "<该资料UUID命名的绝对目录>"`。脚本只在此目录读取已有页图、`source.pdf` 和已知解析 ZIP；不扫描其他资料、不连接数据库。输出 ZIP 内的内容块使用 **解析包局部页码和局部序号**。公开接口没有内容块和分片页映射导出能力，脚本不会猜全书页码、拼全局序号或直接据此改范围。调整过页序、分片范围或原稿时，先核定映射和来源指纹。

快照输出 `paper-detail.json`、`pages/`、`manifest.json`，可选 `cached-blocks/`。记录页码、资料与布局版本、来源和 SHA-256；输出目录须为空，失败的半成品保留并在清单中标为未完成。脚本不是备份或替换工具。

## 归纳循环与语义状态

观察若干完整小节，提出结构假设，并用未参与最初归纳的其他小节验证。两层结构分别考虑：

- 外层：章节标题、讲解栏目、例题栏目、练习栏目，以及书末答案或附录的整体分界。
- 内层：题目起点、题干／小问／选项／题图、思路或解答、反思和延伸讲解；允许变式、拓展、多个解法和缺省部分。

用标题、文字、位置和上下文共同决定状态。不要假定每节页数、题数或段落数固定；不要仅因出现“例1”或“思路”就新建、截断题目。题号可用于核对顺序，来源位置和章节才用于区分重复编号。OCR 可能漏题号、把多题合成一块、把标题标成 `header`，或让同页序号偏离实际阅读顺序。

题干遇到明确解析起点、下一题或下一节结束；页尾本身不结束题干。练习提供的证明、材料或参考解法可能是已知条件，应保留。题干与思路同块时，文字分界与原图几何分界分别核定，不能按 LaTeX 字符比例声称裁图已准确。

## 组合范围与配图

题目可由跨页、跨栏及同页多个区域组成，保留小问、公式、表格和选项。图片顶边可能略高于所属题号，不能只按块先后归给上一题；结合题干引用、纵向覆盖、中心位置和相邻题竞争判断。题图与解答图分别处理，图文交错时允许独立图框，避免整栏矩形带入别题的图。

对照原页检查裁片上下缘、分式上下标、左侧“则／故”等连接字和图底；OCR 块矩形不保证包住所有印刷内容。几何修正作为本书的可追溯例外单列，复用前重新核对。

## 交付候选与核查

每道候选至少给出稳定候选 ID、章节／类型、原题号、来源页与区域、块来源或锚点、图归属、OCR 候选文字、结束依据、现有题卡匹配和待核对问题。保留原文，另列改字建议；候选正文、已核对的人工文字和已发布版本分开记录。

检查漏题、重号／重复 ID、答案区误建、讲解串入、异常长题、块内多题、跨页小问与图表完整性。用完整小节与复杂页面逐图验证，数量对上或未命中关键词不能代替准确率。报告实际看图范围、已修例外与未完成核查。

## 获授权后的替换与回滚

用户已明确授权的指定资料替换可继续准备并执行已验证的本机操作；先固定当前来源、布局版本、题卡指纹与可恢复备份，建立旧卡到候选的保留／改范围／新增／移除对应清单。人工题面、审核、标签、答案及历史版本按对应关系保留，不能用新 OCR 原文覆盖已核对内容。

当前能力边界：CLI/MCP 的 `propose` 只交题面改动提案，不支持 `regions`；单题布局接口并非整书原子替换，范围变化会影响审核有效性；普通备份导入是合并，不是精确撤销。不要虚构 `replace` 命令，也不要用循环单题调用承诺整书原子性或完整回滚。若实际替换工具缺少所需能力，交付已准备好的候选与差异，准确说明缺口；不绕过版本校验或直接写生产数据库。

执行后核对实际题数、来源范围、既有人工内容和审核／发布状态，保留操作收据及已验证的恢复方式。区分“候选已生成、范围已应用、文字已核对、已入库”四种结果。
