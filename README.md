# 把手里的试卷，变成自己的题库

**题有据：每一道题，都能回到原卷。**

导入 PDF、Word 或拍照试卷，逐题对照、改好、入库。下次出题时，直接搜索、选题、打印。

- **出处找得到**：每道题保留原卷截图和页上位置，点“查看出处”就能回去。
- **核对很直接**：左边原卷，右边题面。哪里有疑点就标哪里，确认后才入库。
- **公式和配图一起整理**：公式实时预览，配图从原卷框选，表格也能编辑。
- **整理完就能用**：按关键词、题型和来源找题，放进试题篮，组一份新卷子。

**[下载 Windows 安装版](https://github.com/CEHNICA/question-bank-card/releases/latest)** · **[不用密钥，先学一遍](#try-demo)** · [安装与使用指南](docs/使用指南.md)

**也可以让 AI 带你上手**：把 [https://github.com/CEHNICA/question-bank-card](https://github.com/CEHNICA/question-bank-card) 直接发给能操作电脑的 AI 助手。仓库的 [AI 助手入口](AGENTS.md) 会引导它安装、核实结果，再让你选择配套技能和桌面图标；以后可以直接把题目发给它处理。

功能介绍对应 **main 源码 1.10.14**；下载页提供已发布安装包，版本可能不同。

适用于 Windows 10/11，以数学试题为主。题库和原卷保存在自己电脑上；处理新试卷需要配置识读服务。

## 先看清楚，再收进题库

识读是初稿，核对后再入库。题有据把“看原卷、改错字、补配图、确认”放在一张题卡里，减少来回切换。

发现公式不对，点“改字”就能边改边看排版；预览会标出正在修改的位置。某一块看不清，可以框出来单独识读，先看替换前后，再决定是否填入。

![放大对照：原卷与题面并排显示](docs/assets/screenshots/compare-view.webp)

原卷大图支持 **Ctrl + 滚轮缩放、按住左键拖动**。调整范围或配图时，普通左键用来画框，空格 + 左键或中键用来移动画布。

## 题目有出处，修改有历史

“这道题从哪来”和“这道题改过什么”是两件事，题有据都保留。

- **查看出处**：定位到原卷中的本题或整页，橙色框是文字范围，绿色框是采用的配图。
- **版本历史**：看每次入库的题面、核对人和时间，也能把两版并排比较，查看题干、选项、答案、解析与配图的变化。
- **同题不同资料**：可以查看其他资料中的相同题面，以及仅有公式排版差异的待核对候选。每份资料保留自己的出处和历史，不自动合并。

## 挑几道题，出一份练习

在正式题库按关键词、题型、资料来源、有没有答案筛选，选中的题放进试题篮。组卷时可以决定是否打印题源，有答案和解析时放在卷末。

## 不用密钥，先学一遍

安装后，点 **“先用示例试卷学一遍（不用密钥）”**。内置试卷已经读好，跟着提示练习放大对照、改错字、补配图和入库，不调用识读服务。示例只用来练习，不会进入正式题库。

新版教学把基础练习和新功能回顾分开。已经会用的用户，可直接从 **“设置 → 帮助 → 只看新版功能”** 了解原卷手势、改字预览定位、框选识读推荐、出处与历史、未保存提醒。

框选识读教学可以练习画框、认识自动推荐入口；真实识读仍需配置可用服务，示例不会生成假的 AI 结果。

供自行导入的 [原创三页演示卷](docs/demo/tiyouju-demo-paper.pdf) 也在仓库中；[演示资料说明](docs/demo/README.md) 介绍了生成方法和字体许可证。

## 开始整理自己的试卷

1. 从 [Releases](https://github.com/CEHNICA/question-bank-card/releases/latest) 下载 `TiYouJu-Setup-*.exe`，安装并打开题有据。
2. 在“设置 → 常用 → 填写或更换密钥”中配置自己的识读服务。处理新资料需要 MinerU；看图读题可选魔搭、MiniMax、硅基流动，或让自己的 AI 助手核对。
3. 拖入资料，等题卡生成，逐题对照原卷。确认的题入库后，就能搜索、选题和组卷。

题有据开源免费。第三方识读服务的额度、可用性和费用由服务商决定；选择免费额度时也请查看账户中的当前规则。MinerU 暂不可用时，可以继续教学、核对已有题卡、查出处和使用正式题库。

## 识读和数据怎么处理

AI 用来提速，最终确认仍由你决定。绿卡表示识读一致，并不代表绝对正确；黄卡把疑点列出来，人工通过和 AI 通过分别记录。AI 助手不能改动你已通过的题。

软件服务只监听本机，题库、原卷和版本历史存在本地。**处理新资料会把原卷发送给 MinerU，把题目截图发送给你选用的看图服务**；“忽略手写”不会在发送前擦除个人信息。密钥在本机加密保存。

具体发送内容、AI 自动推荐和数据目录见 [API 与隐私边界](docs/使用指南.md#api-与隐私边界)。
