# 题有据：一个给豆包用的题库

**配合豆包整理数学题，每一道都能回到原卷。**

豆包帮你分析、核对题目，题有据把题面、公式、配图和原卷出处收进自己的题库。导入 PDF、Word 或拍照试卷，逐题对照、改好、确认后入库；下次出题时，直接搜索、选题、打印。

- **出处找得到**：每道题保留原卷截图和页上位置，点“查看出处”就能回去。
- **核对很直接**：左边原卷，右边题面。哪里有疑点就标哪里，确认后才入库。
- **公式和配图一起整理**：公式实时预览，配图从原卷框选，表格也能编辑。
- **整理完就能用**：按关键词、题型和来源找题，放进试题篮，按页预览后直接导出 PDF 或 Word。

**[下载 Windows 安装版](https://github.com/CEHNICA/question-bank-card/releases/latest)** · **[不用密钥，先学一遍](#try-demo)** · [安装与使用指南](docs/使用指南.md)

**先把这个地址发给豆包**：[https://github.com/CEHNICA/question-bank-card](https://github.com/CEHNICA/question-bank-card)。让它了解题有据，按说明带你安装和上手，以后再帮你核对题目。[看看怎么和豆包一起用](docs/使用指南.md#先用豆包帮你核对)

要补知识点或参考答案时，就让当前豆包自己做，再交回题库。**这条流程不需要豆包 API。** 两项默认关闭，明确需要时再启用；能操作本机的助手通过附带工具写回，只有聊天能力时由你导入结果。[给助手的操作说明](AGENTS.md)

当前正式版 **1.11.11**，可从 [Releases](https://github.com/CEHNICA/question-bank-card/releases/tag/v1.11.11) 下载。先在本机切题，完成后自动识读、核对；没有识读服务也能保留原图入库和导出。

适用于 Windows 10/11，以数学试题为主。题库和原卷保存在自己电脑上；没有识读密钥也能导入 PDF、照片，手工框题并作为原图题入库和组卷。文字版 PDF 可在本机提取题号与位置；需要识读文字时再配置服务或交给当前助手。

## 先看清楚，再收进题库

识读是初稿，核对后再入库。题有据把“看原卷、改错字、补配图、确认”放在一张题卡里，减少来回切换。

发现公式不对，点“改字”就能边改边看排版；预览会标出正在修改的位置。某一块看不清，可以框出来单独识读，先看替换前后，再决定是否填入。

![放大对照：原卷与题面并排显示](docs/assets/screenshots/compare-view.webp)

原卷大图支持 **Ctrl + 滚轮缩放、按住左键拖动**。配图、手工切题和范围调整都支持点一个角、移动鼠标、再点另一个角固定范围；双击下一张图的左上角，可复制附近配图框的尺寸，四张选项图不用逐个重画。空格 + 左键或中键移动画布。1.11.14 起，手工切题用 **S 保存下一题、Ctrl+S 完成**，答案编辑与预览左右显示，答题密钥可点眼睛临时查看，桌面导出目录可在设置中指定。[改进说明](docs/release-notes-v1.11.14.md)

1.11.15 起，“专注浏览”可收起筛选和试题篮；“全屏看题”可以用上一题、下一题或左右方向键连续查看当前范围的题目。[连续看题说明](docs/release-notes-v1.11.15.md)

## 题目有出处，修改有历史

“这道题从哪来”和“这道题改过什么”是两件事，题有据都保留。

- **查看出处**：定位到原卷中的本题或整页，橙色框是文字范围，绿色框是采用的配图。
- **版本历史**：看每次入库的题面、核对人和时间，也能把两版并排比较，查看题干、选项、答案、解析与配图的变化。
- **同题不同资料**：可以查看其他资料中的相同题面，以及仅有公式排版差异的待核对候选。每份资料保留自己的出处和历史，不自动合并。

## 不用密钥，先学一遍

安装后，点 **“先用示例试卷学一遍（不用密钥）”**。内置试卷已经读好，跟着提示练习放大对照、改错字、补配图和入库，不调用识读服务。示例只用来练习，不会进入正式题库。

新版教学把基础练习和新功能回顾分开。已经会用的用户，可直接从 **“设置 → 帮助 → 只看新版功能”** 了解原卷手势、改字预览定位、框选识读推荐、题库与试题篮、组卷草稿、标签与答案设置及未保存提醒。

框选识读教学可以练习画框、认识自动推荐入口；真实识读仍需配置可用服务，示例不会生成假的 AI 结果。

供自行导入的 [原创三页演示卷](docs/demo/tiyouju-demo-paper.pdf) 也在仓库中；[演示资料说明](docs/demo/README.md) 介绍了生成方法和字体许可证。

## 开始整理自己的试卷

1. 从 [Releases](https://github.com/CEHNICA/question-bank-card/releases/latest) 下载 `TiYouJu-Setup-*.exe`，安装并打开题有据。
2. 导入资料，程序先尝试在本机切题；不能可靠切出的题保留原页，由你手工补齐，无需先选技术路线。教材与讲义先保留原页，避免章节重复题号被误合并。需要云解析时，再明确允许使用已配置的服务。
3. 手工框出完整题目，跨页题可添加多个片段并排序。桌面新版完成切题后自动识读，题目旁直接显示文字，随后核对、配图和入库；读错可单题重新识读。没有可用读题服务时仍保留原图，也能以原图题入库、选题和组卷。

题有据开源免费。第三方识读服务的额度、可用性和费用由服务商决定；选择免费额度时也请查看账户中的当前规则。MinerU 等待过久时，在“试卷操作”点“停止 MinerU，改为手工切题”，直接打开原卷，已有题目保留。手工导入、切题、原图题审核入库和组卷导出仍可使用。原图题按出处、题号和人工标签查找；转换成可编辑文字后才支持题干全文检索和选项重排。

## 其他智能体也可以

题有据也可以配合其他智能体使用，核对后的题目照样保存出处和修改历史。能操作电脑的智能体可从 [AI 助手入口](AGENTS.md) 完成安装、核验并调用题库；配套技能与桌面图标在收尾时按你的选择设置。只支持对话的客户端，可以指导安装、协助看图核对，由你把确认后的结果放回题卡。[完整接入说明](docs/使用指南.md#自动安装与其他智能体)

## 识读和数据怎么处理

AI 用来提速，最终确认仍由你决定。绿卡表示识读完成且没有待处理提醒；黄卡把疑点列出来，人工通过和 AI 通过分别记录。二次 AI 识读对比可以关闭，有问题可单题重读。AI 助手不能改动你已通过的题。

当前助手生成的标签和参考答案单独保存，记录助手来源，参考答案标为“未核对”，保留原卷答案与审核记录。独立模型 API 是可选途径，可推荐 DeepSeek，也支持用户选择其他模型；按实际接口、模型名和费用配置。是否能调用本机工具或 MCP 取决于当前客户端，不能仅凭安装了豆包就认定已接通。

所有设置集中在“设置”页，分为读题服务、标签与答案、题面与显示、帮助、关于。标签与答案的开关、生成时机和“由谁生成”直接在该页设置；选择独立 API 后才展开配置。支持新题入库后、日后单题或勾选批量处理，新题自动处理默认关闭。助手模式先保留待办，由当前助手逐题完成，生成结果不会冒充原卷答案。

软件服务只监听本机，题库、原卷和版本历史存在本地。**手工切题和本地文字 PDF 不上传原卷；选择 MinerU 云解析时才把原卷发送给 MinerU，调用看图识读时才把题目截图发送给所选服务。**“忽略手写”不会在发送前擦除个人信息。密钥在本机加密保存。

具体发送内容、AI 自动推荐和数据目录见 [API 与隐私边界](docs/使用指南.md#api-与隐私边界)。

MinerU 当前 API 管理页规定单文件最多 200 页；每天 1000 页是最高优先级额度，超出后降低优先级。Token 按本人管理页的到期日更换；服务恢复与账户状态需实际核实。[当前限制、旧文档差异与故障排查](docs/MINERU_API.md)
