    📖题有据题库工作台使用指南
    ① 录题分屏工作台与断点续读

    从左上角「📄 录入题目」进入录题页后，宽屏左侧常驻高清原卷画布：点击题卡联动定位左框，单击左框聚焦题卡，双击直接调框；拍照上传支持前移/后移调序与 90° 旋转。切题只保存范围不自动扣费，可主动点击「识读未完成题目」批量转文字或直接原图审核；中途退出软件重开后，未开始的排队题会自动续读。

    ② 智能文件夹、右键悬停飞出与标签地图

    左侧栏支持按教材/试卷归属与智能视图（OneNote 有笔记、未分类、待补考点标签、AI 生成未人工核对、最近浏览）快速筛题。在题卡上右键可直接悬停展开子标签菜单贴标、修改题型、校订题目或安全撤回至回收站；「🔖 标签管理中心」支持列表与树状地图双向整理。

    ③ 统一答案解析编辑器 & OneNote 双向联动

    在题卡、快速审题弹窗或录题页已入库题卡右上角点「编答案/解析」，均进入同一套答案解析编辑器（支持公式与步骤实时预览、AI 初稿参考）；有 OneNote 笔记的题目支持一键创建做题页、呼出定位及深链回跳题库。

    ④ 全屏看题、界面缩放与保真组卷导出

    选中题目按 Space 全屏审题（← / → 切题），Ctrl + Shift + C 一键复制高清排版题图，Ctrl + 滚轮 或 Ctrl + = / - / 0 调节工作台缩放；加入试题篮后可预览并导出排版一致的 Word / PDF。
