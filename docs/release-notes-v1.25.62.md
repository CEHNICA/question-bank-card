# 题有据 1.25.62：贴标签的流水线；目录长在题库里

这一版做的是同一件事的两头：**把标签贴上去**（流水线），**再按标签找回来**（目录）。中间这一版还修掉了窗口按钮的白屏问题。

## 一、逐题贴标签：一次一道题

题库 807 道题，只有 3 道贴了知识点；300 个标签里有题的只有 7 个。目录画得再顺，空货架还是空货架——所以先解决"贴上"。

在「未标知识点 · N 题」旁边加了「逐题贴」：

- 一次只显示一道题，左边是题目原样（公式、选项、配图都在），右边是标签搜索；
- 输入标签名就搜，上下键选，**回车贴上并自动跳到下一题**；空格跳过，Esc 退出；
- 顶部写「第 N 题 · 未标 M 题」，贴上后数字立刻减一；
- 最近用过的标签排在下面，点一下就贴；搜索结果里也会把最近用过的往上提；
- **这道题已有的 AI 建议直接列在搜索框下面**，点一下就采纳并贴上——走的是「AI 建议待核对」同一套采纳接口，建议会被标记为已采纳，不是另贴一个标签。建议里要新建标签的那一条先禁用，流水线不悄悄建标签；
- 贴错了点「撤销上一次」，不用回题库再找。

## 二、教材目录长在题库里

之前标签目录是"另一个页面"：先开标签管理、找到标签、再跳回题库筛。现在左栏就是目录：

- **章 → 节 → 知识点**，每个节点写这一层有几道题；没题的子标签先收在「还有 N 个没用到的」里；
- 点一章就筛成这一章（含子标签）的题，右上角写「标签：初中 · 图形与几何 ×」；
- 「全部题目」「未标知识点 · N 题」也是目录里的一等入口；
- 目录开合记在本机；窄屏上变成左滑层；
- **标签管理退回去只做编辑目录**：没有上下级的类型（历史标签、方法、自定义）左边不再长一棵树——那棵树和中间的列表是同一批标签；有上下级的知识点，在「顶级」这一层中间改成一句提示，进入某一章后右边才显示这一章的标签。

## 三、窗口按钮认准你正在用的窗口

- 反复启动留下的旧窗口会让「最小化 / 关闭」点上去没反应：动作现在优先落在当前前台窗口，其次是没最小化的那个窗口；
- 关窗淡出后如果窗口没关掉，1.6 秒后页面自动恢复并重试，不会永远白屏；
- 启动时浏览器把最小化状态带回来，现在启动会把窗口恢复出来。

## 四、顺手修掉的

- 「更多筛选」被目录开关挤到第二行，现在目录、来源、更多筛选并排一行；
- 题目详情可以收起：收起后右边整列让给题目（列表回到 1040 宽），顶栏「题目详情」按钮出现，点一下就展开；
- 题库顶上的数字不再互相打架：「804 题没知识点（440 题有 AI 建议） · 539 题没答案」，悬停说明写清两种"没答案"以及 411 / 29 的差别；
- 全部入库的卷子不再摆「开始审核」，步骤卡标题改成「这份卷子的题都已入库」；
- 标签地图原来被挤在 240 像素宽的一列里，现在用满整幅宽度。
