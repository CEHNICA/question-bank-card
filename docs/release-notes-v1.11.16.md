# 1.11.16：统一 API 配置与答案显示

- 已保存的读题与答题密钥按服务列出数量和星号，点眼睛可临时查看，查看不更改密钥。
- 修复未修改配置也提示未保存的问题；复选框右侧空白不再触发勾选。
- 密钥窗口关闭先恢复页面，避免关闭时重绘大量题目造成卡顿。
- 普通阅读区域不再弹出浏览器右键菜单，输入框保留复制粘贴菜单。
- 专注浏览的退出按钮移到右上角，改为浅色小按钮，不再遮住题面。
- 读题、标签与答案的 API 密钥和模型配置集中到一个窗口；答案编辑移除单独的 API 设置按钮，生成失败时提示在设置中检查配置。
- 兼容 AI 答案中被反斜杠转义的全角括号，题库、编辑预览和导出共用修复；保留原始文字。
- 修改并保存答案后，题目优先显示保存版本；原卷与旧 AI 初稿收进折叠的历史。“未核对”表示 AI 初稿尚未确认数学内容。
