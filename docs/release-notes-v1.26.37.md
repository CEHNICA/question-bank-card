# 1.26.37：灰掉的按钮都会开口说话；筛选条上那颗小标签看得清了

这一版是上一版收尾时自己查出来的两个遗留问题，都是「老师会卡住、但软件不吭声」的那一类。

## 一、四个灰按钮，一个字都不说

上一版把「调整范围」那块面板整体做了解释：面板顶部有一块提示写明卡在哪一步，
灰掉的「补一题」「修改题号」「合题…」各自带说明。

**但面板里片段那一排的「前移」「后移」，和工具条上的「撤销」「重做」，没有。**
它们一直是灰的（该灰），鼠标停上去也一直是空的。上一版收尾时用截图逐个核按钮，
就是这一步核出来的：截图里这四个灰按钮，一个字都没标。

对老师来说，灰按钮不吭声 = 不知道是软件坏了、还是自己操作不对、还是压根没得挪。

**这一版让这四个按钮各自开口：**

| 按钮 | 什么时候灰 | 现在鼠标停上去说什么 |
|---|---|---|
| 前移 | 这道题只有一段 | 这道题现在只有一段，没有先后可调。先点「再加一块」框出第二段，就能调顺序了。 |
| 前移 | 已经是第一段 | 这段已经是第一段，往前没有位置可挪。要调顺序，先选后面那一段点「前移」。 |
| 后移 | 已经是最后一段 | 这段已经是最后一段，往后没有位置可挪。要调顺序，先选前面那一段点「后移」。 |
| 撤销 | 还没改东西 | 还没有可以撤销的改动。先改点东西（比如挪一下题框），这里就能撤销回去。 |
| 重做 | 还没撤过东西 | 还没有可以重做的改动。先改点东西（比如挪一下题框），再撤销，这里就能重做回去。 |
| 撤销 | 能撤了 | 撤销刚才那一步改动，把范围调回去。 |
| 移除 | 只剩一段 | 移除这一段，这道题就一段不剩了。要整题删掉，用下面的「删除这题」。 |

话术收在一处，切题那套片段列表和「调整范围」面板**用的是同一套**，不会一边改了另一边没改。

## 二、筛选条上那颗小标签，太淡了看不清

资料库页筛选条上，每筛一个知识点就冒出一颗小标签。以前那颗小标签**拿标签自己的颜色当字色**，
浅色标签配浅底 —— 实测只有 **3.88:1**，低于看得清的那条线（4.5:1）。
老师那边看着就是「字糊在底上，眯着眼才认得出」。

**这一版改成「淡底 + 同色边 + 深字」** —— 颜色还是那个标签的颜色（目录、筛选条、详情里看到的
还是同一根色），但字改用深色。真机复验量到 **7.13:1**。

## 三、这一版的验收检查

加了 **23 条「改坏了就废」的检查，全部被挡住**。

写这批检查的时候当场发现上一版的一个漏洞，值得记下来：

**上一版的检查只验「话术写得对不对」，没验「按钮上到底挂没挂上去」。**
话术函数写得再漂亮，按钮忘了把那句话说挂上去，检查照样绿 —— 而老师那边看到的还是
一个不吭声的灰按钮。

这一版补了两层：

1. **真按钮真属性**：把面板真开起来，点真按钮，看按钮上到底有没有那句话、说的是不是该说的那句
   （可用的按钮不许说「不能」；灰的按钮必须说清为什么灰、下一步去哪）。
2. **真改坏**：把 23 处改动逐个改坏，看检查会不会报警 —— 全部被挡住。

## 四、真机验过

**在哪验的**：老师真题库的一份副本。**老师的真库一个字没动。**

- 面板那几个按钮：在副本上打开一份真资料，点「调整范围」，真浏览器里读按钮上的悬停说明 ——
  「前移」「后移」「撤销」「重做」四个都带上了说明，「移除」也带上了。
- 筛选条那颗小标签：真浏览器里量了字色和底色的对比度，**7.13:1**。
- 另外把这版改动里最容易跑偏的两处（按钮挂话术、标签字色）改坏，看检查会不会报警 —— 23 条全部被挡住。
