# 1.11.11：停止 MinerU，直接手工切题

MinerU 解析等待过久时，打开“试卷操作”，点“停止 MinerU，改为手工切题”。软件先停止本地等待并作废旧任务，然后打开完整原卷裁剪，不需要再找手工入口或选择处理路线。

已有题卡、原文文字块、人工修改、审核和入库版本保留。旧云任务迟到后不能重新启动解析或覆盖当前题面；切换本身不调用识读，完成切题后再继续正常的识读与审核。

原页还没有生成时在本机准备；准备失败会显示原因并允许重试，不删除已有成果。重复点击安全，切换试卷后的旧响应不会打开错误的原卷。

同时修复附答案导出的空页：所选题都没有答案或解析时，PDF 和 Word 只输出题目卷，与预览中的提示一致。

继续保留 1.11.10 的两点配图、双击同尺寸复制、密钥窗口关闭修复和应用专用浏览器密码提示关闭。第三方云端任务是否继续运行由服务方管理，本按钮停止本机使用该任务结果。
