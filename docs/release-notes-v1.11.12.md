# 1.11.12 本地改进版

切题窗口支持两点画框、连续保存和快捷键。配图双击的位置就是新框左上角，四个选项可复用相同尺寸。固定框后不会误关窗口，悬浮操作提示不会挤动画布，可关闭并从帮助恢复。

审核筛选保留三个按钮：“重点核查”“需要核查”“已通过”。识读结束仍需要核查，正在配图的题会留在当前筛选，保存成功或明确丢弃后再更新分类。

题库单题和组卷预览可直接编辑答案解析：结果与过程分开，支持公式预览、图片上传或原卷裁图，以及历史恢复。本次组卷默认只保存自己的解析，勾选后才同步题库；原卷版本不变。明确选择题目后才生成 AI 初稿，保存后才出卷。

教师卷可选择逐题紧跟或卷末集中。旧草稿保留原卷答案和原有卷末位置；新草稿固定所用解析版本。学生卷不带解析图，PDF、Word 与预览使用相同内容。长解析可跨页，没有解答时不生成空答案页。

更新增加独立解析数据，不覆盖旧题库或已保存密钥。实际服务的识读与解题精度仍需对照原卷核查。
