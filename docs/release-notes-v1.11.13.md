# 1.11.13 本地验收版

- “重点核查”和“需要核查”合并为“需要核查”；配图尚未保存时题目和数量保持原分类。
- 处理页可选择“继续 AI 切题”；手工模式也可切回自动处理。已保存解析优先复用，无可用解析时会说明需要重新提交 MinerU；原卷、手工题和审核版本保留。
- 修复退出手工切题后按钮仍停留在“正在准备原卷”、迟到加载重新打开窗口的问题。
- 通过题卡后自动入库。题库可直接修改题干、选项、题型和已有配图，人工保存新版本并保留旧版与原卷。
- 局部框选识读后直接选题干或选项位置。题干支持在输入框选中文字再填入，无需复制粘贴。
- 修复题库已显示的 AI 参考答案在编辑窗口为空：指纹有效的初稿补入缺失字段；原卷与已保存人工解析优先，保存后才用于出卷。
- 答案、标签 API 支持 MiniMax 中国区，M3.1 精确型号为 MiniMax-M3.1-Flash-Preview，需要独立 M Plan Key。不同型号的看图和思考参数按官方能力处理。
- 选项支持全卷或单题竖排；解答题支持12、30、60毫米留白和单题覆盖。旧稿与明确“不留空白”保持原设置，逐题附解析及答案卷不加学生留白。
- 题号对齐题干首行。打印操作菜单收为不透明的“调整”按钮，避免透出正文。
- 答案编辑返回不等待无用请求，迟到保存保留结果但不覆盖新窗口或新组卷。编辑区增强边界和对比度。
- 助手初稿区分待领取、处理中、失败、取消和超时；明确给当前助手的逐题任务，实际解答并提交，避免只领取后无限等待。任务可取消重试，旧结果不能覆盖新任务或人工修改。

这些修改不证明云端数学解答一定正确。未配置对应独立 API 时仍可由当前助手执行明确选定的任务；不会因此打开全局生成或扫描旧题。
