# 题有据 2.1.3 更新说明

## 修复与改进

1. **去掉题卡上的题号不一致与“范围内还印着第 N 题”黄色提示条**
   - 停用「AI 看到的题号是 N，请确认」与「这张卡的范围里还印着第 N 题的题号，卡上只有这一道；请对照原书确认那几道题是不是漏进来了」两类提示生成，不再将题号顺延与教材印刷编号不同步的题目误标黄。
   - 已有题卡在打开试卷列表、批量「通过全部绿色题卡」以及后台启动清理（`tidy_saved_cards`）时会自动剔除这两类历史提示并恢复为绿色（如无其他缺图、模糊字或混入答案等问题）；前端界面 `questionFlags` 同步拦截展示，确保旧题卡立即生效，同时继续保留「缺图 / 看不清字 / 混入印刷答案 / 范围跨节」等核心提醒。
