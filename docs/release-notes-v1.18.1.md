# 题有据 1.18.1

基于 1.18.0，修复删掉最后一个题框后不知道如何继续的问题。

- 移除最后一个范围框后，侧栏明确显示“这道题已经没有范围框”，可直接选择“恢复刚删的框”“重新画框”“删除这题”。
- 恢复框无需保存或确认；重画直接进入十字框选，在原卷上点两个角即可。页码、缩放与浏览位置保持。
- 题目无框时禁用保存，不再显示“结果 1 · 0 段”或空裁片预览。离开时可以继续修改或放弃本次修改，保留原来已保存的范围。
- 多框题移除一框后，数量和页码显示当前草稿的数据。
- 删除整题经过一次确认，移到现有回收站；原卷侧栏保留“恢复这题”，无需关闭原卷即可恢复原来的题目和框。也可以从审核页回收站恢复。取消或失败均保留当前修改，已入库及识读中的题继续沿用删除保护。
- 取消重画时同步退出十字框选，按钮随即恢复正确状态；删除及恢复后保留页码、缩放和浏览位置。
- 新增题、拆题和合题中的空草稿不会出现删除已有题的入口。调框、恢复和重画均不自动识读。

Windows 版发布于 [GitHub Releases](https://github.com/CEHNICA/question-bank-card/releases/tag/v1.18.1)。升级前请备份题库并关闭正在运行的程序。保留既有 PDF 修复、找题、审核位置恢复、直接调框、拆合和持久撤销。
