# 题有据 2.1.0 更新说明

## 本版架构升级与核心改进

1. **桌面端双栏常驻原卷分屏画布与双向题框联动**
   - 在 `>=1120px` 宽屏录题页默认左侧常驻展示高清原卷画布（`#intakeSplitPane`），支持翻页、缩放（`－` / `100%` / `＋`）、显示/隐藏题框叠加与一键收起；窄屏自动收纳以免挤压阅读。
   - **双向精准联动**：点击右侧题卡自动翻页并高亮左侧原卷对应边框；单击原卷题框同步定位并聚焦右侧题卡，双击题框直接打开精确切题调框模式。

2. **三步录入流程导航条（① 导卷切题 → ② 逐题核对 → ③ 完成归档）**
   - 试卷头部下方新增 `#intakeStepper` 流程状态条，实时反映当前所处阶段，点击各步骤可直接切换到「看原卷」「只看需要核查」或「归档收起」。

3. **拍照暂存预处理升级（旋转转正与策略同窗确认）**
   - `#photoDialog` 接入独立模块 `intake-staging.js`，支持缩略图预览、文件大小提示、「← 前移 / 后移 →」、顺时针 90° 旋转（提交时自动对图片像素进行真实旋转重编码）及同窗选择云端辅助切题策略。

4. **共享安全 API 客户端、可撤销整卷回收站与 Eagle 直达解析**
   - 新增 `qb-api-client.js` 统一管理 `X-QB-Request` 请求头、结构化错误、`409` 冲突标识及按资源串行写队列，录题页与 Eagle 题库工作台共用统一安全请求内核。
   - 录题页试卷菜单新增「移入回收站（安全撤回）…」，原子化归档试卷并按卷批量撤回已入库题目（撤题失败自动回滚归档），同时保留题库回收站一键恢复能力。
   - 已入库题卡操作区新增「编答案/解析」按钮，直接跳转到 `/eagle?q=<id>&edit_solution=1` 并自动唤起统一 `LibraryAnswerEditor`。
