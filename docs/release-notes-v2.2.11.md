## 题有据 2.2.11 更新说明

### 更新亮点

1. **统一全屏三区「编辑」工作台与工作台整合**：
   - 录题页与正式题库（`/eagle`）现在共用统一的三区「编辑」工作台：左侧对照原卷（支持内置高清大图灯箱与整页切换），中间编辑题干/选项与默认展开的「答案与解析」，右侧实时 KaTeX 排版与光标位置同步预览；
   - `/eagle` 清理移除原有双弹窗冗余，右键与菜单收口为单一「✏️ 编辑」入口，并按入口自动定位到题干或答案输入区；`/library` 整卷批量「答案解析」模式保持不变；
   - 顶栏精简为三分栏（`← 返回` + 状态徽标 / `‹ 上一题` · 位置 · `下一题 ›` / `题型` + `保存`），题干新增「插入填空线 ____」与表格快捷工具；「答案与解析」新增 **✨ AI 推荐答案**（仅本次显式触发，不改动全局开关），修改题干并同步保存解析时可自动安全迁移已上传的解析配图资产。

2. **选择题与选项配图完整扩展至 `A–H`（8 选项）**：
   - 编辑器默认展示 `A–D`，支持通过「+ 添加选项」逐个扩充到 `H`（并支持清除尾部空选项），前后端解析、校验、配图槽位、预览与 Word/PDF 导出全面兼容 5–8 个选项；
   - 严格保持四选项基准字段集，已入库及已通过的既有四选项题目 `content_hash` 与审批记录不受影响。

3. **录题 0 题待切引导清理与「改字 → 编辑」文案统一**：
   - 修复录题页在「有原卷待手工切题且当前 0 题」时的重复引导与无意义统计栏占用问题，自动展开分栏切题面板且不覆盖用户布局偏好；
   - 将界面操作文案与快捷键提示中的「改字」统一更名为更直观的「编辑」（快捷键 `E` 保持不变）。

### 验证范围

- **代码规范与类型检查**：`ruff check backend tools`、`ruff format --check backend tools`、`npm run lint`（ESLint）与 `mypy` 通过。
- **前端测试**：`npm test`（`node --test frontend/test_*.js`）全量通过，覆盖统一工作台行为测试、动态 `A–H` 选项及预览导出测试与无障碍/窄屏适配校验。
- **桌面启动与打包测试**：`unittest` 覆盖启动器、备份、打包与快捷方式检查通过。
- **后端核心测试**：`manage.py test core` 覆盖 `A–H` 选项保存、跨版本解析图资产迁移、AI 推荐接口、录题准备与 `/eagle` 静态资源服务检查（默认跳过需真机浏览器的导出专项检查）。
