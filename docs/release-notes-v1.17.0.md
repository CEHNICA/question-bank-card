# 1.17.0：切题与原卷校正合并为一个流程

基于 1.16.1，将手工切题、查看整份原卷和补题合并到同一个“切题与校正”窗口。已有题框、改题号、范围校正、补题、拆题、合题及保存后的撤销继续使用原有布局保存与历史记录。

## 连续补题

1. 打开“切题与校正”。空试卷会直接进入第一题的框选草稿；已有题目时先显示彩色题框总览。
2. 点“补一题”，在原卷上依次点题目范围的两个角。若题目跨页或跨栏，使用添加片段并按阅读顺序整理。左侧裁片预览始终显示当前范围。
3. 核对题号、题组和范围后点“保存并框下一题”。保存成功后，窗口保留当前页和缩放，出现空白的下一题草稿。
4. 最后一题保存后点“完成切题”。如果下一题草稿是空白，直接完成，不会多创建一题。尚未固定的框会要求你先处理。

补题只保存原图范围，不会自动识读。完成后回到题卡区，之后可以主动选择“识读未完成题目”或“直接原图审核”；也可以继续打开“切题与校正”。拆题和合题在“更多操作”中，保存前会显示需要核对的变更。

## 快捷键与保护

- 原卷画布有焦点时，`S` 或 `Enter` 保存并框下一题；`Ctrl+S` 或 `Ctrl+Enter` 完成切题。
- 输入框、教学控件及其他弹窗不会触发画布保存快捷键。中文输入法组合输入不受打断。
- 保存失败或结果暂时无法确认时，草稿和请求编号保留；确认原请求结果之前不能创建下一题。改号、校正、拆合和补题继续使用布局版本核验及持久撤销。
- 新上传资料原有自动解析流程保留。进入手工校正会解除尚未提交的自动识读续接；已提交的任务继续显示实际状态。

本版为本地验收成品，不自动升级已有安装，也不代表已在 GitHub 公开发布。
