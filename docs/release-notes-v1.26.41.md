# 1.26.41：「批量通过可入库题目」的结果，从 509 行平铺改成了一份总账

这一版只改一件事：**点完「批量通过可入库题目」之后弹出来的那个结果面板。**

## 一、原来是什么样

在老师那本 771 题的书上实测，点一次「批量通过可入库题目」，弹出来的面板是**509 行平铺**：

- 每行只写一句「第 N 题」；
- 509 行**重复着同一句原因**；
- 想找那道题，只能自己从上往下翻。

## 二、为什么「第 N 题」不算数

这类教辅**按小节重复结构**，题号在同一个小节里就重号上百处 —— 那本书里「第 1 题」就有 205 道。
**光写「第 N 题」，老师拿着这句话回原书根本翻不到那道题。**

所以定位的说法定成一条：

> **先章节小节 → 再题号；没有章节名就用原卷页码；再补题干开头 60 字。**

实际长这样：「章节01 · 公式法 · 第 1 题」，后面跟着原卷第 3 页和题干开头那一句。
旧题里那 257 道既没有章节也没有小节的，就靠「原卷第 167 页 · 第 1 题」加题干开头定位。

## 三、现在是什么样

### 1. 先给一份总账

- 「已入库 N 道」；
- 一道都没入库时，再加一句「最多的一类是 N 道，卡在同一件事上：X」—— 老师不用自己数，也不用自己判断先管哪一类。

### 2. 按原因分组折叠

一类原因占一条，标题写「原因（N 道）」，**展开**才看到具体是哪几道。
509 道全卡在同一件事上时，占的是**一行**，不是 509 行。

### 3. 每一条都能对回原书

每条写三样：**章节小节 + 题号**、**原卷页码**、**题干开头**。

### 4. 每条只说自己多出来的那一句

以前 509 行重复同一句「怎么办」，老师看了等于没看。现在每条只写自己多出来的那部分：

- 没读出题干的 → 「请先改字或重新识读」
- 题型还没定的 → 「请先在题号旁边选一下题型」
- 配图状态没确认的 → 写清卡在哪张图上

## 四、一套说法，三处通用

定位说法**收在一处**，**结果面板、回收站、找题三处用同一套** —— 同一个操作只有一套说法，
不会再出现「结果面板这么叫、回收站那么叫」。

弹窗的标题也统一了：原来叫「一键通过的结果」，现在叫「**批量通过的结果**」，跟按钮「批量通过可入库题目」
是同一个说法。

## 五、怎么验的

- **15 条「改坏了就废」的验收检查，全部被挡住。** 每一条都真的把那处改坏一遍，看测试会不会报警；
  改完按字节还原、再核对一遍指纹。
- 全套检查全绿：前端测试 151 项、后端测试 2444 项、桌面外壳测试 147 项。
- **真机实测**：在老师真题库的一份副本上真按了一次「批量通过」，509 道没过的题**每一道都带章节、页码和题干开头**，
  缺页码 0 条、缺题干开头 0 条、既没章节也没小节 0 条；509 道确实全落在同一类里 —— 「一道都没过」那种情形，
  总账那句话和分组折叠都按预期出现。

**真机验在老师真题库的一份副本上做，老师的真库一个字没动。**
