# 1.11.6：自动导入、立即停止与统一原卷窗口

- 上传无需选择手工、文字 PDF 或 MinerU。先尝试本机处理；只有本次允许发云并已配置服务时才自动使用 MinerU。未切出的题、云服务失败或不同意发云，都保留原卷供框题，不更换其他收费服务。
- 本机停止立即生效，不等待后台返回；处理代次作废，旧任务的成功、失败、进度和下载都不能覆盖重试后的结果。原卷、成功题卡、人工审核和入库历史保留。
- 原卷框选与识读共用窗口和范围。新题保存为原图草稿，识读是显式可选操作；原图题读出文字后先显示建议，确认采用才转换正文。
- 连续保存保留页码、缩放和位置；框选退出有未保存保护，保存期间防重复提交，失败保留全部草稿。新框自动选中，方向键可微调，跨页片段可按缩略图排序并查看拼接效果。
- 空题库提供直接导入入口；未切出的题从原卷选取。取消、排队、超时、失败分别提示，避免无限显示正在识读。
- CLI/MCP 默认 `auto`，云回退需显式 `--allow-cloud` / `allow_cloud:true`；标签与 AI 参考答案继续默认关闭。

本轮先安装本地供检查；GitHub 正式下载安装版仍是 1.11.5。没有宣称 MinerU 已恢复，也没有自动接入整页 AI 语义切题。
