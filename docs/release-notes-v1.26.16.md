# 1.26.16：设置页整体规划，第一轮动工

老师看过 1.26.15 的 API 配置页之后说"非常好"，让我把整个设置界面规划一下，规划完就动工。

规划写在 [设置界面规划](设置界面规划.md)。这一版是规划里的**第一轮**：把五区统一成
一种视觉语言，并给每一区一句开场白。

## 一、五个区现在是同一种卡片了

之前 API 区已经是新样式（圆角 14、淡边、极淡投影），其余四区还是老卡片 —— 现在
统一了：卡片圆角 14、1px 淡边、极淡投影、内边距 16–18px，标题 16px，说明 12.5px 灰字。

五种页面元素只用四种，五区通用：

1. **开关行** —— 浅灰底圆角条，左标题 + 说明，右开关；
2. **键值行** —— 浅灰底圆角条，左标签右值（版本、许可证）；
3. **按钮行** —— 一个主动作（绿底）+ 可选次要动作（白底）；
4. **说明行** —— 12px 灰字，一句话说完。

## 二、每个区开头一句引导

打开设置页不再是一句"核对题目与正式题库共用。"（那是题库页的话），而是**按区换**：

| 区 | 开场白 |
| --- | --- |
| API 配置 | 填好这一区，识读和生成答案就能用。密钥只加密保存在这台电脑上。 |
| 显示与导出 | 只改这台电脑上的显示和导出，不改题库里的题。 |
| 数据备份与迁移 | 换电脑、备份，或者把两台电脑的题库并到一起，都在这里。备份不联网，也不上传。 |
| 帮助 | 先挑一种切题方式，别的随时能换。 |
| 关于 | 题有据在这一台电脑上运行，数据不出这台电脑。 |

备份区原来自己还有一句几乎一样的话，删掉了 —— 同一件事不说两遍。

## 三、导入记录的时间写成人话

```
今天 10 月 23 日 05:28　并进来 1 套卷子、2 道题、给 2 道题补上答案
昨天 10 月 22 日 18:45　并进来一些题目
```

以前是 `2026/10/23 05:28:16` 这种机器时间戳。合并记录往往是几天前的事，
"几天前"才管用。
