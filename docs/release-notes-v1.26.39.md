# 1.26.39：把「教辅按章节重复结构提题」这件事，交给外部助手来干

这一版**不动软件的界面**，也不新增按钮。它做的是一件事：
**让住在软件外面的 AI 助手（比如 ChatGPT、Codex、Claude Code 这类能操作电脑的助手），有一套看得懂的说明书和一把趁手的工具，
好让它们来接管「教材／教辅只要题目、不要讲解」这种活。**

## 一、为什么需要这个

有一类活，软件的自动切题做不了，也**不该**由软件自动切题做：

- 教材、教辅整本书是**按同一个章节结构反复排**的 —— 第一节「公式法」是例题＋点评＋变式，
  第二节「数形结合」又是例题＋点评＋变式，一本书下来几十节都是这个骨架。
- 老师要的是**把题目抠出来**，讲解部分不要；而且抠出来的题目还得**按书里的章节号归位**。
- 机器按「这一页切几道题」的思路去切，会切得七零八落，还把讲解也当成题干。

这类活真正需要的是：**有人（或者某个助手）读懂这本书的结构，然后按结构来提题。**
所以这一版把「怎么读懂结构」写成了一套固定流程和一只只读工具，让外部助手照着做就行。

## 二、这一版具体加了什么

### 1. 一条明确入口：`skills/tiyouju/SKILL.md`

在题有据自带的助手说明书里，多了一节 **「外部助手接管与教辅结构提取」**。
外部助手接到这个任务时，按这节走就知道：

- **普通活**（读题、改字、配图）照旧走原来的逐题工作流；
- **教辅活**（只要题目、按章节重复结构重提取）走新写的《教辅结构提取》流程；
- **边界写得很死**：先交候选，再按已确认的范围替换；
  题面提案不支持整书范围，**不能把「候选生成完了」说成「整本书已经换掉了」**。

这一条不是客套话 —— 过去助手最容易出的岔子就在这儿：交了一份候选题清单，
就汇报说「这本书已经替换完成」。现在白纸黑字写在说明书里，助手读得到。

### 2. 一份新流程：《教辅结构提取》

新文件 `skills/tiyouju/references/book-structure.md`，写的是这类活的完整打法：

- 怎么从一本书里看出「章节 × 题型」是重复结构；
- 怎么用只读快照把原页和题卡拿出来做归纳；
- 怎么把归纳出来的结构对应回具体题目；
- 交候选时该给老师看什么、怎么标出没把握的地方。

### 3. 一只只读工具：`book_structure_snapshot.py`

**新加的脚本**，作用就一句话：**把指定的一份资料的详情和原页导出成快照**，交给助手去归纳。

```powershell
python skills/tiyouju/scripts/book_structure_snapshot.py `
  --paper <资料 id> --out <空目录> --pages 1-2 --timeout 120
```

它会输出：

- `manifest.json` —— 这次快照的基本信息；
- `paper-detail.json` —— 这份资料的题目详情；
- `pages/page-0001.jpg` …… —— 对应页的原图。

**这只脚本是只读的**：它只导出你**明确指定**的那一份资料，不碰题库、不写库、不替换任何东西。
这是刻意的 —— 归纳结构可以交给助手自动做，**动老师的题库必须由老师点头**。

### 4. `AGENTS.md` 里同步了规矩

在同一批改动里，`AGENTS.md` 加了对应的一条：教辅提题／按章节重复结构重提取时走哪条入口、
需要读哪份参考、以及那条不许吹牛的边界。

## 三、验收

- 新脚本按仓库的 ruff 规矩重排过（`ruff check` 与 `ruff format --check` 全绿）。
- **拿已安装的软件实跑过**：脚本正常导出资料详情与原页，题数与页数都对得上。
- 全套检查跑完：ruff、eslint、mypy、后台测试（2441 项）、前端测试（147 项）、
  桌面外壳测试（147 项），**全绿**。
- 脚本改动**不碰软件功能**，所以这次升级对老师来说没有任何操作变化 ——
  装了跟没装一样顺手，只是外面的助手多了一份说明书和一只工具。

## 四、给使用者的说明

如果你用能操作本机的 AI 助手（ChatGPT、Codex、Claude Code 等）：

1. 先让助手读 `skills/tiyouju/SKILL.md` 的「外部助手接管与教辅结构提取」；
2. 需要时再读 `skills/tiyouju/references/book-structure.md`；
3. 让助手用 `book_structure_snapshot.py` 导出指定资料的快照，然后归纳章节结构、提题；
4. **最后一步由你自己点**：候选交上来，你核对、采纳，才算入库。

助手**不会**替你删题、撤回入库、自动通过题目，也不会在没确认的情况下把整本书换掉。
