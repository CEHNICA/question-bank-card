# 1.25.91 → 1.25.97：标签这一块理顺了，最后把配图存不进去这个真 bug 修掉

这一段共 7 版（1.25.91–1.25.97）。前六版是**题库标签**这一块——同一个标签在好几个地方长得不一样、加标签有两个入口、贴在题上的标签深底压着深字；最后一版是**配图保存被卡死**的修复，那是这一段里唯一影响"能不能把活儿存进去"的问题。

---

## 一、1.25.97：配图存不进去，「无关候选图格式不正确」而且重试永远没用（本次重点）

### 老师看到的

在题卡上配好图，点保存，弹出一行红字：

> 未保存: 无关候选图格式不正确。框选仍保留，请重试。

框确实留着。可点一百次「重试」，还是这句话 —— 框里画的活儿白干。

### 查出来的两个原因

**一、同一张候选图，网页和后端算出两个身份。**

候选图的身份是「第几页 + 框在哪」，写成 `页码:x0,y0,x1,y1`。

- 网页算它用 `Math.round(v * 10) / 10`：**90.55 → 90.6**
- 后端算它用 Python 的 `round(v, 1)`（银行家舍入）：**90.55 → 90.5**

同一张图，两个身份。网页把自己那份当作「这张与本题无关」发给后端，后端对不上号，
于是**把整份配图一起拒掉** —— 老师框的图、标的归属，全没了。

拿 25 万个随机坐标实测：

| 规则 | 与网页不一致的坐标 |
|---|---|
| 旧后端规则（银行家舍入） | **2,174 处** |
| 新后端规则（逢五进位） | **0 处** |

命令行工具 `tiyouju.exe` 里还藏着**第三份**同样的算法。这次三处一起对齐 ——
不然助手按自己那份去核对，结论和界面对不上。

**二、改过题目范围之后，之前「与本题无关」的判断会被悄悄丢掉。**

范围一改，后端重算本题的候选图；原来那张被标成无关的图，已经不在范围内了。

但「这张不是本题的图」这个判断本身**没错** —— 以前后端会因此把整份配图一起拒掉，
回给网页时还会把那条判断悄悄抹掉，下次重算它又冒出来。

现在：原卷里确实存在的那张图（哪怕已经不在本题范围内）继续算数；
连原卷里都没有的 key，仍然是格式错误 —— 这个保护留着，没有放松。

### 还改了什么

存不下时不再只说「请重试」（重试永远不会成功），改成说清是哪一步卡住了、
接下来该点哪里：关掉窗口，重新打开「配图」再保存一次 —— 那一步会重新核对候选图。

### 怎么验的

- 后端 2,264 个测试全过（含新增的 `core/test_figure_candidate_identity.py`）
- 外壳 148 个、网页 131 个测试全过
- 隔离环境里端到端验过四件事：
  1. 范围外但原卷里有的那张图标成「无关」→ **存得进去**，判断也记住了
  2. 原卷里根本没有的 key → 仍然拒（400「无关候选图格式不正确」）
  3. 旧版本记下的身份 → 照样认
  4. 坐标带两位小数（90.55）时，网页和后端算出同一个身份（`0:90.6,...`），发过去存得进去

## 二、1.25.96：「还有活没干」那块面板被挡在屏幕外面了

老师发来截图说「挡住了，让他在右边展示」。实测出两个病：① 这块面板原来贴在
「还有活没干」按钮右边，而那个按钮在吸顶的批量条里，窗口一窄（1100 像素宽）
面板就甩出屏幕左缘，落在 x = -141，「标签」栏五颗按钮只剩右半截、「答案」栏却完好；
② 它住在吸顶条（层级 20）里，「更多筛选」住在筛选行（层级 21）里，整层压着整层，
1442 像素宽也能被盖住。

现在面板自己算位置（贴按钮右缘；放不下就贴屏幕右缘；视口更窄才贴左缘），
并挂到最上层，宽窄窗口下都整个落在屏幕里。

## 三、1.25.95：贴在题上的那颗标签，深底压着深字

标签底色用同色系加深、字仍是浅色，**对比度只有 1.83:1**（远低于 4.5:1），
在题卡上一片深底浅字糊成一团。改成淡底 + 同色边 + 深字，对比度 **7.50:1**，
标签本身也还是原来那个颜色。

## 四、1.25.94：加标签的两处入口，操作方式不一样

题卡上点标签、题库页批量加标签，是同一件事却是两套操作。统一成同一套：
选中题目 → 点「加标签」→ 同一副弹窗里选父级、填名字。

## 五、1.25.93：同一个标签，在几个地方长得不一样

标签颜色以前在几个地方各算一遍，浅色系和深色系混用，同一个标签在标签地图、
题卡、弹窗里颜色对不上。改成**颜色只算一次**，六处共用；算不出颜色时回退到一个
不会和老师拧着的颜色。

## 六、1.25.92：开着教材目录时，试题篮盖住了整片题目

左侧目录展开时，中间那一栏被试题篮整个盖住。篮子挪回第三栏，栅格改成会算账的
（按实际可用宽度算，而不是写死），窄屏时不再互相压住。

## 七、1.25.91：一颗灰着的按钮，一句说不清的话

一个按钮因为没有可做的事而灰着，旁边的话既像在解释规则又像在抱怨。改成：
按钮按三种原因分别说清「为什么灰」「什么时候能点」「现在该做什么」；
待办条里的数字不会再出现负数。

## 顺带记一件事（本机环境，不是代码问题）

开发机上 **Inno Setup 安装包一度装不进去**：装到一半报「拒绝访问（错误码 5）」，
回滚把程序目录删掉。排查下来是本机 **360 的「主动防御」**在装软件时拦文件操作
（连已发布的 1.25.96 安装包也同样失败，几十个小文件的安装能过、五千多个文件
的大包必挂）。卸载 360 后安装包一次通过，程序目录、开始菜单快捷方式、
「控制面板 → 卸载」条目全部正常。

**给其他老师的提醒**：如果安装包报"拒绝访问"或装到一半自己退回去，
多半是本机安全软件（360 / 火绒等）在拦。可以先临时关掉这类软件的
"软件安装防护"再装一次；本项目的 `install.ps1` 也计划加一条退路
（安装包失败时改用便携目录覆盖的装法）。
