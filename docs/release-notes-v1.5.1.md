# 题有据 v1.5.1

修正教材例题的题面：印在题前的“例1”“例 2．”“例题3”“【例4】”这类标号不再写进题目文字。

- **新识读**：识读时不再誊录例题标号；即使模型带上了，也会在保存前去掉。MinerU 旁证比对时同样忽略这个标号，所以不会因为一边有“例1”、一边没有而多出黄卡或多一次调用。
- **已有题卡**：升级后第一次启动时，本机题库里题面以例题标号开头的题卡会自动去掉标号，只动标号，其余文字、配图、范围都不变。原来已标记通过的仍保持通过；已入库的题目同步更新，不会生成新版本。
- **保留引用**：“例2中的函数……”“例1与例2的结论”这类引用例题的题目，标号是题目内容，原样保留。
- **题卡标题**：教材例题的题卡标题显示“例 1”，不再显示“第 1 题”，和练习题区分开。

## 升级说明

覆盖安装即可，无数据库结构变化。
