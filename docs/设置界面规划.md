# 设置界面规划（1.26.16 起）

老师看过 1.26.15 的 API 配置页之后说"非常好"，并让我把整个设置界面规划一下。

## 现状盘点（2026-10-23 实拍）

| 区 | 现在的样子 | 判断 |
| --- | --- | --- |
| API 配置 | 1.26.15 刚重排过：三步进度条 + 服务商一行式 | ✅ 已是新样 |
| 显示与导出 | 三张卡：导出位置 / 题面整理 / 审核界面 | 基本可用，缺一句引导 |
| 数据备份与迁移 | 三张卡：导出备份 / 从备份合并 / 导入记录 | 可用，导入记录的时间是机器格式 |
| 帮助 | 三张卡：选一种切题方式 / 遇到问题时再看 / 常见问题 | 结构最好的一张 |
| 关于 | 一张卡：隐私三条 + 版本 + 许可证 | 简单，够了 |

**共同的毛病**（不是某一个区的问题）：

1. **五区不是一个视觉语言** —— API 区已经是新样式（圆角 14、淡边、浅影），其余四区还是老卡片；
2. **页头那句话是别的页的** —— 设置页顶上的"核对题目与正式题库共用。"是题库页的说明；
3. **有的区有引导、有的没有** —— API 区有"现在配到哪一步"，显示与导出区没有；
4. **同一层级的说法不统一** —— 有"位置/文件夹/路径"三种叫法，"重试/重新读取"两种叫法。

## 规划：一条视觉语言 + 每区一句引导

### 一、统一的骨架

- **页头**：「设置」+ 一句**这一页**的说明（按区变）+ 右侧「返回题库」。
  现在那句"核对题目与正式题库共用。"是题库页的，改成设置页自己的。
- **导航**：五个标签保持不变（AGENTS 1.11.17 定的五区）。
- **每个区开头一句引导**：说清这一区管什么、要不要管。
- **卡片**：白底、圆角 14、1px 淡边、极淡投影、内边距 16–18px —— 五区完全一致。
- **卡片头**：标题 16px + 一句说明 12.5px 灰字。
- **元素只用四种**，五区通用：
  1. **开关行** —— 浅灰底圆角条，左边标题 + 说明，右边开关（题面整理、审核界面已在用）；
  2. **键值行** —— 浅灰底圆角条，左标签右值（版本、许可证已在用）；
  3. **按钮行** —— 一个主动作（绿底）+ 可选次要动作（白底）；
  4. **说明行** —— 12px 灰字，一句话说完。
- **不新增第三种卡片样式**。

### 二、逐区怎么做

**① API 配置** —— 保持 1.26.15 的样子，不动。

**② 显示与导出**
- 开头加一句："这些只影响这台电脑上的显示和导出，不改题库里的题。"
- 「导出位置」不动（桌面版有路径 + 更改位置/打开文件夹，网页版说明用浏览器下载）。
- 「题面整理」「审核界面」保持开关行。

**③ 数据备份与迁移**
- 开头加一句："题库全在这台电脑上。按电脑、备份，或者把两台电脑的题库并到一起，都在这里。备份不联网，也不上传。"（已有，改个位置）
- **导入记录的时间改成人话**："3 天前 · 10 月 23 日 05:28"，并在右边标出这是哪一次合并。
- 「导出备份」「从备份合并」保持不动。

**④ 帮助**
- 开头加一句："先挑一种切题方式，别的随时能换。"
- 两张并排的卡（自动切题 / 切题与校正）保持 —— 这是整个设置页最好的一块。

**⑤ 关于**
- 开头加一句："题有据在这一台电脑上运行，数据不出这台电脑。"
- 隐私三条、版本、许可证、查看源代码保持。

### 三、动手顺序

1. 五区卡片统一视觉（一条 CSS，五区通用）
2. 页头说明改成设置页自己的
3. 每区加一句引导
4. 导入记录的时间写成人话
5. 发版

### 四、规矩

- **一个 id 都不改** —— 脚本照旧跑，功能一个不少。
- 每个区的开关、按钮、折叠区的行为一个字不动。
- AGENTS 1.11.16–1.11.18 的规则照旧：API 配置只有一份、密钥不回填、测试要明确同意。
- 新样式照旧放在单独文件 `frontend/api-redesign.css` 里（现在它管整个设置页），删掉一行 `<link>` 就退回原样。
