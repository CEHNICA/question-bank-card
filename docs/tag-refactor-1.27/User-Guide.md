## 一、找题：三个入口，三件独立的事

左边竖着三个入口，**它们不是一套东西的三级分类**：

| 入口 | 回答什么问题 | 例子 |
|---|---|---|
| **教材目录** | 这题在哪本书的哪一节 | 甲版必修一 → 第十六章 二次方程 |
| **数学主题** | 这题涉及什么数学内容或方法 | 函数单调性、分类讨论、构造中位线 |
| **个人专题** | 你打算怎么用这道题 | 周五小测、易漏解、一题多解 |

一道题可以同时在两个专题里，也可以既属于某章又考某个概念 —— 三者是独立的。

**教材目录只记「在哪本书的哪一节」。** 不知道版次的旧章节会落在「通用教学目录」里，不会编造一个教材版本给你。

**数学主题是概念，不是章节。** 搜「函数单调性」时勾上「包含下级」，会把「单调性」「增函数」这些下级一起算进来 —— 这只是把范围放宽，**不会给你的题复制一个「函数单调性」的标签**，也不表示这道题考查了单调性的全部性质。

## 二、搜索：条件看得见，也拿得掉

### 两种写法

**直接写关键词** —— 搜题干、选项、答案、解析。

**写一句话** —— 比如：

```
第（1）问用配方法
不用配方法
主要考查二次函数的最值
解法一 分类讨论
```

写完点「找题」，程序会告诉你**这句话被理解成了什么**：

```
这句话被理解成了：
  第（1）问 → 小问：第（1）问
  配方法 → 方法：配方法
认不出来的部分放在关键词里，没当成正式条件。
```

**没认出来的词不会变成正式条件**，只会进关键词走全文检索。

本地只认这几种说法（界面上也列着）：用途词（主要考查／辅助用到／解法采用／题面特征）、小问（第（1）问／第一问）、解法（解法一／另一个解法）、排除词（不用／排除）、题型（选择题／填空题／解答题），以及**你自己目录里的概念和方法名**。

这不是「懂中文」—— 换个说法它就认不出来了。认不出来时它会老实说。

### 条件条

搜出来的条件摆成一行行的小条，每条都能单独拿掉。拿掉一条立刻重搜。

### 结果分几块，各算各的

| 分区 | 什么意思 |
|---|---|
| **已确认匹配** | 人工确认过、依据当前有效的正式关联 |
| **旧标签命中** | 旧记录，没定位到具体解法 —— 不冒充精确的方法证明 |
| **待核对线索** | 还没核对过，不计入正式匹配 |
| **未整理** | 这些题还没贴过标签 |

**「未整理」不等于「没有」。** 一道题没贴标签，不代表它不含那个知识或方法。

排除某个方法时，没整理过的题会进「未知」，**不会被当成「确认没用这个方法」**。

### 搜到的方法条件，默认要「同一个解法里」

「方法 A 和方法 B」默认要求**在同一个解法分支里同时出现**。

要找「分别有两种解法」的题，条件里要显式写「分别存在」。默认这么严，是因为暗中混用两种语义，搜出来的题会让你白翻。

### 保存这次搜索

「保存这次搜索」保存的是**完整条件**（关键词、来源、题型、用途、范围、排序），不是结果快照。条件改了结果跟着变。

## 三、整理一道题

在左边点一道题（**点卡片就行**，不用找按钮），右边就展开整理面板。

### 主要考查

这道题主要在考什么。加的时候点「＋添加」，输入名字或别名，回车选已有的。

同名但含义可能不一样的概念，**会列出范围说明让你选，不会默认挑第一个**。

### 当前解法

先选**范围**（整题 / 某一小问），再选**解法分支**，然后「＋添加」记下这个解法用了哪个方法。

> 「解法采用」必须指明是哪个解法分支。没有分支就记不了是哪种解法 —— 按钮是灰的，旁边也写清楚了原因。

### 其他已记录解法

你确认过的别的解法放这儿，**连同每个解法用过的方法一起显示**。

这里写「已记录」，不写「所有」—— 没有任何工具能证明一道题的解法已经被穷尽了。

### 更多信息

辅助知识、题面特征、专题、教材对应，以及这道题**整理到什么程度**。

「没贴标签」和「查过、确实没有」是两回事，界面上分得开。

### 待核对建议

AI 给的建议摆在这儿，**一条一条**：

- 名称、拟议用途、范围、对应解法
- **依据**（折叠起来，要点开看）
- 可以先改再决定
- 「采纳」「拒绝」逐条点

**没有「一键全部采纳」。** 每条建议你都得自己看过。生成建议也要你自己点 —— 打开题库、翻目录、贴标签都不会自动调 AI。

## 四、记另一种解法

「其他已记录解法」里放你确认过的另一种解法。当前采用的解法不会因为多记了一种就被换掉。

**解法选择不会改变打印和组卷草稿里已经固定的答案版本。**

---

## 五、维护概念

在「数学主题」入口搜概念名，可以：

- 看它的规范名、别名、范围说明
- 看哪些题用了它
- 看它和别的概念的关系

「中位线定理」和「构造中位线」**不等价，不会被合并** —— 它们之间是「相关」关系，独立显示，不参与上下级继承。

## 六、和旧版的关系

| 你原来用的 | 现在 |
|---|---|
| 正式题库页 | **一切照旧** —— 题、组卷、导出、答案编辑都没变 |
| 「保存标签组合」（浏览器里） | 继续能用；新的「保存这次搜索」存在服务端，换设备也在 |
| 贴标签 | 旧入口照旧；新工作台里贴的会同时反映到旧界面 |
| AI 标签建议 | 照旧：得逐条采纳 |

**新贴的标签会同步到旧界面**（旧界面显示的是标签名列表，不分用途）。要分清「主要考查」和「辅助用到」，用新工作台。
