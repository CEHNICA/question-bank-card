# 1.26.55 —— 教材目录（左栏）现代 Clean UI 深度升维

## 这一版忙了什么

老师在查题与筛选时反馈：「教材目录这一块不太好看，美化一下」。
通过对左栏界面的视觉走查，我们定位了以下几个关键视觉与交互瑕疵并进行了深度优化：
1. **风格拼接割裂**：分类切换栏（知识点/方法/自定义）为椭圆药丸胶囊，而学段栏（全部/初中/高中）为方块切换块，上下风格严重脱节。
2. **斑马虚线打孔手柄粗糙**：零题章节左侧绘制了密密麻麻的虚线打孔长竖条，视觉杂乱且抢眼。
3. **高亮与大块涂抹生硬**：“全部题目”和高亮章节采用大面积荧光绿块涂抹，缺乏留白与呼吸感。
4. **计数徽标单薄**：数字 0、1、5 孤零零展示，与目录名称紧挨。

---

## 核心美化方案

### 1. 统一为现代 Segmented Control（分段控制器）
- 将「知识点/解题方法/自定义」与「全部/初中/高中」两组筛选器统一重构为 Apple / Modern Clean 风格的 Segmented Control；
- 底层采用一致的浅冷灰微凹底槽（`#f1f5f9`，圆角 `9px`）；
- 选中项以白色微投影卡片悬浮呈现（`box-shadow: 0 1px 3px rgba(15, 23, 42, 0.08)`），排版工整，质感显著提升。

### 2. 彻底清除斑马虚线竖条
- 移除 `.library-directory-row-wrap.is-empty::before` 的斑马打孔竖虚线，保持树形结构的宁静素雅；
- 有题章节保留细致的导角主色指示条，悬浮与选中时柔和高亮。

### 3. 精致微胶囊 Badge 计数
- 章节题目数升级为微型圆角胶囊 Badge；
- 0 题时透明淡灰显示，不抢主视觉焦点；有题时浅灰底清晰对比；选中当前章节时联动高对比徽章。

### 4. 容器与新建按钮现代升维
- 左栏面板整体注入 `14px` 圆角与细腻柔和阴影（`box-shadow: 0 4px 20px -2px rgba(15, 23, 42, 0.05)`）；
- 「+ 按课本目录新建」升级为清爽的虚线浅底条，悬停响应淡翠绿微边框；说明文案升级为微浅灰气泡卡片。
