## 题有据 2.3.1 更新说明

### 更新亮点

1. **右键标签查看打标时间（仿 Eagle 风格）**：
   - 在 `/eagle` 题卡底栏或右侧属性栏的任意标签上**右键点击**，即可查看该标签是何时打上的（如 `14 天前 · 2026-11-11 19:20` 或 `2 年 3 个月前`）及来源，并可就地筛选、排除、按打标时长筛查、按时间排序或移除。
   - 悬停提示与题卡外观保持纯净，不额外堆叠时间文本；老题库升级后即可直接回溯历史打标时间。

2. **修复「改题干后丢标签」与全链路打标时间保真**：
   - 修复在 `/eagle` 编辑已入库题干保存新版本时未继承旧版正式标签的问题；
   - 撤销打标、原图 AI 转文字升级、重复题合并及标签合并均完整保留原始（或更早）打标时间。

3. **真实年份排序、打标/入库时间排序与标签时效筛选**：
   - 修复「最新年份优先」排序，改为自动提取题源与卷名中的真实年份；
   - 新增「最近入库优先」「最近打标优先」「最早打标优先」排序，以及「近 7 天 / 近 30 天 / 超过 30 天 / 超过半年 / 超过 1 年」等标签时效筛选（支持保存为智能文件夹）。

4. **筛选栏收口**：
   - 将「不排除已用」与「用题记录」从顶栏移入「筛选」展开栏的 `🕒 排除已用` 胶囊内，顶部工具栏更清爽。
