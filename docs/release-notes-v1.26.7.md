# 1.26.7：教材目录照着课本自己写；两个在设置页和题库里卡住老师的地方

## 一、教材目录可以照着课本自己写了

来自交流群的一条反馈：

> 「关于目录能不能自己根据教材目录来编写，现在根据标签模板生成的目录感觉还是不够细，
> 也不太自由」——「我是不是要求有点多了」
> 「对了，那个教材目录怎么设置，我没有搞懂」

**这条反馈说的是两件事。**

**① 目录只能整套套模板，不能照着自己那本书写。** 题库左栏的「教材目录」就是标签的层级树
（章 → 节 → 知识点），层级只能靠「应用系统模板」整套导入，或者一个个新建标签、一个个
设上级 —— 想按课本的目录来，就得手工敲几十上百个标签。这就是"不够细、不太自由"。

**② 入口根本找不到。** 目录摆在题库左栏，能改它的却是另一个页面（标签管理），那里也只有
"新建标签"。"怎么设置"这件事在界面上没有答案 —— 不是她笨，是没入口。

**做成什么样**：教材目录面板的标题下面多一个「＋ 按课本目录新建」。点开是一个框：把课本
目录**贴进来**（抄一遍、复制粘贴、拍照转文字都行），下面实时显示解析出来的树，确认了再
点「建好这份目录」—— 一次建好整棵。

- **认得这些写法**：`第一章 集合`、`1.1 集合的含义`、`1.1.2 外集`、`一、集合的概念`、
  `（一）集合的含义`；`（一）`和`（二）`认成兄弟（同一层），不是父子。
- **页码行、页眉页脚不算目录**：`第一章 集合 …… 1` 这种只取目录本身。
- **已有的同名目录直接接上**，不重复建（目录改过一遍再贴一次，不会变成两份）。
- **建完可以撤销**：整棵树一起撤；已经贴到题上的标签只停用，不会让题的标签凭空消失。
- 解析规则单独成文件、单独有测试，以后要支持别的课本格式（比如"§1.1""Unit 1"）
  改一个文件就行。

## 二、点「测试连接」一律报"设置状态读取不完整"

设置页（API 配置）拿**同一把尺子**校验每个答复：少一个字段、少一种类型，就报
「设置状态读取不完整，请重新读取设置后再试。」—— 这把尺子是为了挡住"答复缺一半"
的情况（半截答复会让页面显示错误的开关状态）。

问题是「测试连接」和「共用读题密钥」这两个接口的答复，**少了一个字段**：
`backlog`（题库里"还差几道"那个数字）。读取设置和保存设置都有它 ✓，测试连接没有 ✗。

于是：**点一下「测试连接」，不管连接通不通，一律报"设置状态读取不完整"** ——
老师根本看不出自己的密钥到底能不能用。

**改成什么样**：那两个接口现在和「读取设置」返回**完全一样的形状**（字段一个不多一个不少 ✓）。
另加一条自动测试：**设置页读的每一个答复，形状必须和「读取设置」一样**。

## 三、「AI 标签记录」弹出 "Unexpected token '<' ... is not valid JSON"

题卡右栏那个「AI 标签记录」，点开是空白的，还带一句英文报错。

原因：接口在**这道题属于某个题组**时崩了 —— 也就是**书里的题**（一本书的每一章是
一个题组）。题组的字段叫 `title`，代码里写成了 `.name` → 接口 500 → 生产环境返回
HTML 错误页 → 前端一解析就是那句英文。

**改成什么样**：改用 `title` ✓。另加一条自动测试：**一道题属于某个题组时，记录照样
读得出来**，而且答复必须是 JSON。

顺带说一句：500 返回 HTML 错误页这件事本身也该改 —— 接口出错时应该回一句人话
（JSON），而不是让页面显示英文的解析错误。这次先把根上的洞补了。

## 四、怎么验的

- 后端 `manage.py test core`：全过（新增：一次建一棵树、同名标签接上不重复建、整棵树能撤销；
  每个答复形状一样、题组里的题能读记录）；
- 前端 `node --test test_*.js`：全过（新增：课本目录的解析器）；
- 真机点了一遍：贴一段课本目录 → 预览 5 个节点 → 建好 → 目录面板里出现新的一章，
  提示"教材目录建好了：新增 4 个节点"。
