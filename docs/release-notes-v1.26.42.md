# 1.26.42：回收站里的题，也能对回原书了

上一版把「怎么指出一道题」收成了一套说法，结果面板、回收站、找题三处通用。
这一版把**回收站那一处补齐**。

## 一、原来是什么样

回收站里那批旧误建卡，多数**既没有章节名也没有小节**。界面上就只剩一句「第 1 题」。

问题是：**这类教辅里「第 1 题」在书上有上百处**（老师那本 771 题的书里就有 205 道）。
光这一句，老师拿着它回原书根本翻不到那道题。

## 二、现在是什么样

这些题会带上**原卷页码**，写成：

> 第 167 页 · 第 1 题

跟结果面板里那一套写法一模一样 —— 同一道题，在哪看到都是同一句话。

有章节名的题不受影响，还是写「章节01 · 公式法 · 例 1」。

## 三、顺带把页码算法收到一处

结果面板和回收站现在**共用同一个页码计算**（从题目在原卷上的位置算起，按书上的页码报）。

理由很实在：同一道题在两个地方算出两个页码，比只写题号更让人信不过。

## 四、怎么验的

- **19 条「改坏了就废」的验收检查，全部被挡住。** 这次新加的两条是：
  把回收站的页码去掉、把回收站改回只写题号 —— 两条都得被测试挡住。
- 全套检查全绿：前端测试 151 项、后端测试 2446 项、桌面外壳测试 147 项。

**真机验在老师真题库的一份副本上做，老师的真库一个字没动。**
