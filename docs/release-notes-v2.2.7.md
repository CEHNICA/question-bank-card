## 题有据 2.2.7 更新说明

### 更新亮点

1. **修复工作台生成答案与标签建议失败问题**：
   - 修复单题点击「AI 生成解析 / 补充推导」在全局开关关闭或 `assistant` 默认状态下直接报错无法排队的问题，改为检查实际 API 就绪状态并在卡片内直接提供 **一键改用已填密钥服务并测试**、**一键验证连接** 与 **前往设置** 按钮；
   - 修复右栏点击「生成标签建议」在未开启全局开关或未测试连接时闪现误导提示后失败的问题，改为卡片内直接提供一键开启/一键测通入口；
   - 上游 API 返回非 200 错误时，接口会脱敏提取并展示具体错误原因，排查密钥、模型 ID 或余额问题更直观。

2. **精简并理顺「设置 → API 配置」页面**：
   - 统一顶部进度条与下方三步卡片名称；已填写 MiniMax / 魔搭 / 硅基流动等密钥时，第 3 步会自动弹出「一键改用并开启功能」引导；
   - 将模型 ID、Base URL、Thinking 等低频技术参数以及 DeepSeek / 豆包 / 自定义独立密钥卡收纳为可展开高级区，默认界面只保留核心选项，不再杂乱。

3. **名称规范化：「AI 语义推荐」改为「AI 标签建议」**：
   - 工作台右栏对应卡片统一命名为更直观的「AI 标签建议」。
