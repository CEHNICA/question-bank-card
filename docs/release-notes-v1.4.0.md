# 题有据 v1.4.0（草稿）

这一版集中解决“慢”和“绿卡不一定对”两个问题。同样 5 份真实试卷（数字 PDF、扫描件、带学生作答的扫描件、手机照片），处理总时长从 26 分钟降到约 4 分半；高考卷从近 6 分钟降到 38 秒。

## 更快

- **一个账号也能同时读多道题**：MiniMax 账号默认同时处理 6 个请求（原来 1 个），遇到限流会自动为该账号减少并发。
- **少读一遍**：每道题先拿 MinerU 自己识别出的文字做旁证，和 AI 誊录逐字一致就不再重复识读，只有对不上时才请复核模型。
- **不再被个别慢请求拖住**：一次请求 18 秒没有回应就补发一份，谁先回来用谁。
- **调整范围后的重读不用排队**：处理整本书时，已完成任务里的单题重读也会立刻进行。
- 读题时按实测速度显示“约还需多久”。

## 更准

- **两套引擎互相印证**：绿卡新增“两种引擎一致”——视觉模型与 MinerU 文字逐字相同。两次识读有分歧时，先用 MinerU 文字逐处裁定，再不行才请裁决模型，并把 MinerU 文字给它参考。实测修正了循环小数读错、把原卷“蒋铭祖”改成“赵爽”、给原卷补字（“相交点 O”→“相交于点 O”）等被旧版当作绿卡的错误。
- **照抄原卷**：错字、漏字、特殊字母顺序与大小写一律照原样誊录；只有原卷印了 ▱ 符号才写 ▱。

- **两次读法一致也会再核对**：同一个模型读两遍可能重复同一个错误（把 x³ 读成 x²、把“销售定价”读成“销售单价”）。两次一致但与 MinerU 在某个字符上不同时，会单独问一次“原卷印的是哪一个”；拿不准就变成黄卡，并直接写出是哪一处、MinerU 读成什么。

## 切题更完整

- 不再把“注意事项”里的 1、2、3……切成题卡。
- 能补回首题丢了点号（“1 设 z=…”）、扫描裁掉首位数字（“9.”其实是 19）、只剩“（本题满分 6 分）”、“14 如图”这类缺点号的题号。
- 大幅减少不必要的“确认资料结构”提示；分式分母不再被答题空白裁剪切掉。
- 全国卷的“（二）选考题”“[选修 4-4：坐标系与参数方程]”不再被抄进第 21、22 题的题面。
- 拍歪的照片里，上一题最后一个选项和下一题挤在一起时，不再把选项切给下一题；跨过栏线的字不再被切掉最后一个字。

## 配图与审核

- 几道题的图印在同一行时（印在第一题或最后一题下面都可以），按从左到右分给对应的题并提示核对（旧版可能把别的题的图配给最后一题）。
- 别的题的识读认为“这张图是第 N 题的”，而第 N 题已经有自己的图或题面没提到图时，会提示人确认，不再直接变绿。
- 选择题下方并排 4 张图且没有选项文字时，自动作为 A–D 选项图。
- 减少“没有发现图像提示词”的误报。
- 选择题等横长截图放在题卡上方，接近原卷大小，便于逐字对照；选项按实际宽度排版。

## 稳定性

- MinerU 上传、下载或接口遇到网络中断、超时、服务器临时错误会自动重试；MiniMax 过载（HTTP 529）也会重试。
- 处理整本书时遇到限流不会越跑越慢：排队中的请求不再被重复发送，被限流的账号在恢复正常后逐步找回并发。

## 升级说明

覆盖安装即可，题库、原卷和 API 配置保留，无数据库迁移。已有题卡不会被重新识读；新规则对新任务和之后的重读生效。
