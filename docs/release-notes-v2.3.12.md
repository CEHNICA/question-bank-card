## 题有据 2.3.12 更新说明

### 更新亮点

1. **大文件夹秒开与定位码复制反馈**：
   - 修复题库工作台目录树每次渲染重复计算上百次教材章节归属的问题，配合 `localStorage` 自包含缓存、单遍标签/未分类索引与 `bulk=1&limit=500` 按卷加载，500+ 题大文件夹切换耗时大幅下降；点击复制题目定位码按钮新增按压变暗与「✓ 已复制」成功态反馈。
2. **社区大包上传、关闭二选一与上传记录中心**：
   - 桌面端与社区同步 `role` 权限，作者/管理员上传不再受 100 题、250 图、8 MB 原卷及 15 MB 限制（单包放宽至 95 MB）；上传关闭时可选择「取消上传」或「后台继续」，并在顶栏、右下角浮动条及上传记录中心实时查看进度与历史。
3. **OneNote 静默读取与 C 盘防膨胀止血**：
   - Agent 查看 OneNote 笔记步骤默认静默通过 COM 导出，不再把 OneNote 窗口强制切到前面；修复后台自动补标签遇到失败/多图题目时死循环重排并重复写大快照的问题；彻底移除工作台设置里残留的自动备份开关并自动清理旧自动备份压缩包，同时滚动保留最近 3 份升级前快照并修复浏览器 `Default` 子目录缓存清扫。
4. **软件启动弹出置前与官网同步加速**：
   - 修复启动画面关闭后主窗口停留在任务栏、不主动弹出到最前的问题；官网下载与版本清单接入 Cloudflare R2 全球缓存与发布自动预热，提升客户端更新与官网安装包下载速度。

### 验证范围

- `ruff check`、`ruff format --check`、`npm run lint`、前端全部 `node --test`、社区 `npm test` / `tsc`、根目录 `unittest` 与 Django `core` 单元测试全部通过。
