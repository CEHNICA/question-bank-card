# 1.21.0：分级标签与就地校正

本版为本地验收版。安装包不会自行安装；当前安装、个人题库和密钥不会被这次验收修改。验收全部使用独立虚构题库。

## 给题目的标签换得更具体

1. 在正式题库选中题目。绿色边框对应右侧详情。
2. 将鼠标停在题卡或详情中的标签名称上；键盘聚焦或触屏点击也可以打开。
3. 浮层注明正在修改的题目和原标签。点击箭头只浏览，点击标签名称立即替换这一个标签。
4. 向下可以细化，向上可以概括。选原标签不保存。同题其他标签保持原状；误改可以撤销。

例如，题目原贴“二次函数”，可以改为“二次函数的最值”，继续细化为“二次函数在闭区间上的最值”。也可以直接保留“二次函数”。新增子标签不会让原标签失效。

浮层内可以连续浏览，鼠标进入浮层后保持打开。按 Esc 或点外部关闭。触屏和键盘使用同一套明确按钮，不要求悬停才能操作。

## 分级目录与个人分组

上下级表示数学概念的归属。例如“正方形”可以同时属于“矩形”和“菱形”，它始终是同一个标签。知识点和解题方法各有自己的上下级。

“课堂复习”“我的收藏”等个人分组只是整理方式。把标签放进两个分组不会重复造标签，也不会把两个分组变成知识父级。

进入“标签管理”可以浏览知识或方法层级，添加子标签，增删父级或移动其中一条父级关系。增加父级会保留其他父级；移动明确替换选中的那条关系。系统会拒绝循环。

删除父标签时保留子标签；没有其他父级的子标签成为顶级。使用中的标签删除前会展示影响题数，历史支持受保护的撤销。

“相关方法”只表示可能有关的方法，不代表题目解析已经采用。使用此入口会打开添加操作，不会把知识点替换成方法。

## 按上下级找题

选择“二次函数”会找到直接贴该标签的题，也会找到贴“二次函数的最值”等后代标签的题；同题多条命中只计一次。只贴“二次函数”的题不会自动出现在某个具体子标签的筛选中。

全部、任一和排除标签均采用这条规则。刚改完标签的题如果不再符合当前筛选，题卡会暂时保留并说明原因，便于继续阅读；改变筛选或主动刷新后才移出。匹配数量仍按实际结果计算。

## 模板与 AI

目录保持原状；需要层级模板时，在标签管理中明确预览并追加。模板复用已有身份，不覆盖改名和个人分组。也可以从空目录建立，不强制套用模板。

AI 标签仍只提供待核对建议。它可以选择有依据的具体标签，也可以停在较宽主题；提出新标签时给出建议父级，用户可以修改父级或明确作为顶级再采纳。方法建议仍依赖题库当前采用的已保存解析，不采用未保存草稿。

目录修改、浏览、替换和撤销都不会自动调用 AI。已采纳或拒绝的建议保留处理状态；新生成记录保存当时目录快照，题卡展示当前标签名称与归属。

## 保存保护

正常保存和响应丢失后的核实使用同一个请求编号，不重复替换或造标签。两个窗口同时修改时，过期操作会被拒绝。撤销先检查后续变化，避免覆盖后来保存的内容。

本轮不包含教材章节映射、解法步骤链或学习状态。正式验收结果与限制以同目录的验收记录为准。
