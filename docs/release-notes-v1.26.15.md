# 1.26.15：API 配置这一页重新排了一遍

老师看了一眼设置页，说：

> 就当前的这个API界面，我就感觉不好看

我先把这一页的问题数了一遍，都是真的：

1. **同一个信息说了四遍** —— 上面一行"共保存 0 个密钥"、卡片右上角"已保存 0 个"、
   勾选行里的"未存密钥"、卡片里的"暂无已保存密钥"；
2. **步骤编号像一个贴纸** —— 绿圆点浮在标题上，跟文字挤在一起；
3. **四张服务商卡片长得一模一样** —— 看不出哪张是"正在用的那家"；
4. **大半篇幅是重复的输入框和灰色小字** —— 页面 2631px 高。

## 改了什么

**一、顶上先告诉你"配到哪一步了"**

```
① 云端切题 还没配   ② 看图读题 还没配   ③ 生成标签和答案 还没配
```

三步各一颗点，配好的那一步是绿的。不用往下翻就知道还差哪一样。第三步（生成标签和
答案）的状态由答题面板自己报上来。

**二、服务商卡片改成一行式**

```
MiniMax API Key          新的 Key（留空就不改）
填写可用于视觉模型的 Key [粘贴 MiniMax 开放平台里复制的 API Key ]
已保存 0 个                模型名称   [MiniMax-M3]
                           □ 我同意这一次测试
                           [ 测试连接 ]
```

左边是"是哪家、什么状态"，右边是"要填什么"。标签和输入框挨着了（以前中间空一大块）。

**三、去掉重复**

- 空的那句"暂无已保存密钥"删了 —— 状态已经写在标题右边；
- "共保存 N 个密钥"和下面那句说明合成一行；
- 步骤编号从浮着的绿圆点改成贴着标题的圆角徽章；
- 勾选行像几个可点的卡片，选中的那家有绿色高亮和一圈光晕。

## 没动的东西

**一个 id 都没改**，脚本照旧跑；密钥的保存、加密、查看、删除、测试连接一个字没动；
弹窗里那份配置（从题库或答案编辑器打开的）也用同一套样式，两处长得一样。

弹窗里那条吸底的保存栏**保持原样** —— 那里它本来就该跟着走；只有平铺在设置页上时
才改成普通一行操作。

## 怎么验的

- 前端 134 条、后端 2295 条全过（新增断言：三步进度条在页面里、重新排版是独立样式
  文件、空列表不再塞占位句）；
- 真实页面看过：进度条 ✓、步骤徽章 ✓、一行式卡片 ✓、勾选行高亮 ✓；
- 页面从 2631px 缩到 2435px。
