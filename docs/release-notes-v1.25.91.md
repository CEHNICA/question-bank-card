# 1.25.91：一颗灰着的按钮，一句说不清的话

老师 10 月 20 日发来一句话：「这个 AI 建议标签好像打不了标签了。」

查下来，**功能没坏**。坏的是「说不清」。

## 一、到底发生了什么

时间线是从服务器日志和本机的连接记录里倒出来的：

- 10 月 16 日 22:56，老师在设置里测通过一次连接；22:57 又保存了设置、并共用了一次读题侧的密钥。
- **共用密钥 = 换了一把新钥匙。** 软件的规矩是：换过凭据，之前那次「测通过」的结论就不作数了，要重新测一次。这条规矩是对的 —— 那次通过测的是上一把钥匙。
- 之后老师没有再测。于是从 10 月 16 日晚上起，「已测通」这个状态一直是不成立的。
- 10 月 20 日 17:14 老师发来那句话；17:35 这次测试才真正做成功（用的是合成题和合成图，没发老师的卷子）。

所以那颗按钮灰着是**对的**，错的是**灰着的时候只写了一句笼统的话**：

> 需要先到「设置 → API 配置」里配置并测试通过，才能用这一项。

这句话把三件不同的事说成了一件：老师看到的是「我还没配好」，其实他只要**再点一次测试**。看见一颗灰按钮加一句「配置并测试通过」，自然理解成「功能坏了」—— 老师的原话就是这么来的。

还有一层：设置页和题库页是同一个窗口的两个页面。从设置页测通了回到题库页，题库页会重新读一次状态；但只要不刷新页面，那颗按钮就一直按旧状态画着。

## 二、这一版改了什么

1. **按钮改名叫「批量生成标签建议」，旁边常驻一行字。**
   原来的「AI 建议标签」看着像**贴标签**的按钮 —— 老师以为贴不上就是功能坏了。现在名字里写明是「生成建议」，旁边那行字直接写差哪一步、去哪做。
   这行字是**常驻**的，不靠鼠标悬停：悬停说明看不见就等于没说。

2. **三种「用不了」分开说，不再一律写「配置并测试通过」。**

   | 差哪一步 | 旁边的提示 | 悬停说明 |
   |---|---|---|
   | 功能没开 | 这项功能没开：到「设置」里打开 | 题库里没有开启「AI 生成标签建议」这项功能，要到「设置」里打开才能用。 |
   | 还没填密钥 | 还没填 API 密钥：到「设置 → API 配置」填上 | 还没填 API 密钥。到「设置 → API 配置」里填上密钥、选好模型，再点一次「测试连接」，这一项才能用。 |
   | 填了但没测 | API 还没测过：到「设置 → API 配置」测一次 | 密钥填好了，但连接还没测过（换过密钥或改过模型都要重测）。到「设置 → API 配置」里点一次「测试连接」，这一项就能用。 |

   题库页现在能分清这三种情况 —— 以前它只知道「能不能用」，不知道「差哪一步」。

3. **单题卡上那颗也改了名**（原来也叫「AI 建议标签」），并补上悬停说明 —— 那颗原来一个字说明都没有。

4. **修掉待办折叠条上的负数。** 原来写着：

   > 题库里没有入库答案的是 437 题，其中 **-37** 题已有 AI 初稿，可先保存。

   那是拿**当前筛选下**的题数去减**全题库**的题数，两个口径混着减就减出了负数。现在三个数都按全题库算：

   > 题库里没有入库答案的一共 807 题（全题库的数，不受筛选影响），其中 333 题已经有 AI 初稿、可以先保存下来；剩下 474 题连 AI 初稿都没有，才需要让 AI 补。
