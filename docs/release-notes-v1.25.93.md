# 1.25.93：同一个标签，在几个地方长得不一样

老师 10 月 20 日晚上发来一句：

> 标签系统的界面感觉还是有问题。

问下来是「整理勾选题的标签」那个窗口，毛病是「同一个标签在几个地方长得不一样，操作也不一样」。

## 一、到底发生了什么

查下来，根子不在样式，在**颜色只有一处真算了**。

代码里那条规则（1.25.64 定的）是：

> 这颗标签自己设的颜色 → 同型祖先的颜色 → 按类型/学段从调色板取一个

但**只有教材目录真的去算了**。标签管理、标签选择窗口、题目详情、题卡这四处，各自只看「这颗标签自己有没有设颜色」。

而老师的标签几乎都没设过颜色 —— 302 个标签里只有 17 个章设了。于是同一个标签在几个地方长成几个样：

| 在哪儿 | 原来长什么样 |
|---|---|
| 教材目录 | 蓝的 / 绿的（算过） |
| 标签管理列表 | 灰绿的（没设色就是灰的） |
| 标签选择窗口 | 灰的 |
| 题目详情 | 灰的 |
| 题卡 | 一律绿 |

代码里那行注释写着「目录、筛选条、详情里的颜色都是同一根」—— **注释是这么说的，代码没这么干**。

## 二、这一版改了什么

1. **颜色只算一次。** 规则搬到共享的一份代码里（标签管理页在另一个文件里，也得用同一套），上面五处都调它。同一个标签，现在在六个地方是同一个颜色。

2. **形状也统一。**

   | 是什么 | 长什么样 | 出现在哪儿 |
   |---|---|---|
   | 一颗标签（列表里） | 彩色圆点 + 名字 | 标签管理列表、教材目录里的子标签、标签选择窗口的那一行、标签地图 |
   | 一个章节 | 左边一条色条 | 教材目录的章根 |
   | 贴在题上的一颗标签 | 淡底 + 同色边 | 题目详情、题卡、标签选择窗口里"已经在这道题上"的那几颗 |

3. **题卡和详情终于一样了。** 题卡上原来所有标签一律绿（跟标签自己的颜色无关），详情里原来一律灰。

4. **选择窗口里的话改成人话。** 原来那三句：

   > 全部都有 / 部分有 2/3 / 全部没有

   说的是「这个标签」怎么样，读起来像库里没这个标签。改成：

   > 3 道都有 / 3 道里有 2 道 / 3 道里都没有

   说的是这次要整理的那几道题。

5. **选择窗口左栏按类型分组。** 原来二十来个顶层标签平铺着排，知识点和解题方法混在一起，只能靠名字前缀去分；现在分成「知识点 / 解题方法 / 自定义」几组，跟标签管理页一致。

6. **实机复验时又逮到一颗漏网的。**「平面向量的应用」既没有上级、又同时属于初中和高中，只能去调色板里取色；而那个调色板写的是「初中绿、高中蓝」，**正好跟老师自己给章设的颜色拧着来**（老师给初中章设的是蓝 `#477a9e`、高中章设的是绿 `#387f72`）。结果 204 个知识点里有 1 颗是绿的，混在 99 颗蓝的初中知识点里。

   现在改成：找不到上级时，先去问「同学段、同类型里那些顶级的章自己是什么色」，跟着它走；写死的那一份也跟老师的选择对齐。老师改某一章的颜色，底下那颗标签也跟着变。

## 三、验证

- 前端 `node --test frontend/test_*.js`：**128 项全过**（新增 1 项：标签颜色）
- 新测试 `frontend/test_library_tag_color.js`：
  - **量的是真代码画出来的颜色**，不是规则文本 —— 窗口里"已经在这道题上"的那几颗，实际写进样式的颜色跟共享函数算出来的一致；
  - **逐处**验每一处调的是共享的那个函数（只数调用次数的写法踩过坑：改坏其中一处而别处照旧，次数不变，测试照样绿）；
  - 老写法「只看标签自己有没有设颜色」不许回来。
  - **9 条变异全部被挡住**：题卡那处退回老写法 / 选择窗口那一行退回老写法 / 标签管理圆点退回老写法 / 题卡 CSS 退回一律绿 / 状态字退回「全部没有」/ 拆掉「跟同学段顶级章走」这一步 / 调色板改回「初中绿、高中蓝」/ 方法那色换掉 / 阶段认错。
- **实机复验**（临时副本，8770 端口 + 真实题库的只读副本，不碰用户数据）：同一个标签在**六处**都是同一个颜色 ——

  | 在哪儿 | 颜色 |
  |---|---|
  | 教材目录的子标签圆点 | `rgb(71, 122, 158)` |
  | 标签管理列表的圆点 | `rgb(71, 122, 158)` |
  | 标签地图上的圆点 | `rgb(71, 122, 158)` |
  | 标签选择窗口那一行的圆点 | `rgb(71, 122, 158)` |
  | 更多筛选里那一颗 | `rgb(71, 122, 158)` |
  | 题卡上那颗标签 | `#477a9e` |
  | 题目详情里那颗标签 | `#477a9e` |

  全库 302 颗标签算完只剩四种颜色：初中知识点 99 颗蓝、高中知识点 103 颗绿、解题方法 58 颗紫、历史标签 39 颗灰 —— 没有一颗是「跟别处不一样」的。

  同一个标签在几个地方长得不一样这件事，改完了。
