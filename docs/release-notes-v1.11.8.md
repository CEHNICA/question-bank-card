# 1.11.8：简化识读与密钥设置

“已核对，采用此读法”简化为“采用此读法”，采用操作只转为文字题，不冒充人工审核。原卷裁片只显示在左侧，右侧保留识读结果；原图题的组卷和导出内容不变。

修复原图题空题干被误判为整段缺文、把正常识读结果整段标黄的问题。文字题中真实的补充差异默认折叠，按需展开查看；识读记录不再固定宣称存在两位或三位读者。

新增“设置 → 读题服务 → 二次 AI 识读对比”开关。关闭后每题只识读一次，不触发第二次比较或第三次裁决；保留取消、重新识读、采用与入库。旧配置默认沿用此前行为，本地用户可按自己的选择关闭。

“保存密钥”和每家服务的“删除密钥”分开。删除确认只处理对应服务，不会保存或清空其他尚未提交的输入。

这是先供用户检查的本地版本。隔离验收使用模拟识读结果和虚构测试密钥，不证明实际云服务的准确率或可用性。
