# 1.26.13：看图读题这一段也有测试连接了

老师在设置页问：

> 这个没有测试连通性吗

指的就是「勾一家看图读题服务」那一段。之前**只有「标签与答案」那一段有测试按钮** ——
读题这边填了密钥，只能等真的读一份资料才知道能不能用。

## 现在

在「勾一家看图读题服务」的勾选行下面，多了和答题那边一模一样的一套：

```
□ 我同意这一次测试（会向服务商发一张软件自己画的合成图）
[ 测试连接 ]
```

- 测的是**你勾的那一家**（魔搭 / MiniMax / 硅基流动）；
- 发的是**软件自己画的一张图**（白底两个黑点），问模型图里有几个点 ——
  **不发你的试卷**，不带任何题库内容；
- 密钥用的是**已经保存的那一份**（所以要先「保存读题密钥」再测）；
- 每测一次要重新勾一次同意（和答题那边一样）。

## 会看到的几种结果

| 结果 | 说明 |
| --- | --- |
| 连接成功 | 这家的密钥能用，模型也能看懂图片 |
| 密钥没通过 | 这家服务商不认这串密钥（复制少了、有空格，或过期） |
| 额度用完 / 请求太频繁 | 稍后再试 |
| 服务商拒绝了请求 | 多半是模型名不对，或账号没开通这个模型 |
| 有回应但没数对点 | 这个模型看不懂图片（是纯文字模型），或还没开通多模态 |
| 连不上 | 网络不通或地址被挡住 |

**MinerU 没有这一项** —— 它的官网没有公开的 Token 验证接口，保存成功就表示已配置，
实际能不能用要看切题任务的返回。这句话在设置页上也写着。

## 顺带修的一处

「模型名称」那个标签在窄栏里会被挤成两行（"模型名 / 称"），改好了。
