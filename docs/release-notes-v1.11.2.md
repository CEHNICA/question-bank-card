# 题有据 1.11.2：设置更直接

当前为本地版本，未推送 GitHub、未发布新安装包；Releases 仍以下载页标注的正式版本为准。

- **打开设置就能用。** 主设置页直接分为读题服务、标签与答案、题面与显示、帮助、关于，不再先显示空页面或打开设置抽屉。
- **标签与答案不用再找弹窗。** 功能开关、生成时机和“由谁生成”直接显示在同一页，`/settings#ai` 可直达；选择独立 API 后才展开服务配置。
- **移除不必填写的选项。** 不再显示 MiniMax 会员档位和同时读题数量，后台保留已有值与自动调整机制。
- **离开前处理未保存改动。** 标签与答案设置有未保存内容时，提醒继续设置或放弃更改；读题模型保存失败可重试，不把未保存状态当作保存成功。
- **密钥保存失败可正确重试。** 更换密钥失败后提示重新填写，删除密钥失败后保留删除勾选，避免再次保存时悄悄变成保留旧密钥。
- **保留原来的选择。** 本次界面调整不重置已保存的开关或密钥；题前出处整理、中文引号的默认开启状态不变，标签、参考答案与新题自动处理仍默认关闭。

本轮未实测付费 API 的数学能力、真实计费或 MinerU 云识读恢复；助手模式仍需当前助手领取并写回任务，不会自动唤醒桌面助手。最终回归与安装结果以本地验收为准。
