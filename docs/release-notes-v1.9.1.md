# 题有据 v1.9.1

审核时更顺手的一版：已通过的题可以用键盘展开，J/K 连按不再乱跳，专注模式只在真正看得到的题上亮起。

## 展开已通过的题

- **O**：展开 / 收起当前这张已通过的题。**Shift+O**：已通过的题全部展开，或全部收起。
- **J/K 自动展开**：用 J、K 跳到一张已通过、收起的题时，它自动展开；离开时再收回去。自己点“展开”、点那一行或按 E 改字打开的题，不会被收回。
- 不想要自动展开，可以在“设置 → 常用 → 审核界面”把“J/K 自动展开”关掉，选择记在这台电脑上。
- 快捷键说明（按 ? 打开）里加上了这两个键。

## J/K 和专注模式

- **J/K 连按不再乱跳**：以前按得快时，上一张还在滚动中，下一次按键会从屏幕最上面那张算起，看起来像弹回去了。现在接着从刚跳到的那张往下走。
- 跳到的题停在工具栏下方，不再多空出一截。
- **专注模式更准**：一张题卡大半被工具栏挡住、只露出选项和按钮时，不再算“正在看”，别的题也不变暗。刚展开、下半截还在屏幕外的题照常亮着。

## 其他

- 题卡上的“原卷截图 · 点击放大对照”现在是一个按钮，点哪里都能打开放大对照（以前偶尔点了没反应）。
- 配图归属的小菜单：“取消”移到标题右边，按 Esc 也能取消；“与本题无关”单独占一行，不再和题号挤在一起。
- README 重写：这是什么、一份试卷怎么变成题库、为什么值得信任、适合谁、完全免费的配法。

## 升级

已经装了题有据的，下载新的安装包直接覆盖安装即可，题库和设置都会保留。也可以运行：

```powershell
irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
```

它会下载最新版、核对 SHA-256、先备份题库，再静默安装。
