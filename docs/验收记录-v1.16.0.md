## 真实界面与数据库验收

源码与实际 `QuestionBankCard.exe` 均使用全新隔离的 schema 0020 旧版数据库升级到 schema 0021。104 道虚构旧题、原有题文和其他原始字段逐项保持不变，六色回填通过。

使用真实鼠标和键盘验证大框包含小框的候选选择、0–3 像素抖动、两种缩放倍率、框内部选择、Esc 回滚、右键平移、边缘缩放、键盘细调和跨页草稿撤销。成功保存后页码和缩放保持，人工内容不丢失。

补题、跨页合题、已入库题拆分、重新打开后的撤销、审批与发布不自动恢复均通过。两个窗口持有不同布局版本时，过期提交被拒绝，草稿保留。人为丢弃服务器成功合题后的响应，界面通过原请求编号查回同一记录，只产生一次写入和一道结果题。

一百道题的完整配色、列表计数及桌面、650 像素窄屏显示均检查。全部布局流程没有隐式 AI 请求，没有新建 RegionRead 或 LibraryJob。验收结束后仅终止自己启动的测试进程，隔离服务器均已停止。

复验入口：`python tools/check_question_layout_browser.py --run`。冻结程序复验使用 `--bundle packaging/dist/QuestionBankCard`。证据分别保存在 `tmp/layout-source-accepted` 和 `tmp/layout-frozen-accepted`。
