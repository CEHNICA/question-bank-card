# 正式题库旧标签迁移说明

正式目录升级时会先建立稳定身份的知识点、解题方法、自定义标签和分组，再按以下规则迁移旧题卡中的标签。迁移保留原始名称及来源快照，不修改题面、答案、审核结论或入库版本。

| 旧数据情况 | 迁移结果 | 是否参与普通标签筛选 |
|---|---|---|
| 与新目录规范名称或唯一别名完全对应的人工标签 | 建立正式关联，记录旧版人工来源 | 是 |
| 不能唯一对应细目录的人工标签 | 放入“历史标签”组，标为待核对；人工确认后可合并到正式目录 | 否，直到人工整理 |
| 明确标记为未核对的旧 AI 标签 | 转成 AI 候选，不写入正式关联；旧候选可逐条采纳或拒绝 | 否 |
| 来源不明的旧标签 | 作为“旧标签待核对”保留原始快照 | 否 |
| 旧版任务或撤回版本中的 AI 标签 | 保留为历史候选，不能直接采纳 | 否 |

名称只在规范名称或别名**唯一匹配**时自动映射；宽泛名称、多义词、同名歧义不猜测。人工采纳会新增正式关联并保留 AI 来源、理由、依据和适用范围。目录合并前会显示影响题数；合并保留旧名称为别名，撤销时校验后续目录和题目标签版本。

升级完成后，在正式题库打开“标签管理”，点击“导出旧标签映射”即可导出本机实际迁移结果。报告仅含旧标签名、目标标签、处理状态和题数，不含题干、图片或题目编号。它会区分已映射、旧 AI 待核对、来源不明待核对和无法映射的历史标签。

迁移是可重复保护的数据库升级步骤；重新导出报告不会再次迁移或改动题库。
