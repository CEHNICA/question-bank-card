# 题有据 1.11.3：把练习带进 Word

当前为本地版本，未推送 GitHub、未发布新安装包；Releases 仍以下载页标注的正式版本为准。

- **导出真正的 Word 文档。** 本地生成 DOCX，保留可编辑文字、表格、图片与支持的 Word 原生数学公式，无需安装 Pandoc 或 Office。
- **题目和答案分开发。** 可选题目卷、答案与解析卷、题目卷附答案；也能下载 ZIP，包含两份独立 Word 文档。打印与另存 PDF 继续使用浏览器，按 A4 排版。
- **调好排版，下次继续。** 字号可选 12、14、16 磅，解答题留白可选不留白、适中、较多，姓名班级栏可开关；这些选择随命名草稿保存和恢复。默认 12 磅、不额外留白、显示姓名班级栏，旧草稿沿用此前的答案打印选择。
- **导出结果说清楚。** 等待题目完整加载再导出；缺题、缺图或不支持的公式会明确提示，生成失败后可重试，不静默漏掉内容。
- **教学同步入口。** 草稿教学介绍排版和导出，仍只认识入口，不保存真实草稿或下载文件。本轮没有新增 CLI/MCP 导出命令。

AI 标签与参考答案仍默认关闭；明确选用 AI 参考答案时保留“未核对”标记，导出不生成新答案、不调用云端 AI 解释失败。最终文件兼容性、回归与安装结果以本地验收为准，本说明不宣称付费 API 或云识读已完成实测。
