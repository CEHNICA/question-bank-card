# 1.26.34：软件可以由 AI 助手来干活了；改题面这件事，最后还是老师说了算

老师的原话：「下一步的建议就是将这个软件可以由 ai agent 控制。你有什么建议」

## 一、这里头分清了两件事

老师提的是「让 AI agent 控制这个软件」。但「控制」如果不管住，就会出这种事：
助手替老师改了题面，老师打过的勾被弄没了，题库里那版也跟着变了 ——
过一阵老师回头看，还不知道这字是谁改的。

所以这一版把两件事分开了：

- **干活**：助手领活、看原卷、选标签、写答案初稿、交改法。这些助手自己干。
- **定稿**：改题面、打勾、入库。这些还得老师点头。助手不能自己按。

## 二、助手怎么领活

助手一次领一批活，每道活带着一个**到期时间**（30 分钟）一起领走。

- 助手中途没了（断网、崩了、关掉了），这道活**自己回到池子里**，别的助手能接着领。
- 别人还占着、租约没到的活**抢不走** —— 不会两个助手干同一道题。
- 干不完的可以**主动交回**池子，别占着。

以前助手是「自己去翻有哪些活」，两个助手会翻到同一道题；现在是有借有还。

## 三、助手改「已经入库」的题，改不动

分两种情况：

- **还没入库的题**：照旧走原来的改字流程。那本来就是导入流程，老师会逐题核对原卷，
  不存在「助手偷偷改了」的问题。
- **已经入库的题**：**不能直接改**。直接改会把老师打过的勾弄没，而且看不出是谁改的。

已经入库的题，助手的改法先交成**提案**：

1. 助手交一份提案。**题面一个字不动。**
2. 老师在题库页「助手工作台」里看到这条，看到「原来是什么 → 改成什么」。
3. 老师点「采纳」：题卡这才改成助手提议的样子，卡上留一条提醒
   「助手 X 改了题面，请对照原卷核对后再通过」，并回到「待核对」。
4. 老师对照原卷点「通过」，题库才更新。

**不自动通过、不自动入库。** 「只有核对过原卷的题才入库」这条地基不动。

**不采纳也要记下来。** 同一个助手再提一模一样的改法，会被**直接拒掉**，
并把老师的理由原话带上 —— 不是提醒一下，是真的不收。助手随时能问
「刚才那条被否了吗、为什么被否」。

## 四、题库页里多了一块「助手工作台」

**不是新页面**，是题库页里的一块。理由很简单：老师每天就在题库页里干活，
让他为助手的事再开一个页面，多余。

这块上面一屏能看完：

- **待核对几条**：题面改动、标签、答案各多少。
- **谁在干活**：哪位助手领着哪几道活、领了几次、还剩多久到期。
- **采纳 / 不采纳各多少次**。

每条待核对的改动都写着「原来是什么 → 改成什么」，老师在那一行点「采纳」或「不采纳」。
没东西的时候这块是收起的，不占地方。

## 五、助手能问「老师此刻在哪」

助手问一句就能知道：老师正在看哪道题、有没有没保存的改动。

老师正在改的那道题，助手绕开：既不去领它，也不去提改法。

## 六、没给助手开的权限

- 不给删除题卡、撤回入库、改标签目录的权限。
- 不做「无人值守自动通过 + 自动入库」。
- 不给助手直连数据库的后门。
- 助手交上来的东西，一律先落到「待核对」，由人点头。

## 七、真机验过

**在哪验的**：老师真题库的一份副本 —— 原样拷来（10 卷、858 道题、870 个入库版本），
在副本上跑。**老师的真库一个字没动**：文件时间戳没变、新迁移没往上落、数据一条不少；
真库的表结构也逐列核对过，模型不认的多余列没有「非空又没默认值」那种会让写入失败的。
新迁移在这份副本上跑通，前后条数一致。

- 完整走了一遍：助手领活 → 交提案 → 题目页那块工作台里看到「原来 → 改成」 →
  老师点「采纳」 → 题卡真的改了、卡上留了提醒、回到待核对 → 对照原卷点「通过」 →
  题库更新。中间每一步都验过。
- 领活的互斥验过：别人租约没到的活抢不走；租约到期活自动回池；交回后别的助手能领。
- 不采纳记档验过：否掉之后同一个助手再提同样改法会被拒。
- 题卡与题库不一致时（改过还没重新入库）提提案会被拒，提案会标成作废。
- 这一版加了 **19 条「改坏了就废」的验收检查**：提案落地、选项整体、租约互斥、租约到期、
  交回、作废处理、工作台读数、老师在场、按钮点下去发的是什么 —— 每一条都有检查守着，
  19 条全部被挡住。写这批检查时当场暴露了两处真问题，已经修好：

  **一处：只改一个选项，会把其余选项抹掉。** 助手交提案时说「A 改成这样」，原先的意思
  是「A 改了，B、C、D 照旧」，落下去却成了「只剩 A」—— 老师一点采纳，这道题就少了
  两个选项。现在选项按整体算：给哪几个就改哪几个，其余原样留着。

  **一处：被否过的改法还能再提一遍。** 老师说了「原卷就是这样」，同一个助手换个说法
  又提上来，待核对里就多一条看着眼熟的噪声。现在同一个助手再提一模一样的改法，
  **直接拒掉**，并把老师的理由原话带回去；换个改法仍然能提。

- **有一处得跟老师说实话**：这台机器只配了 MiniMax，账号池里没有可用密钥，
  真模型调不出去。所以「AI 真正写出来的那几个字」在这台机器上当场验不了 ——
  上面那次真机验的是「领活 → 提案 → 采纳 → 题卡改 → 待核对 → 入库」这一整条接线，
  助手交上来的字是人工构造的，不是模型生成的。提案、租约、工作台这些本身不受影响。

## 八、给老师的一句话

以后想让助手动手，它自己会领活、自己交改法；改了什么，你在题库页那一块里看得到
「原来是什么 → 改成什么」，点一下「采纳」它才落地，不点就原样不动。
