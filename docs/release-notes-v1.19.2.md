# 1.19.2 本地验收版

标签窗口可以直接新建自己的标签和分组。标签类型、颜色、说明和分组在一个表单中填写，分组可以多选；别名、学段与适用条件按需展开。

- 在题卡的“标签”窗口点“新建标签”，默认创建自定义标签，可选择“创建并添加”或“仅创建标签”。
- 点“新建分组”后自动进入新分组，再新建的标签默认归入该组。
- 标签管理左侧点击分组查看标签，通过独立“编辑”按钮修改分组；已有标签也使用同一个编辑表单。
- 窗口顶部与底部保持可见，分组及标签列表独立滚动；保存时保持实色背景，修复叠字和重影。
- 保存失败保留输入。标签创建成功而贴标失败时，重试仅贴标，避免重复创建。

保留 1.19.1 的右侧 AI 建议栏、人工核对、持久撤销及 PDF 导出修复。本版本未公开发布，也未自动升级现有安装。
