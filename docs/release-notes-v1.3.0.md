# 题有据 v1.3.0

这一版重点改善教材录入、配图核对、审题效率和软件内设置，并把处理等待状态改成真实可核对的信息。

## 新功能

- **教材重新切题预演**：在“工具 → 切得不对？重新切题”中先查看只读影响预演，明确列出保留、新增、范围变化、例题去解和将移入回收站的题卡；预演不改题卡、不调用识读模型，确认后才应用。
- **教材例题只保留题干**：识别“例题 / Example”等来源，遇到“分析、解析、解、证明、Solution、Proof”等印刷解答边界时停止；已有例题若只是尾部多收了解答，可在本机直接缩短，不重新调用模型。
- **更稳的教材切题**：同一本书里重复出现的题号使用来源类型和原始块位置匹配；补强首题漏号、表格题、图号与题号配图、例题 / 练习交界、章节引用题等场景，并为异常超长题卡设置安全上限。
- **批量移除与回收站**：Ctrl / Cmd 点击增减单题，Shift 点击连续范围，Delete 可批量移到回收站；支持即时撤销和按删除批次恢复，避免误删。
- **API 与模型收回软件设置**：可在“设置 → API 与模型”中配置 MinerU、MiniMax、硅基流动账号池；凭据由当前 Windows 用户加密保存，页面只显示配置状态和账号数，不回显密钥。可选择或填写 MiniMax / 硅基流动视觉模型 ID，并分别设置主读、复核和分歧裁决模型。
- **真实处理进度**：显示实际排队项数、任务已等待时间、最近状态更新时间、MinerU 分片进度以及 AI 已完成 / 总题数；无法得知百分比时明确说明，不再给出固定“一两分钟”。额度不足会显示为可恢复暂停。

## 配图与审题改进

- 扩展“如图是、如图为、图中、下图、as shown、in the figure”等中英文提示词，同时排除“图书馆”等误命中，并区分“请画出图象”这类作图要求与题目自带配图。
- 旧题卡会用已有文字和候选图按新规则重新判断；人工确认不会被自动规则覆盖，也不需要重新处理 PDF。
- 自动排除窄小章节徽标等装饰图，同时保护真实选项图、表格和题干图；对被错误带入的模型图片说明或 Markdown 表格，保留原图并清理推测性文字。
- 配图编辑不再常驻“新框属于”下拉框。画框或点击候选图后，再明确选择题干、A / B / C / D 或无关；标签可拖动、自动避让，归属菜单会根据窗口空间向上或向下展开。
- 配图冲突提供明确处理动作；当当前配图正确、其余候选图无关时可一次确认，不再陷入无法通过的死路。
- 减少无意义的黄色标记：纯格式差异不再算内容冲突，题号只要任一独立读法正确便不误报；数字小问在没有 A–D 选项时可正确归为解答题。

## 稳定性

- 识读账号池在任务边界重新加载：正在处理的任务保持原配置，新设置从下一份任务或下一次重读开始生效。
- 一个识读服务额度不足时，另一位读者仍可完成任务；全部可用读法都无法继续时才暂停，并可在补充额度后重试。
- 程序重启只恢复真正处于等待或识读中的题卡，降低重复处理风险。
- 重新切题会保护人工修改、已通过和已入库记录；若新旧范围冲突则保留原内容并要求复核。新规则不再命中的自动题卡会进入可恢复回收站。

## 升级说明

1. 关闭正在运行的题有据，下载并运行 `TiYouJu-Setup-1.3.0.exe`。
2. 可直接覆盖安装 v1.2.0，无需先卸载；现有题库、原卷和本机加密保存的 API 配置会继续保留。
3. API 配置入口已移入软件内；升级后请从“设置 → API 与模型”管理账号池和模型。
4. 已有教材任务不会擅自重切。需要采用新规则时，进入“工具 → 切得不对？重新切题”，先核对只读预演，再确认应用。
5. 新保存的 API 或模型设置从下一份任务或下一次重读开始生效，不会中断当前识读。

当前安装包未进行商业代码签名，Windows SmartScreen 可能显示提醒。请只从本仓库的 Release 页面下载，并用 `SHA256SUMS.txt` 核对文件。
