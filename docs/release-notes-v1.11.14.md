# 1.11.14：答题与导出更顺手

- 手工切题：S 保存下一题，Ctrl+S 完成。Enter / Ctrl+Enter 仍兼容，输入和中文组合输入不会误触发。
- 答案解析：编辑文字和公式在左，实时预览在右；小屏自动纵排。返回先关闭界面，再释放图片和公式，保存后的刷新只处理变更答案。
- “检查初稿”改为“刷新生成结果”：读取生成进度与结果，不检查数学对错，不再次调用模型。
- 暂时隐藏豆包或当前助手的辅助生成入口。未配置时提示设置答题 API；已配置并测试后，只生成勾选题目的本次答案初稿，不自动打开全局开关。现有答案、初稿与历史版本保留。
- 答题 API 密钥增加眼睛按钮。默认隐藏，主动点击可临时查看；收起、离开或切换服务商后清除显示。查看不修改已保存的密钥，也不请求模型。
- “设置 → 显示与导出”可指定桌面版 Word/PDF 保存目录，同名文件自动编号；留空继续使用浏览器下载。移除组卷的打印按钮。
- 预览和 PDF 共用 A4 字体度量、宽公式调整与分页规则；预览缩放不再改变字体排版。Word 显式两列/四列图选项，在原图尺寸能容纳时使用对应网格。
- 点击空白处收起组卷调整菜单。Esc 先关菜单，再退出预览。
- 题库增加“全屏看题”和“专注浏览”：全屏显示完整题干、所有配图与答案，可缩放；专注浏览收起筛选栏和试题篮。退出恢复原题和滚动位置，选题篮保持。修正导航时的陈旧组卷未保存标记，真正未保存内容继续受保护。

AI 结果仍需人工核对。离线测试与导出排版验收不代表真实云模型的数学准确率。
