# 题有据 v1.10.1

这一版主要改照片卷，尤其是学生写满演算的卷子：切线不再压字，草稿不再拼进题目，多选题不再记成单选。另外，审题页的题卡统一成左图右文。

## 审题界面

- 每张题卡都是左边原卷截图、右边文字。以前宽截图会把题卡变成上图下文，打勾的位置也跟着变；现在都一样。
- 打勾、题号、题型、状态排成一行，放在题卡顶上，和收起的题卡对齐。

## 切题

起因是一份两栏横版的照片卷（高一质量检测一），19 道题里有好几道切得不对。

- **切线不再压在字上**。照片上 MinerU 给的文字框常常偏大，下一题的框从上一题最后一行的中间开始，原来的切线就会切掉分母、下标、答题横线，被切掉的半行又出现在下一题顶上。现在切之前先看原卷，切线压到字时挪到两行之间的空白处：
  - 上一题的下沿只往下挪，挪过碰到的那几笔，不会越过下一题的题号；
  - 下一题的上沿只有在切到上一行印刷字的下半截时才往下挪，挪到那行字下面为止；
  - 下一题题号上方单独的小记号（比如“−1/2024”的分子“1”）照旧留给下一题。
  - 原来就切在空白处的（印刷清楚的 PDF 大多如此），位置不变。
- **草稿不再当成续页**。一道题在一栏底部结束时，原来会把下一栏顶上、下一题之前的那一段也拼进来。现在这一段如果只有算式、没有文字（没有汉字、英文单词，也没有 A. B. 或 (1)(2) 这类标号，也没有图），就当作学生的草稿，不拼进来。
  - 选择题已经看得到 A–D 四个选项时，直接略去，不提示。
  - 其他题略去时，会在任务说明里写一句“第 N 题：下一栏开头有一段只有算式……”，万一那是印刷的公式，按提示调整原卷范围即可。
- **重新切题不打扰已经审过的题卡**。对已经打勾、改过字或入库的题卡，如果新规则只是把切线挪了一点（上下不超过页高的 1.2%，范围里的文字没变），保留原来的范围，不标黄，审批也不作废。

## 识读

- **多选题**：大题写着“有多项符合题目要求”“部分选对的得部分分”这类说明时，这一大题的选择题按多选题记，即使读题模型说是单选；写着“只有一项符合题目要求”时按单选题记。说明里按题号分开写的（“第 1~8 题只有一项……第 9~11 题有多项……”）不算，仍按模型读的。单选题说明里常见的“多选、错选均不得分”也不算。
- **编出来的“此处为配图”**：模型偶尔把看不清的选项写成“（原卷此处为配图，无印刷文字）”。现在这类说明当作没读出来，题卡提示你补上这个选项，不会把这句话当成选项内容存起来。

## 升级后

- 已经读完的卷子不会自动重新切题。想按新规则重切，在这份卷子的任务里点“重新切题”：范围变了的题卡会重新识读，没变的原样保留。
- 升级后第一次启动时，大题写明“有多项符合题目要求”、却记成单选、还没有通过也没有手动改过的题卡，会改成多选题。已经通过或入库的题不动。

已经装了题有据的，下载新的安装包直接覆盖安装即可，题库和设置都会保留。
