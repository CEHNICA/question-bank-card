# 1.25.94：加标签的两处入口，操作方式不一样

老师 10 月 20 日晚上 23 点发来一张截图，说：

> 这个整理勾选的标签这个按钮你点进去啊，它是可以添加标签的啊，它是可以添加标签的。然后呢，这种添加标签的方式跟在右边添加标签的方式是不一样的，你发现了吗？当然我并不是说这种不一样不被允许，但是这说实话有点有点有点乱了，你觉得呢？

他说得对，而且点得准。

1.25.93 统一了**颜色和长相**（同一个标签在几个地方是同一个颜色、同一副样子），但没统一**怎么操作**。两处差得很远：

| | 右边「＋添加标签」（一道题） | 「整理勾选题的标签」（一批题） |
|---|---|---|
| 打开后 | 一个输入框 + 一行键盘提示，**下面一片空白** | 左边章节树 + 右边 263 条全铺着 |
| 怎么找 | 必须先打字才出候选，最多 8 条 | 搜索框，或者点左边某一章 |
| 一条候选长什么样 | 圆点 + 名字 + 上级路径 | 圆点 + 名字 + 「知识点 · 初中 › 方程与不等式」+ 一整段说明 |
| 新建标签 | 在列表最后一条：「新建「函数」并贴上」 | 右上角一个孤零零的「新建标签」按钮 |
| 摘掉已贴的 | 在详情里点 × | 再点一下那一条 |
| 提示 | ↑↓ 选择 · 回车贴上 · Esc 收起 | 点一下贴上，再点一下拿掉。 |

## 一、先说清楚：两个入口都得留

右边那个管**一道题**，「整理勾选题的标签」管**你勾选的那几道题** —— 范围不同，不是重复。所以这次不是「砍掉一个」，而是让**同一件事只有一套做法**。

## 二、这一版改了什么

1. **候选行长成同一副样子**：彩色圆点 + 名字 + 上级路径。

   路径只写上级、不再带「知识点 · 」这种类型前缀（批量窗口原来那行挤了四样东西：类型、路径、说明、状态字）；类型和说明挪到鼠标放上去才出现。

2. **右边那个空着的输入框改成有话可说。**

   以前展开后只有输入框，不打字就**一片空白**，第一眼看着像坏了。现在不打字时列出「最近用过的」，点一下就贴上 —— 而且这就是批量窗口打开时列的**同一份**（同一处代码算出来的，不是各算各的）。

3. **批量窗口打开先列「最近用过的 + 收藏」**，不铺满两百多条。

   点左边某一章才列那一章；要看全部就点上面的「全部标签」。

4. **新建标签统一放在列表最后一条**：「新建「XXX」并贴上」。右上角那个孤零零的「新建标签」按钮去掉了。

5. **提示语统一成同一句**：「点一下贴上，再点一下拿掉。」右边那行提示现在一直挂着（以前有候选就藏起来，老师看不到「点一下会贴上」）。

6. **顺带修掉一个真 bug**：「最近用过的」是集合，代码却按数组取 —— 单题那边空着打开会直接报错，是新测试跑出来的。

## 三、验证

- 前端 `node --test frontend/test_*.js`：**129 项全过**（新增 1 项：两处加标签是否统一）
- 新测试 `frontend/test_library_tag_add_unify.js` 量的是**真跑出来的两棵 DOM** —— 把两处渲染函数切出来在假浏览器里跑一遍，再比它们画出来的东西：
  - 批量窗口打开时只摆最近用过的几颗，不铺满；
  - 候选行是「圆点 + 名字 + 路径」，路径不带类型前缀，说明文字不在行里而在悬停里；
  - 同一颗标签，两处写出来的上级路径**一字不差**；
  - 两边的提示语是同一句；
  - 输入的名字目录里没有时，两边最后一条都是「新建「XXX」并贴上」。
- **7 条变异全部被挡住**：批量窗口又变回铺满全部 / 候选行不写路径 / 路径加回类型前缀 / 单题空着又变回空白 / 提示语换回旧的 / 新建入口改回「新建标签」/ 说明语换回「点击标签立即保存」。
