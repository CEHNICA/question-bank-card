# 题有据 1.12

帮助和设置更简洁，自动切题与手工切题分别入门，新手可以实际完成一份练习卷。

- 新手练习只用三道示例：框第 1 题、改第 9 题错字、核对并通过，再到独立练习页选题、预览、导出 PDF。练习不用密钥，不调用云服务，不混入正式题库、试题篮或组卷草稿。
- 帮助入口区分“自动切题入门”和“手工练习”。自动流程说明导入、本机切题、按需授权 MinerU、核对入库和选题导出；“开始导入”回到真实上传入口。离线示例明确属于手工练习。
- 指导栏占用审核侧栏或窗口标题下的独立区域，不再悬浮遮住原卷；“指给我看”仅给操作位置加轮廓。练习可暂停、刷新后继续；补图单独练习，跨页、补答案与读题失败按任务查看短说明。重学与恢复提示放入次要入口，标记原理折叠显示。
- 导出位置按当前状态显示最多两个操作按钮。读取自动进行；未保存的选择不被读取覆盖，取消保留已保存配置。浏览器下载作为保存方式选项，读取失败才显示重试。
- 快捷键按场景显示，补齐手工切题 S/Ctrl+S、题库全屏左右切题和答案编辑 Ctrl+S。切题窗口中的 Ctrl+S 可在工具栏或指导栏获得焦点时完成切题，不再弹出“另存为网页”；输入、组合输入和保存中的操作仍受保护。审核列表和放大窗口的 Enter 都通过并继续；已通过题不会被 Enter 撤销，撤销使用 U 或取消勾选。
- 题卡用待核对等简短状态提示；识读比较留在详情，高级整理选项和知识点文件位置折叠。真实故障、未保存改动和云处理授权保持清楚可见。
- 安装与更新脚本支持两段版本号，软件和安装包显示为 1.12；旧版本更新核验仍保留。
- 修复 Windows 浏览器启动时端口文件短暂锁住或尚未写完导致 PDF 导出失败的问题，在原有时限内等待可读内容。预览与 PDF 共用分页器，真实两页输出按两页校验，仍保留答题留白、公式、配图和整题优先规则。

逐题通过自动入库、原卷保留、旧版题目及组卷保存范围保持原有规则。练习 PDF 与预览共用排版文档，导出时拒绝已修改或尚未通过的练习内容。
