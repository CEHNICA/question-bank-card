# 题有据 1.12.6

本次是按老师反馈修的九条：四条是「界面看着做完了、其实没做」，两条是入口放错了地方，还有一条让人白录了一遍卷子。

## 入库以后，对号撤不掉了

题库里已经有这道题了，但题卡上的方框还是空的，点一下没反应。

原因：方框一直**只管"通过"，不管入库**。取消方框只是清了"通过"，题库里那一条原封不动——所以点第一次像没用，点第二次也一样。

现在这个方框是一个**完整可逆的开关**：

- 打勾 = 通过并入库
- 取消勾 = 撤销通过，**并把这一版从题库撤回**
- 题卡和原卷都留着，改个字重新勾上就能再入库

已入库的题，方框现在一上来就是**实心的**（以前是空的，看着像没入库），鼠标停上去会写明"取消勾会同时从题库撤回"。

顺带修掉一处藏得很深的问题：撤回请求少带了一个请求头，被服务端挡回"请求格式不正确"。请求发出去了、失败提示也弹了，但题库里那一版留在原地——**界面看着像撤了，其实没撤**。现在实测走完整往返：题库 162 → 161 → 162，两个计数同步 10↔9 / 15↔16 再一起回来。

## 改字面板：保存条不再挡着内容

原来"保存答案与解析"那一条浮在面板**底部**，遮着下面的内容，底部还专门留了一小块空地给它。

现在移到面板**顶部**和标题并排，钉住不动，底部那块空地删掉。

「预览和输入框不在同一水平位置」也一起修了：预览放回左边原卷下面，用量出来的像素把两边的顶补到同一条线上。

试过把题干和预览并排放进右栏，右栏只有 551px，分完两半题干框只剩 265px——长题干根本没法打字，而且两列标签高低不同，还是对不齐。

## 归档以后，同一份卷能再录一遍

上传查重把**已归档的卷排除在外**了。所以一份卷归档之后，同一个文件再传一次会悄悄建一份新任务，题库里于是出现**两份同名来源**。

实测复现过：两份同名的月考卷，各 25 题全入库，题库里 50 条同源题。

现在归档过的原件再传，会先问一句：**恢复原来那份** 还是 **仍然重新录入**。选后者也允许，但新任务名会加序号，题库里两条来源名字分得开。

## 版本历史整套删掉

题卡和题目详情里那个「版本历史」弹窗，只读、看不懂、也没人用，整块删除（弹窗、样式和它专用的测试脚本）。

「撤回」和「查看出处」是另外两条路，不受影响。

## 设置页三个「API 配置」

同一屏里「API 配置」出现三次：左侧页签、内容区标题、底部按钮。三个同名的东西，只有一个能点。

现在分成三种说法：页签「服务与密钥」、内容标题「读题与看图服务」、按钮「打开密钥窗口」。指向早已删除的分区的旧说法（"设置 → 常用 → 填写或更换密钥"）也一并改掉，免得照着找扑空。

## 从题库点回「录入终审」，位置不丢了

原来点顶栏「正式题库」再点回「录入终审」，会回到默认状态：筛选重置、跳回第一题、展开的卡全收起。

现在切筛选、停在第几题、展开哪几张卡都记着，转一圈回来还在原处。

「设置 → 返回录入终审」本来就是对的，没有动它。

## 「改为手工切题」收进菜单

它在试卷头下面是个**醒目的主按钮**，但这个动作实际是中止云端任务、改走手工框题——样式在暗示"这是现在该做的事"，和它的真实含义正好相反。

现在只留在「试卷操作」菜单里；切换进行中菜单会自动展开，显示进度。失败现场的小按钮、空状态的主按钮、原卷页面里的按钮都还在——那三个是不同场景。

## 题库新增「撤回所选」，同名来源分得开了

清一份 25 题的卷要点 25 下，做不完。现在勾选后一次撤完，**撤了几条、哪条没撤、为什么**逐条报出来。

顺带修掉一个会出事的地方：题库里有几对**来源同名**的卷，来源下拉里长得一模一样，照着随手一选就可能撤错那一份。现在每份都带录入时间（精确到分），撤回确认框也按来源分组写出卷名、题数和时间。

## 验收

后端 1380 项、前端 96 项全部通过。九条逐条在真实题库上点过，不是只看测试结果。宽屏并排布局单独验过——内置浏览器只有 639–901px，截不出宽屏。
