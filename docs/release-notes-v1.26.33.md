# 1.26.33：识读读不出字时，说清是哪一种情况；整块手写的题能自动誊录；框选识读改成快捷键 C

老师的三句话：
「识别不出来题目之后，给他一个反馈……这是手写题啊，这是照片题啊，是吧？」
「还不还不会影响印刷题目的识别，因为印刷题目有时候会混杂着大量的手写，
如果他真的能把手写看出来，那题目基本上就没法看了，你说对吧？」
「算了算了，不要放到更多里面。你搞个快捷键吧……我只需要我在任何一个界面，
我都可以实现这样的一个操作。」

## 一、原来的那句话为什么没用

一道题读不出文字时，题卡上写的是「识读未返回有效正文」。这句话只说了一个事实，
没说老师下一步该干什么：到底是自己把题干写下来，还是范围框偏了要重新框，
还是这道题本来就不该用看图识读。老师只能自己猜，猜错就卡在那儿。

真实案例：老师把自己在白板上写的题拍成照片传上来。白板上只有手写，
识读按规矩只誊印刷体，于是交了白卷 —— 这不是坏了，是这套系统本来只认印刷题。

## 二、这一版改了什么

**先问清楚，再给话。** 只有在「这次一个字都没读出来」的时候，才多问一句：
**这块范围里到底有没有印刷出来的内容？**

- **有印刷内容** → 多半是范围框偏了或图太糊。题卡上写：
  「这道题里有印刷文字，这次没读出来：多半是范围框偏了或图太糊。
  点「调整范围」框准一点，再点「AI 识读这题」重读一次。」
- **一个字印刷都没有** → 整块是手写/板书/照片。这时**改成誊录它**：
  让识读把上面的手写内容誊成文字当题面，并挂一条提示
  「这道题是手写的，文字是识读誊录的，请对照原图核对」。
  誊出来照样要人核对，所以卡不是绿的。
  连手写也誊不出来时，题卡上写：
  「这道题没有印刷内容，是手写题或照片题，识读誊不出字。
  请点「改字」对照原图把题干写下来 —— 这张图里的图形程序已经认好了，可以直接用。」
- **判不出来** → 两种可能都写上，让老师对着原图看一眼再决定。

**印刷题一个字都没动。** 誊录提示词没改，印刷题的识别流程、调用次数、结果
全都不变；「有没有印刷内容」这一问**只在读出白卷时才问**，正常的题不多花一次调用。
「只要有一个印刷元素就算有」这条硬判据，和程序里早就有的
「这张插图是不是整幅手写」那道闸门用的是同一把尺子 —— 印刷题里混着学生手写批注时，
誊录仍然只取印刷体。

## 三、顺带修好的：识读卡在「正在识读」出不来

老师问过「为什么识读这么慢」。查到两种原因，都修好了：

- **写结果时被数据库锁挡住。** 识读读完了，结果写不进去，题卡就一直停在
  「正在识读」，而队列里已经没人接手 —— 永远转圈。现在写结果遇到锁会重试，
  重试还是不行就先把题卡放出来，别再让它转圈。
- **程序重启后没人接手半途停下的题。** 现在 worker 一启动就把「卡在半路的题」
  放出来，并写明原因：「上次识读没有完成，请重新识读这道题。」

## 四、新加的：按 C 框一块，字直接进剪贴板

老师的原话：「不要放到更多里面。你搞个快捷键吧……我只需要我在任何一个界面，
我都可以实现这样的一个操作。」

**「更多」里撤了两个按钮。** 「查看识读记录」和「框选识读（纠错）」都不在了；
「修改题目来源」和「让 AI 重读这题」留着。识读记录不是消失，是换了个地方：
现在只在「其他读法还有不同内容」那块里展开 —— 那是它唯一有用的时候。

**多了一个快捷键 C。** 在录入审核页、放大对照页、改字的时候、题库里都能按。
按一下打开原卷，框住要读的一块，AI 把框里看到的字都读出来
（**印刷的和手写的都认**），读完**自动复制到剪贴板**，可以立刻粘到
Word、微信、别的软件里。

这一路只抄字，不填题：题卡一个字都不会改，也没有「放到题干」「填到选项」这些按钮。
浏览器有时不让程序自动复制（窗口没焦点就会），这时题卡上留一个
「复制到剪贴板」按钮，老师自己按一下就行。

题库里按 C 会带着当前选中这道题跳到录入终审、直接打开原卷画布 ——
题库那一页没有画布，框不了，所以是跳过去再框。

**这一条新路和印刷题的识读是两条路。** 印刷题怎么读一个字都没变：
还是只誊印刷体，印刷题里混着学生手写批注时照样忽略。
只有「框里抄字」这一条新路才把手写一起认。

## 五、真机验过

- 本机真数据里那道白板题（库里唯一一道原图题）已按新流程走过一遍：
  题干、答案、解析、图形齐全，组卷导出的 PDF 上题干规范、配图正确。
- 识读读出白卷的三种情况（有印刷内容 / 整块手写 / 判不出来）各有测试守着；
  「印刷题正常读出时一次都不多问」也有测试守着。
- 按 C 框一块这一路，在本机真数据上从头走到尾：按 C 弹出框选窗口 → 在原卷上画框
  → 排队 → 读回来 → 字自己进了剪贴板（读回来的就是框里那段文字）。题卡一个字没改。
- 这一版一共 15 条「改坏了就废」的验收检查，全被挡住：手写那一路 6 条、
  剪贴板这一路后端 4 条、前端 5 条。
- **有一处得跟老师说实话**：这台机器只配了 MiniMax，账号池里没有可用密钥，
  真模型调不出去。所以「AI 真正读出来的那几个字」在这台机器上当场验不了 ——
  上面那次真机验的是「框 → 排队 → 读回 → 自动复制 → 进剪贴板」这一整条接线，
  读回来的那几个字是本机临时搭的假服务给的固定文字，不是 AI 读出来的。
  换到有密钥的机器上，读出来的就是框里真正的字。

## 六、给老师的一句话

以后再拍白板传题，如果那道题整块都是手写，程序会自己把它誊成文字并标出来
（请对照原图核对一下）；如果其实是印刷题而读不出来，题卡会直接告诉你
「范围框偏了或图太糊」，点「调整范围」框准再读一次。

另外，想从原卷上抄一小块字出来，按 C 就行 —— 框一块，读到的字直接进剪贴板，
粘到 Word、微信里都能用。
