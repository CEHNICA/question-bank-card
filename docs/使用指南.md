# 使用指南

[返回项目首页](../README.md)。这里保留完整操作、服务配置、数据边界与开发说明；先体验可以使用软件内置示例，不用密钥。

本指南对应本地改进版 **1.11.7**；当前 GitHub 安装版为 [1.11.5](https://github.com/CEHNICA/question-bank-card/releases/tag/v1.11.5)。下载或升级后先检查实际版本与命令能力，旧安装包可能还没有本文中的新功能。

## 完整工作流程

直接上传 PDF、Word 或照片，程序先在本机判断和处理，不用选择手工、文字 PDF 或 MinerU。只有本次允许云处理、已配置服务且本机未切出可靠题目时，才使用 MinerU；不允许发云、服务不可用或处理失败，都保留原卷，从原卷选题。已有成功题目不会因此被删掉或重复创建。

**第一步：切题。** 点击“手工切题”，选题号和题型，在原卷上框出完整题面；跨页或跨栏可添加多个片段，按缩略图调整阅读顺序并查看拼接效果。浏览工具左拖移动画布，框选工具左拖画框；Ctrl＋滚轮缩放，空格＋左拖或中键临时移动，选中框后方向键可微调。连续切题用“保存并切下一题”，保留页码、缩放和当前位置。最后点“完成切题”；即使已到空白的下一题，也能直接完成，不会再要求框选或多造一道题。未保存退出会提醒，保存失败保留框选结果。

**第二步：AI识读。** 完成切题后，在主界面提交已经保存的题目。点“AI 识读已切题目”批量识读待处理的裁片，或在单张原图题卡上点“AI 识读这题”；直接使用已有完整题目范围，无需重新框选。保存范围、连续切题、完成切题都不会自动调用识读服务。读题服务未配置时明确提示去设置，已裁剪的原图题仍保留。

识读时可点“停止识读”，立即结束本机等待，保留已裁剪的原图和已经完成的建议。远端服务可能仍在收尾，其迟到结果不会被采用；再次识读需要主动点击。

在“设置 → 读题服务 → 识读方式”可关闭“二次 AI 识读对比”。关闭后每题只读一次，不再进行第二次比较或第三次裁决；有问题时可重新识读。这个开关不取消采用读法、标记通过和入库操作，已有题目不会因此重读。

**第三步：审核。** 原图题识读先生成建议，对照原卷确认采用后再审核；不会直接覆盖人工题面或入库版本。逐片段核对完整后，也可跳过识读，直接把原图题审核入库、加入题篮并导出 PDF/Word。范围不对用“调整范围”；已识读的文字只有局部需要重读时用“框选识读”，并非让已经切好的整道题再次切题。原图里的配图和选项属于完整正文；转成文字后可以单独整理配图。

原图只在左侧显示，右侧显示识读结果，点“采用此读法”转成文字题。原图题尚未采用文字时，不把空题干与识读结果比较成整段缺文；文字题有不同读法时，补充内容默认折叠，按需展开。组卷和导出仍保留原图题的完整裁片。

文字 PDF 的公式、上下标和配图仍须看原卷核对。原图题支持按出处、题号、题型、人工标签查找；全文检索和选项重排需先补可编辑文字。点“停止”立即结束本机处理，保留原卷、已生成题卡和人工修改；可以继续整理，远端服务可能仍在收尾，但迟到结果不能覆盖新处理。识读排队、运行、失败分别提示，超过等待期限明确说明；“不读了”退出本次识读，原题保持不变。

下述识读与复核流程适用于明确选择云解析时：

```
导入原卷 → 切题 → 读题与复核 → 逐题核对 → 入库 → 搜索、选题、组卷打印
```

1. **导入**：拖进 PDF、Word，或几张照片（合成一份试卷）；也可以复制文件后直接粘贴。一本书或讲义选“一本书 / 讲义”，长资料在本机按页分片，失败的分片可以单独重跑。
2. **切题**：[MinerU](https://mineru.net) 识别整页版面和文字，题有据在本机按题号切出每道题在原卷上的范围，并找出可能是配图的地方。手机拍的卷子，切线会避开字、落在两行之间的空白里；学生写在栏顶的演算不会当成题目的续页拼进来。
3. **读题**：看图模型把每道题的截图读成文字，公式写成 LaTeX，表格写成文字表，学生手写和批改按要求忽略。每道题都和 MinerU 自己认出的文字逐字比对；对不上就请另一个模型独立再读一遍，有分歧的地方逐处裁定。
   - 题型（单选、多选、填空、判断、解答）一起读出来；大题说明写着“有多项符合题目要求”的，按多选题记。
   - 题干前面印的出处，比如“（2025·北京海淀·期中）”，单独放进“题源”，不算题干。
4. **核对**：每道题一张题卡，左边原卷截图，右边读出来的题面。
   - **绿卡**：识读完成且没有待处理问题。关闭二次对比时，一次成功的识读也可成为绿卡；开启时会记录多次识读或与 MinerU 文字的对比结果。标记通过后才能入库。
   - **黄卡**：有疑点，比如两次读法不同、可能漏图、配图冲突、有看不清的字。疑点会直接写在卡上；和 MinerU 读法不同的字，在原卷截图上用编号虚线框标出那一行，在题面上标出那个字。
   - **红卡**：没读出来，需要改字或重读。
   - 题型没读出来的题是黄卡，在题号旁边选好题型才能打勾。
   - 题目说“如图”却没有配图，或多出不属于本题的图，会给出提醒；明确的配图冲突需要处理后才能通过。

   改字时边打字边排版预览，预览中的绿线或公式框提示正在修改的位置。截图范围不对用“调整范围”，文字题配图不对用“配图”。文字题需要局部识读时用“框选识读”；推荐会展示替换前后和对应位置，确认后填入改字表单，核对后再保存，也可以手动选择位置。
5. **入库**：打过勾的题入库，生成可追溯的版本。之后改了内容再入库，会成为新版本。
   - 正式题库中点 **版本历史**，可查看每次入库的时间、人工或 AI 核对标记，以及当时保存的题面。
   - 选择一版，与此前任一版并排比较；题干、选项、答案、解析、题源、配图和原卷位置的变化会分别列出，文字与公式写法可展开看具体改动。
   - 每一版都能打开对应的原卷位置。历史窗口只供查看；需要修改时回到题卡，重新核对、入库。
6. **用起来**：在正式题库里按关键词、题型、来源、有没有答案搜题。列表先看摘要，点“完整题目”看全部条件、选项和配图；勾选当前已显示的题加入试题篮，也能切到“已选题目”集中检查。试题篮可以收起，换筛选不会清空。组卷预览中起名字、保存草稿，下次继续；旧版题被更新、撤回或缺失时，会提示先处理，不悄悄换题或漏印。知识点和 AI 参考答案的用法见下文，两项默认关闭。

审核时主要用键盘：

| 按键 | 作用 |
| --- | --- |
| `J` / `K` | 下一张 / 上一张（跳到已通过、收起的题时自动展开，可在设置里关） |
| `Enter` | 通过并跳到下一张 |
| `Space` | 放大对照原卷 |
| `E` / `R` / `F` | 改字 / 调整范围 / 配图 |
| `O` / `Shift`+`O` | 展开或收起这张已通过的题 / 全部展开或收起 |
| `N` | 下一张需核对的卡 |
| `U` | 撤销通过 |
| `Z` / `L` / `Q` | 专注（其余题暗下来）/ 放大镜 / 全屏 |
| `?` | 全部快捷键 |

## 组卷打印与 Word 导出

进入正式题库的“组卷预览”，先等待所选题目和配图完整加载，再选择输出内容：**题目卷、答案与解析卷、题目卷附答案与解析**。预览按实际 A4 页显示，可逐页检查题号、公式、配图和分页位置。

- **导出 Word**：下载真正的 `.docx`，文字、表格、图片和支持的数学公式可在 Word/WPS 中继续编辑。本地生成，不需要安装 Pandoc 或 Office。
- **分别导出题目卷与答案卷**：下载 ZIP，里面是两份独立 Word 文档，学生卷与核对用的答案卷分开。
- **导出 PDF**：直接下载 A4 PDF，不再需要经过浏览器打印窗口。本机使用已有的 Edge 或 Chrome 在后台排版，不上传试卷、不调用识读服务，也不额外安装浏览器；找不到可用浏览器时会提示原因，仍可导出 Word。
- **选择分页方式**：默认“省纸排版”，充分利用页面；“尽量保持单题完整”会尽量让题干、选项和配图放在同一页。题目长于一页时仍须分页，不会把内容裁掉。
- **调整选项与分页**：全卷可选自动、一行四项或两列；个别题可单独设置，覆盖全卷选择，也能点“此题另起页”。预览有排不下的提示时先调整，不靠隐藏内容出卷。
- **调整排版**：正文字号可选 12、14、16 磅；解答题留白可选不留白、适中、较多；姓名、班级与得分栏可开关，题源仍按你的选择显示。默认 12 磅、不额外留白、显示姓名班级栏。
- **留待下次**：起好标题并点“保存草稿”，题目顺序、输出内容、分页方式、选项排列和单题调整一起保存；下次从“组卷草稿”读取继续。旧草稿按原来的答案打印选择恢复题目卷或附答案模式。

缺题、缺图或不支持的公式会明确提示，处理后再导出；PDF 与 Word 的公式支持范围可能不同，某个格式失败不代表另一种格式也无法使用。生成期间请等待完成，失败后保留选题和排版选择，可调整后重试。AI 标签与参考答案仍默认关闭，只有明确选用 AI 参考答案时才附入，并保留“未核对”标记。导出不会补造答案，也不调用云端 AI 解释失败原因。

## 示例教学与新版回顾

首次使用时，点欢迎窗口里的“用示例试卷学一遍”，或空白工作区里的“先用示例试卷学一遍（不用密钥）”。已用过软件，从“设置 → 帮助”重新进入。

基础练习有 7 步：认识题卡、放大对照、确认第 1 题、改第 9 题、补第 2 题配图、认识入库、完成基础练习。内置示例已经识读好，不调用外部识读服务；示例只用来练习，不会进入正式题库。

基础练习结束后可以看新版回顾；老用户可以直接点“设置 → 帮助 → 只看新版功能”。回顾有 8 项功能和 1 个完成页，包括整份原卷的缩放与拖动、改字预览定位、框选识读推荐、题库与出处、试题篮、命名草稿、标签与答案设置、未保存提醒。

框选识读教学可以在原卷上画框并认识“自动推荐（AI）”入口，但不会调用模型或伪造结果。实际识读需要已配置且可用的服务。正式题库和组卷在教学中介绍入口；示例不充当真实题库。

## 安装与服务配置

### 推荐：Windows 安装版

1. 打开 [Releases](https://github.com/CEHNICA/question-bank-card/releases/latest)，下载最新的 `TiYouJu-Setup-*.exe`。
2. 完成安装后，从开始菜单打开“题有据”。1.10.14 起，手动安装时可勾选显示桌面图标；AI 一键安装先不新建图标，收尾时按你的选择显示或隐藏。
3. 首次处理资料时，按提示填写自己的 API 凭据。也可选择有免费额度的服务，见下面的配置说明。
4. 上传资料，等待处理完成，再逐题对照原卷确认。

### 选择有免费额度的服务

录入终审和正式题库共用一个“设置”入口，进入统一设置页（`/settings`）。页面直接分为“读题服务、标签与答案、题面与显示、帮助、关于”五区，不需要再点“打开设置”或进入 AI 弹窗，也不需要在两个页面重复配置。

在“设置 → 读题服务 → 填写或更换密钥”里填：

填写新值后点“保存密钥”；留空的服务保持不变。删除使用各服务卡片里的独立“删除密钥”按钮，确认后只删除这一家的已保存密钥，不会同时保存输入框里的草稿。密钥仍使用当前 Windows 用户加密保存在本机，保存不联网验证。

| 服务 | 要不要 | 使用方式 | 申请 |
| --- | --- | --- | --- |
| MinerU | 自动云解析时填写；手工和本地文字 PDF 不需要 | 在管理页创建 Token；以页面显示的到期日为准，过期后更换 | [mineru.net](https://mineru.net/apiManage/token) |
| 魔搭 | 可选，看图读题 | 申请访问令牌，并完成服务商要求的账户验证 | [modelscope.cn](https://www.modelscope.cn/my/myaccesstoken) |

- 免费额度、模型可用性、验证要求和费用以各服务账户中的当前规则为准。题有据本身不收费，不保证第三方接口持续免费或始终可用。
- 看图服务额度用完时，还没读的题可用 MinerU 识别的初稿（标黄），直接对照原卷改字，或在服务恢复后点“重新识读”。这要求原卷已由 MinerU 成功解析；MinerU 本身不可用时，不能继续导入解析新资料。
- 已有 MiniMax 或硅基流动账户也可以填写。它们可能产生费用，请先查看所选模型的计费规则；某一家暂不可用时，会尝试其他已配置的看图服务。
- 想配合豆包核对：展开“设置 → 读题服务”中的“读题模型”，把“谁来读题”选成 **AI 助手读题**。这样只要 MinerU：题卡先用 MinerU 识别的文字做初稿（标黄、注明“初稿”），再让豆包对照原卷截图逐题核对，或者你自己核对。

MinerU 不可用时，已生成的题卡仍可核对、修改和入库；正式题库仍可搜索、查出处、选题与打印。内置示例教学不调用识读服务。

### MinerU 当前规则与排查

2026-10-02 核对的 [官方 API 管理页](https://mineru.net/apiManage/docs) 规定精准解析单文件不超过 **200 MB、200 页**；每日 **1000 页是最高优先级额度**，超出后降低优先级。旧文档入口仍显示 600 页、2000 优先级页，题有据按当前管理页的较保守限制处理。

[官方限流页](https://mineru.net/apiManage/limit) 另规定提交接口共用 50 个文件/分钟、每用户每日最多 5000 个文件（HTML 最多 100）、查询结果共用 1000 次/分钟，并表示当前暂无商业化收费计划。它可以依系统负载调整限制；不把这些规则当成永久免费或单个账户已经可用的保证。

Token 没有本项目承诺的固定“14 天有效期”，按本人管理页的实际到期日更换。`A0202` 是鉴权错误、`A0211` 是过期，限流、队列满、每日文件数和结果下载失败也各有原因；不把所有失败都归为密钥过期。免 Token 轻量 API 只有 10 MB / 20 页及 Markdown 输出，不能直接替代切题与原卷定位所需的结构化结果。

1.10.15 起，保存 MinerU Token 时只检查格式并在本机加密保存，显示“已配置，未核验”；不会仅为验密钥请求未公开的额度接口。是否能用，要以实际识读任务及本人账户提示为准；如果任务明确返回鉴权或过期错误，再按相应原因处理。

完整差异、接口约定、ZIP 格式和错误分类见 [MinerU 云 API 调查与排查](MINERU_API.md)。本次公开文档核对与离线测试不证明真实云识读已经恢复；没有读取本机密钥或提交用户原卷。

> 当前发布包可能尚未进行商业代码签名，Windows SmartScreen 因此可能显示风险提醒。请只从本仓库的 Releases 下载，并用发布页提供的 SHA-256 校验值核对文件。

### 标签与参考答案

进入“设置 → 标签与答案”（`/settings#ai`），直接设置功能开关、生成时机和“由谁生成”；选择独立 API 后才展开配置。**知识点标签、AI 参考答案以及新题自动处理都默认关闭。** 默认由当前豆包工作版或正在操作软件的 AI 助手自己看图、分类和解题，再通过本地 CLI/MCP 写回，**不需要另填豆包 API**。

可以选择三种时机：

1. **新题录入并入库后自动处理**：打开需要的功能，再选择相应的“录入并入库时自动生成”。只有新入库版本产生后才建立任务，未入库的识读初稿不会提前生成答案；重新入库未变的题不会重复排队。
2. **入库后处理单题**：在题目的操作中补标签或参考答案，或直接让当前助手处理指定题目。
3. **勾选批量处理**：在正式题库勾选需要的题，再批量补标签或答案。助手逐题、按每种任务分别提交，不能把多道题写成一段整体答案。

助手模式会保留待处理任务，仍需当前助手实际领取、看图完成并写回；软件不会自动唤醒桌面豆包。客户端必须支持本机 CLI 或 MCP 才能直接交回结果；只有聊天能力时，由你完成本地写回操作，不能声称已自动接通。安装收尾照常邀请继续发题，不把 API 配置当成必经步骤。

标签从知识点目录选择，参考答案标着“AI 参考 · 未核对”，记录真实助手来源，单独保存，不替换原卷答案、不自动通过题目。题目版本或配图变化、功能关闭、标签不在目录中时，提交会被拒绝；重新领取当前任务并核对，不能用旧结果强行覆盖。[助手命令与任务协议](../skills/tiyouju/references/commands.md#助手补标签与参考答案)

**独立模型 API 是可选途径。** 可推荐 DeepSeek，也可选择豆包 API 或其他兼容服务；实际接口、模型名称和图像/思考能力按所选服务核实，不把“DeepSeek Pro”当作未经确认的官方模型 ID。配置保存不联网，连接测试需要明确选择，测试与生成可能计费；不会自动借用 OCR 服务。当前版本未实测收费 API 的数学能力或真实计费结果。

### 让 AI 助手帮你用

#### 先用豆包帮你核对

先把这个项目地址发给 [豆包](https://www.doubao.com/)，让它了解题有据，并按仓库说明带你安装、上手：

> https://github.com/CEHNICA/question-bank-card

核对时，打开一张题卡，把原卷截图和当前题面交给豆包，说明“请对照原卷找出识读错误，指出需要修改的位置”。把确认后的修改放回题有据，检查公式预览、配图和出处，再保存、入库。豆包负责帮你看题，题有据负责把这些题和出处保存下来。

自动安装、直接改题卡和安装配套技能，需要当前客户端提供相应的电脑操作能力；只支持对话时，豆包可以给你步骤、协助核对，由你在软件里完成操作。

#### 自动安装与其他智能体

其他智能体也可以配合题有据使用。如果当前助手能操作这台 Windows 电脑，也可以直接把上述项目地址发给它。

仓库提供了 [AI 助手入口](../AGENTS.md)：只收到项目地址时，以安装和上手为默认帮助方向；具备必要权限和安装授权的助手可直接安装，核实 EXE、实际版本与本机应用状态，再告诉你“已经帮你安装好题有据”。你明确要求介绍或审代码时，会先按该要求工作；网页里的说明本身不代替安装授权。

安装结束后，助手会一次询问两个可选项：**配套技能要不要安装到当前助手里，桌面图标要显示还是隐藏**。你已经说过选择，就直接照做。配套技能是给支持技能的客户端使用的操作说明；没有这项功能的助手仍可通过命令行帮你使用题有据，不需要修改全局 AI 设置。

然后直接把试卷或题目发给它即可，例如：“帮我处理这份试卷：D:\试卷\期中.pdf”。已有题目任务会先继续处理，不等待可选设置。助手仍需对照原卷逐题核对，不能只凭 AI 识读就通过。

AI 安装收尾命令从 **1.10.14** 起提供；助手先检查本机安装版能力，旧发布包没有新命令也不能假装执行成功。软件已装好与云识读可用会分开说明：MinerU 不可用时，仍可练习示例、核对已有题卡和使用题库，新原卷要等解析服务可用。

实际操作取决于 AI 客户端提供的权限。只支持对话、不能操作电脑的助手，可以指导你安装，不能声称已替你安装。

- **一键安装或升级**：
  ```powershell
  irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
  ```
  它会下载最新版、核对 SHA-256、备份题库，然后静默安装。
- **命令行 `tiyouju.exe`**：和题有据装在一起。上传、等它读完、看每道题的原卷截图和文字、改字、配图、打勾、入库、查题库，都能做。本地新版还提供 `features` 与 `enrich tasks/prepare/submit/auto`，让当前助手补标签和答案。`tiyouju.exe mcp` 把同样的能力做成 MCP 服务器，给实际支持 MCP 的客户端使用；不会自动修改未知客户端配置。用法见 [AGENTS.md](../AGENTS.md) 和 [skills/tiyouju/SKILL.md](../skills/tiyouju/SKILL.md)。
- **安装收尾 `assistant-setup`**：默认只读检查安装和可选设置；你明确选择后才安装配套技能或显示/隐藏题有据图标。技能目录由当前客户端的真实配置确定，覆盖已有自定义技能须先说明并保留备份。[收尾说明](../skills/tiyouju/references/install-finish.md) · [命令参数](../skills/tiyouju/references/commands.md)
- **AI 通过和人工通过分开记**：AI 打的勾显示成“××已通过 · 待你核对”。你点一下题号左边的方框，它就变成你的通过。审核页有“AI 通过”筛选；题库里标着“AI 审核”，可以只看人工核对过的。
- **保留人工确认**：AI 助手不能撤销你的通过，也不能修改你已经通过的题。
- **AI 不碰密钥**：密钥由你在“设置 → 读题服务”里填写。删除题卡、撤回入库这类操作不开放给命令行。
- 读题用的是你在软件里填的密钥（额度和费用以服务商当前规则为准）。选了“AI 助手读题”时，看图核对这一步由 AI 助手自己来做，使用的是 AI 助手自己的服务额度。

## 支持的工作方式

- PDF、Word 和多张图片导入；界面聚焦时也可以复制文件后直接粘贴上传。
- PDF 单次解析按当前 MinerU 管理页的 200 页上限处理；教材/讲义默认按 100 页在本机稳定分片，超长试卷也按页数上限分片，保留原卷页码对应关系。
- 任务可以重命名并同步更新题目来源；失败任务可以删除，失败分片可以续跑。
- MinerU、MiniMax、魔搭和硅基流动均支持最多 8 个账号组成的本机账号池。某一家暂时用不了（限流、额度用完、服务出错），这道题自动交给另一家已填密钥的服务。
- 多个 MinerU 账号可并行解析不同分片；图像模型账号可同时承载多个识读请求，多个账号叠加。软件自动根据可用服务和限流情况调整处理速度。
- 每道题先用 MinerU 自己识别的文字做独立旁证：与视觉模型逐字一致就不再重复识读；有出入时再请复核模型，并用 MinerU 文字逐处裁定分歧。
- 正式题库支持搜索、试题篮、A4 分页预览、直接 PDF 和 Word 分卷导出；分页方式、选项排列、单题调整与字号、答题留白等排版设置随草稿恢复，题源按选择显示。
- “题面与显示”中，题前出处整理、中文引号默认开，显示小问数默认关；现有选择不会因界面更新被重置。“标签与答案”中，知识点标签、AI 参考答案和新题自动处理默认关，可直接配置执行方式和生成时机；知识点目录默认是人教A版高中数学（2019）各节名称，存在数据文件夹的 `knowledge-points.txt` 里，可以用记事本改。

## API 与隐私边界

手工框题、本地文字 PDF 和原图题导出在本机完成。选择云识读或让外部助手看图时，相应材料会发往所选服务。

| 服务 | 用途 | 是否必需 |
| --- | --- | --- |
| MinerU | 自动解析原卷；长资料先在本机分片，再发送相应分片 | 仅选择 MinerU 云解析时 |
| 魔搭、MiniMax、硅基流动 | 对切出的题目截图进行识读和交叉复核 | 显式识读时按所选服务配置；纯手工不需要 |
| 你使用的 AI 助手（豆包等） | 通过 `tiyouju` 读取题面、原卷截图和配图，用来核对、生成标签或参考答案 | 只在你让 AI 助手操作时；使用该助手自身的服务额度 |
| 独立模型 API（可选 DeepSeek、豆包或其他兼容服务） | 为指定题目生成标签或参考答案，按配置发送题面及支持的图像 | 仅在明确选择独立 API 并启用所需功能时，费用按所选服务规则 |

- 框选识读只发送框内截图；选“自动推荐（AI）”时，还会发送当前题干与选项文字，让所选视觉模型判断替换位置。推荐经过本机检查后展示，用户确认填入、核对保存。
- “忽略手写”是一项识读要求，不会在发送前擦除姓名、答案或批改痕迹。处理含有个人信息的材料前，请先取得适当授权，并核对各 API 服务的数据政策。
- API 凭据使用 Windows DPAPI 加密，只能由当前 Windows 用户解密；网页进程只知道“是否配置”和账号数量，不会收到密钥原文。
- 同一家服务有多个账号时，在“设置 → 读题服务 → 填写或更换密钥”里一起粘贴，用英文分号 `;` 隔开（每家最多 8 个）。无效、过期或额度耗尽的账号会在本次运行中隔离；限流账号会进入冷却，由其他可用账号接手。
- 服务默认只监听 `127.0.0.1`。当前版本没有面向公网的账号、认证和权限系统，请勿直接暴露到局域网或互联网。
- 用户数据库、原卷、日志和备份属于私密资料。它们已被 `.gitignore` 排除，但提交或公开分发前仍应自行复核。

源码运行时，数据位于仓库的 `backend/` 下；安装版数据位于 `%LOCALAPPDATA%\QuestionBankCard\`。卸载程序不会自动删除用户数据。
