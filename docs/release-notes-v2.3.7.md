## 题有据 2.3.7 更新说明

### 更新亮点

1. **软件自己的窗口**：题有据自己弹出窗口，不再另开 Edge。关掉这扇窗口才停止后端。
2. **OneNote 往返**：打开笔记会进入 OneNote；页面上点「在题有据中打开」会把这扇窗口拉回前台并定位到该题。
3. **资源社区**：左栏「资源社区」用系统默认浏览器打开官网社区。
4. **官网更新**：设置 → 关于里可以自动检查更新。软件询问 tiyouju.com，有新版本时从官网下载安装包，核对 SHA-256 后再安装，安装前先备份题库。

### 验证范围

- 本机已打出 `TiYouJu-Setup-2.3.7.exe` 并通过打包审计。
- 更新检查只接受 tiyouju.com，安装包校验不对就停止。
