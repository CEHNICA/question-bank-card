# 1.20.1 本地验收版

本版重新整理正式题库的标签交互，继续使用现有题卡、标签目录、历史和撤销服务。安装包用于本机验收；公开发布另行安排，不自动安装或升级当前程序。

## 给一道题贴标签

在正式题库单击题卡，右侧显示这道题的正式标签和待核对建议。题目复选框用于批量操作，不会把右栏操作范围扩大到勾选的其他题。

点击“＋ 添加标签”，搜索或从分组中选择；点选后立即保存。没有合适标签时可新建。点击标签的移除按钮，只从当前题移除，并可撤销。点击标签本身查看类型、适用小问和依据，需要筛选时再点“查找同标签题目”。

窄屏上先阅读题卡，需要整理时再点“标签与详情”打开右栏。题面和出处信息可按需展开。

## 整理多道题的标签

先勾选题目，再点“整理勾选题的标签”。选择器明确显示题数，并区分全部都有、部分有和全部没有。批量添加或移除只影响这些题，保留其他标签。

## 管理标签目录

点击题库侧栏“标签管理”，进入独立工作区：左侧选择分组，中间查看或多选标签，右侧编辑当前标签。可以新建标签和分组、多选加入或移出分组、合并、删除；标签使用题数可以打开相应题目。

“追加模板”只增补明确选择的内容。全库“清空标签目录”放在“更多”中，先展示影响再确认。删除分组只改变组织方式，保留标签和题目关联。操作记录中可查看并撤销近期操作；后续内容已变化时拒绝覆盖。

多标签的“包含全部、包含任一、排除这些”，以及“未标知识点”“AI 建议待核对”会按当前条件查询。点击标签使用题数或“查找同标签题目”时，清除旧的冲突标签条件，保留来源、题型等其他筛选。

## 核对 AI 建议

每条待核对建议可以单独采纳或拒绝，也可明确勾选后批量处理。处理完的条目立即退出右栏；原始依据与处理结果仍可在“AI 标签记录”中查看。方法标签保留适用小问和解析依据。

同一浏览器会话内，换题、后台刷新或刷新页面会保留尚未提交的建议名称、分组和勾选。保存时禁用重复操作；回复丢失、结果不确定时，点击“核实上次操作”继续验证原请求，AI 建议的对应按钮为“核实上次提交”。原请求身份也会在同一浏览器会话内保留，避免重复采纳或创建标签。核实完成后再继续其他修改。失败或失效的建议可由用户主动重新发起，打开题库和管理目录不会调用 AI。

本版保留既有题文、人工标签来源、原卷校正、持久撤销和 PDF 导出。功能验证结果、安装包及校验值以本次验收记录为准。
