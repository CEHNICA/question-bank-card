# 1.26.12：保存按钮的位置，和模型名怎么填

老师看设置页时提了两点：

> 保存按钮位置感觉不对。其次模型名应该支持自由填写，但会给一个默认的。

## 一、保存按钮

**之前**：平铺之后，「保存密钥」这条按钮夹在「看图读题」和「标签与答案」两段中间，
还摆成一条横贯整页的白色工具条 —— 看着像"整页的保存"，其实它只管读题这一段。

**现在**：

- 改名叫**「保存读题密钥」** —— 它存的是哪一段，一看就知道；
- 平铺时不再摆成横贯整页的工具条，改成一行普通操作（左边提示、右边按钮）；
- 弹窗里还是原来的样子（弹窗里它本来就是贴在底部的 ✓）。

## 二、模型名：能自由填，默认给你填好

**之前**：模型名藏在「模型和 API 地址（一般不用改）」这个折叠区里 —— 想换模型得先
展开，而且看不出当前用的哪个。

**现在**：模型名从折叠区里搬出来，**跟着它那一家的卡片走**：

- **读题侧**：勾了哪家的看图服务，那家的卡片下面就有它的「模型名称」输入框
  （魔搭 / MiniMax / 硅基流动，各是各的）；
- **答题侧**：勾了哪家的生成服务，紧跟着那排勾选项下面就是「模型名称」输入框；
- 输入框里**已经填好这家默认的模型名** ✓（比如硅基流动默认是
  `Qwen/Qwen3-VL-32B-Instruct` ✓），**想换就照着服务商后台里的名字改，不改就用默认** ✓。

折叠区里现在只剩「API 地址」和「此模型支持图片 / 开启数学思考」这些真的少碰的东西，
标题也改成「API 地址和模型能力（一般不用改）」。

## 三、怎么验的

- 前端 `node --test test_*.js`：134 条全过（改了三处切片起点和一处按钮名断言）；
- 后端 `manage.py test core`：全过；
- 真实页面看过：读题侧模型框在对应厂商的卡片里 ✓；答题侧模型框紧跟勾选行 ✓，
  默认值按真实配置正确填好 ✓（`Qwen/Qwen3-VL-32B-Instruct` ✓）。
