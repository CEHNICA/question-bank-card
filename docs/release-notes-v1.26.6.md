# 1.26.6：点「测试连接」一律报"设置状态读取不完整"

## 怎么回事

设置页（API 配置）拿**同一把尺子**校验每个答复：少一个字段、少一种类型，就报
「设置状态读取不完整，请重新读取设置后再试。」—— 这把尺子是为了挡住"答复缺一半"
的情况（半截答复会让页面显示错误的开关状态）。

问题是「测试连接」和「共用读题密钥」这两个接口的答复，**少了一个字段**：
`backlog`（题库里"还差几道"那个数字）。读取设置和保存设置都有它 ✓，测试连接没有 ✗。

于是：**点一下「测试连接」，不管连接通不通，一律报"设置状态读取不完整"** ——
老师根本看不出自己的密钥到底能不能用。

## 改成什么样

那两个接口现在和「读取设置」返回**完全一样的形状**（字段一个不多一个不少 ✓）。

顺带加了一条自动测试：**设置页读的每一个答复，形状必须和「读取设置」一样** ——
以后再少一个字段会被挡住。

## 怎么验的

- 后端 `manage.py test core`：全过（新增那条"每个答复形状一样"的测试）；
- 手工对照：读取设置 / 测试连接 / 共用密钥三个答复，字段集合完全一致 ✓。
