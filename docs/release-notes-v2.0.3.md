# 题有据 2.0.3 更新说明

## 本版修复与优化

1. **录题空状态与多照片上传体验提升**
   - 录题主界面空状态增加「选择文件或照片上传」主按钮，直接唤起文件选择框；「自动切题入门」的「开始导入」按钮在当前页面内同步唤起上传选择。
   - 多照片上传预览窗（`#photoDialog`）支持「← 前移」「后移 →」调整合成页序及「移除」单张误选照片，不必整批重选或上传后再重切。

2. **窄窗口与设置页响应式布局修复**
   - 修复 `<=760px` 视口下待录试卷列表与章节目录（`.entry-chapter-nav`）横向越界裁切问题。
   - 为设置页「API 配置」（`#credentialUi .credential-service`）补齐窄屏响应式规则，消除 200px 固定左留白导致表单与按钮向右溢出屏幕的问题。

3. **状态一致性与说明文案对齐**
   - 清理已被永久删除的试卷在 `sessionStorage` 中的残留引用，空库回访不再弹出误导提示。
   - 帮助、引导文案统一将旧名「服务与密钥」修正为「API 配置」，并在录题改字抽屉中明确标注「原卷参考答案与解析」。
