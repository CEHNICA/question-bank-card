# 题有据 2.3.21（未签名修复版）

- 录入页侧栏滚动时，「题库工作台」和「设置」留在原位。试卷一多也不会把这两个入口滚出屏幕。
- 文件夹改名改为 Enter 或 F2。双击改为把这一支连同下级一起收起。用键盘选文件夹时，焦点不再交给题目，避免没点过的题进入最近浏览。
- 上传记录的灰色遮罩盖住顶栏，不再在上面留一条白。
- 标签搜索框在没输入时不再弹出按拼音排在最前面的无关标签。输入之后仍可按名字搜索，目录里没有的名字仍可以新建。

本版未签名，仍可能出现 Microsoft Defender SmartScreen 提示。签名申请与自动签名门禁保持原状。
