## 题有据 2.3.8 更新说明

### 更新亮点

1. **原卷重框与重新识读**：在题库原卷证据窗口、快速审题或编辑工作台发现配图或文字少裁时，可直接框选原卷更新图片并一键重新 AI 识读。
2. **界面精简与防误触快捷键**：录入入口收进 `≡` 主菜单；题库单字母快捷键统一加 `Ctrl` 防误触；精简右栏定位码复制、`📄 原卷`、`✨ 建议` 与 OneNote 记笔记按钮（去掉自动计刷数与时间轴）；文件夹悬停显示完整层级路径。
3. **社区分享升级与图片压缩**：支持对整套试卷/教材、**普通自定义文件夹**、**单题**与**多选勾选题目**打包上传社区；打包自动压缩图片体积并限制单包 15 MB / 100 题，支持随题导出作者 OneNote 思考与做题步骤（未启动时自动打开 OneNote）。
4. **云端收题自动归档与存储扩展**：下载合并社区题包后自动在左侧创建并放入顶级 **`来自云端`** 文件夹；社区服务端新增个人空间限额与 123 云盘 WebDAV 混合存储适配接口。

### 验证范围

- 前端 ESLint 与全套 `frontend/test_*.js`、社区 Worker TypeScript/构建/单元测试、Python Ruff 与后端测试全部通过。
