# 题有据 2.1.4 更新说明

## 修复与改进

1. **解除历史按章节重提取原图题的「已有人工文字，不再识读」误拦截**
   - 识别旧版按章节重提取遗留在原图题（`body_mode="source_image"`）上的助手候选草稿（`text_source="assistant"` 或携带「文字是本次候选…」标记，实际界面仍按原图展示且未由人工定稿）：`cut_guard` 与批量识读（`paper_read_cut_questions`）、单题识读（`reread`）不再将其误判为 `manual_text` 锁定，这 41 类题卡现在可直接点击「AI 识读这题」或加入「识读未完成题目」批量处理。
   - 后台整理（`library.tidy_saved_cards`）与发起识读时同步清理这些未定稿候选标记，确保 AI 识读结果可正常写入并保留原有「题型 / 人工配图 / 切题范围」。

2. **清理「按章节结构重新提取 / 文字是本次候选」两行历史提示条**
   - 后台接口即时返回、后台启动整理以及前端 `questionFlags` 统一剔除「按章节结构重新提取，请对照新原图范围核对；原审核记录保留在旧版本中。」和「文字是本次候选，显示和出卷以原图题面为准；如需文字题面请另行校订。」两行提示，保留「选题型」「缺图」「看不清字（[?]）」「混入答案」等实用提醒。
