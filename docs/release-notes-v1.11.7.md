# 1.11.7：切题、AI识读、审核分步

裁剪窗口只保存题目范围，手工切题与自动切题都属于第一步。连续保存后，可以从空白的下一题直接完成切题，不会再要求框选，也不会创建多余题卡。

完成后在主界面进入AI识读，直接使用已经保存的范围；可以识读单题或一批待处理题目。保存裁剪与完成切题不会调用模型。识读建议仍需对照原卷确认采用，再审核入库。

识读期间可以停止本机等待，保留原图与成功建议，迟到结果不会覆盖题目。停止后可继续手工整理或主动重新识读。

重复的“漏了一题？手动框出”和“从原卷补题”合并为一个“手工切题”入口。局部框选识读保留在文字纠错阶段，与初次切题分开。

这是本地改进版，先安装供用户检查。AI语义切题与新增OCR服务仍是后续开发项；本次离线验收不证明真实云识读服务已经恢复。
