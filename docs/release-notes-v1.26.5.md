# 1.26.5：重复的卷怎么认、重复的题怎么认

这一版改的是**去重**——两台电脑合并时，怎么认出"这是同一样东西"。

## 一、重复的**试卷**

**认的是原文件内容的 sha256，不是文件名** —— 改了名的同一份卷照样认得出。

| 情形 | 怎么办 |
|---|---|
| 同一台电脑上传了同一份文件 | 不新建，把原来那份指给老师（"这份已经在题库里了"） |
| 原来那份归档了 | 老师点"仍然新建"才会多一条，任务名自动加序号（"卷一 (2).pdf"） |
| 原来那份失败��� | 当作没有重复，可以重做 |
| 备份包里同一份卷出现两次 | 按 sha256 认，并进同一套 —— **不会变成两套** |
| 本机已经有同一份卷 | 并进本机那套，逐题比 |

本机留着好几份一样的（重录过一次）时，挑得**确定**：先排除归档的（归档的那份老师在
题库里看不见，题并进去等于藏起来），剩下里挑题最多的那份；全都归档了就另建一份
看得见的。

**卷子自己的编号（UUID）也要重新给** —— 本机可能已经有同一个编号了（同一份卷在这儿
归档过），照抄会撞车，撞车就是又一次"操作没完成"。

## 二、重复的**题目**（这一版最要紧的改动）

原来的认法是 **(卷, 题号)** —— 错的。

**一本书每章都从第 1 题开始编。** 只按题号找，第一章的第 1 题就被拿去和第二章的第 1 题
配对，题干一对不上 → 判成"题号一样但内容不同" → 又搬一遍。

真机上量到的：同一本书合并两次，**712 道题被当成冲突又搬了一遍**。

现在认题是 **(卷, 题组, 题号)**，再拿**题干**核一遍：

1. 同组同号 → 看题干：对得上就是同一道；对不上，就在同组里再找找有没有题干一样的
   （上次合并给"题号一样内容不同"那道另编了题号的副本）；
2. 这个题号上没有题 → 同组里按题干找 → 题号变过也是同一道题；
3. 都没有 → 才是新题。

**题干才是硬证据，题号只是显示用的。**

验证（拿老师真导出的 88MB 备份包）：第一次合并搬 898 道题；**第二次、第三次合并
一道都不动** ✓（外键 0 违反，各表行数与包里一一对得上）。

## 三、顺带修掉一个"从来没生效过"的兜底

插一行时"这个编号本机已经有了就跳过"这条兜底，捕的是 `sqlite3.IntegrityError`，可
Django 抛的是 `django.db.utils.IntegrityError` —— **这条兜底从来没生效过**：同一个包
合并两次、或本机已经有同编号的行，就会当场失败。现在捕对了。

## 四、怎么验的

- 后端 **2277 项全过**（新增：书里每章重编题号、重复卷挑哪一份、归档的那份不用、
  卷子编号撞车、外键不断链、撤销一并带走）；
- 两台电脑的实盘演练：预览 = 合并；本机答案一道没被覆盖；对方独有的卷子整卷搬过来；
  撤销干净；
- 真包复验：合并 → 撤销 → 再合并，两次合并结果完全一致。
