# 1.20.0 本地验收版

标签目录现在由用户决定如何建立。你可以查看初中数学、高中数学和解题方法模板，勾选需要的分组后导入；也可以从空目录开始，再自行创建标签和分组。模板浏览不会修改现有目录，重复导入会复用相同标签并保留你已有的编辑。

标签管理区分标签与分组。删除分组只移除整理关系，题目仍保留原标签；删除标签会先显示当前题和历史版本中的影响数量，再一次确认，并保存可撤销记录。清空目录也先显示全库影响，可撤销；撤销前会核对题目标签版本、内容和审核状态，发现后续修改时拒绝覆盖。

空目录是有效的个人目录。打开题库、重启程序或启用 AI 都不会自动导入模板。AI 建议可以使用当前助手或已测试的独立 API；目录为空时可以建议新标签，但仍需人工核对后才会创建并正式贴到题目。目录变动后，旧建议和排队任务会失效，迟到结果不会重新写入。

题卡只显示尚未处理的 AI 建议。逐条采纳或拒绝后，该条立即从待核对栏收起；正式标签仍在题卡标签区域显示。可通过“AI 标签记录”按题分页查看此前的依据和处理结果。

知识点预览、AI 助手、设置摘要和兼容读取统一使用正式题库目录。旧版 `knowledge-points.txt` 不会再覆盖个人目录或恢复已删除标签。已有正式题库在升级后保留现有标签和关联。

本版保留 PDF 导出修复、原卷校正、题目内容和人工标签来源。本包用于本机验收，不公开发布，也不会自动升级现有安装。
