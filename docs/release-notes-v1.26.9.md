# 1.26.9：API 配置不再收起来 —— 一页平铺，勾选厂家

## 老师说的三件事

设置 → API 配置，原来长这样：一行说明 + 一个「配置 API」按钮。点开是个弹窗，弹窗里
还有两个标签页（「切题与读题」「标签与答案 · 可选」），每家服务又是一个下拉框，
选完才看见选了谁、密钥存没存。

> 「api配置为什么要收起来，完全没必要，其次只需要有一个api配置窗口，没必要分开标签答案，
> 读题看题，只需要在标签答案，读题看题的时候勾选相应的厂家服务即可」

参考的是老师 GitHub 上那个高中数学题库项目（`math-question-bank`）的做法：**一页平铺，
每个用途一行，选厂家 + 填密钥，没有标签页、没有二级弹窗。**

## 现在是什么样

**设置 → API 配置** 这一页直接就是配置本身：

```
API 配置
下面就是全部配置：云端切题、看图读题、生成标签和答案。勾选哪一家，它就管哪件事；
密钥只加密保存在这台电脑上。

① MinerU（云端自动切题必填）            已保存 0 个
   … Token 输入框 …

② 勾一家看图读题服务
   看图读题用哪家
   ( ) 魔搭 推荐   (●) MiniMax   ( ) 硅基流动   ( ) 暂不配置 原图审核或 AI 助手
   … 这家的密钥输入框 …

③ 标签与答案 · 可选
   ☑ 允许 AI 生成标签建议     ☐ 补充 AI 参考答案
   勾一家生成服务  标签和答案都用这一家
   可复用看图读题密钥  ( ) 魔搭  (●) MiniMax  ( ) 硅基流动
   独立答题服务      ( ) DeepSeek  ( ) 豆包 API  ( ) 其他兼容服务
   … 这家的密钥输入框 …

④ 连接测试
   ☐ 我同意这一次测试   [ 测试连接 ]   状态：还没测过 …
```

具体改了这些：

| 原来 | 现在 |
| --- | --- |
| 一行说明 + 一个「配置 API」按钮 | 整份配置直接摆在这一页上 |
| 弹窗里两个标签页（切题与读题 / 标签与答案） | 没有标签页，两段内容一直摆在一起 |
| 厂家是一个下拉框，选完才知道选了谁 | 摆成一排勾选：谁在用、谁有密钥，一眼看得见 |
| 从题库、答案编辑器打开会弹一个窗 | 同一份配置（同一个 DOM）在两边显示，密钥和未保存的改动跟着走 |

**整份配置只有一份**（`#credentialUi`）：设置页把它摆出来，题库或答案编辑器要临时
看一眼时再把它搬回弹窗。搬的是同一个 DOM —— 不会出现"弹窗里填了一半、设置页里是
另一份"。
