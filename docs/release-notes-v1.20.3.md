# 1.20.3 本地修正版

- 采纳或拒绝 AI 标签建议后，题库会留在当前题目附近，不再把页面滚动位置重置到顶部。
- 右侧详情明确标出它对应的题卡；绿色边框和柔和光晕突出当前题目，并可点“定位题卡”返回该题。
- AI 标签任务失败时，可在失败提示旁直接重试。通用本机错误不再一律提示检查服务商、密钥和模型；同一失败原因也不再重复显示两遍。
- 题库侧栏保留待核对和未标知识点的快捷查看；会消耗 API 的批量标签与参考答案操作移到题目列表顶栏，并默认收起，展开后显示操作浮层。标签管理保持独立入口。
- 来源、题型、排序和更多筛选集中放在题目列表上方；侧栏保留搜索、全部/已选切换及标签快捷查看。更多筛选作为浮层打开，不推动题卡；窄屏自动换行。
- 常用筛选的保存、删除操作并排放在筛选选择框下，避免和批量 AI 操作混排。

截图中的 AI 任务没有保存结果，说明生成任务在本机执行过程中失败。应用把未分类异常统一显示为“本机生成任务未完成”，该提示本身无法判断问题来自 API 配置、服务响应或本机任务执行。此前前端又对所有失败都附加“检查 API 配置”，这会造成误导。新版修正了这个提示，但无法仅凭截图还原当时隐藏的具体异常；若重试仍失败，需要保留的本机诊断记录才能进一步定位。

本版已使用隔离的虚构题库完成浏览器验收，确认采纳后保留滚动位置、题卡高亮和定位按钮正常；并验证桌面与 390px 窄屏下的顶部筛选布局，测试未连接外部 AI 服务。本版尚未公开发布或自动升级已安装程序。
