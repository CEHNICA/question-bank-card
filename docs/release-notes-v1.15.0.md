# 题有据 1.15：修复 PDF 导出

本版以 **v1.14.3** 为基础，程序版本为 **1.15.0**。

修复 Windows Edge 在启动时重新拉起自身，被误判为“本机浏览器未能启动 PDF 排版”，导致 PDF 导出失败的问题。PDF 与 Word 公式图片共用受控浏览器启动，保留独立临时配置、联网屏蔽和导出后的进程清理。

同一修复代码已通过 Windows 后端 1514 项、前端 101 项、桌面与打包 125 项检查，合计 1740 项。Edge 和 Chrome 的真实浏览器回归全部通过；临时移除修复参数后，Edge 测试能准确重现原故障。

发布安装包还须以全新隔离数据完成实际选题、预览与 PDF 下载验收。原卷、题库、凭据和测试运行目录不随发布附件上传。

本版包含 v1.14.3 基线与此次 PDF 修复，未纳入后续 main 分支的配图改动。升级前请备份题库、关闭程序，再运行 `TiYouJu-Setup-1.15.0.exe`。

附件包含 Windows 安装包、对应应用源码、PyMuPDF/MuPDF 对应源码、第三方许可证、一键安装脚本和 SHA-256 校验文件。
