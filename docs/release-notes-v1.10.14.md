# 题有据 v1.10.14

把项目地址发给能操作电脑的 AI 助手，就能从首页进入安装与上手流程，不必额外指定先读哪个文件。具体安装仍遵循当前助手的权限与用户已有选择。

- **AI 安装有完整收尾**：核验软件和命令行的实际版本后，告知安装结果，一次询问配套技能与桌面图标，直接邀请以后发题。旧版本会先探测能力，已有较新软件不会自动降级。
- **技能、图标真的能设置**：新增 `tiyouju assistant-setup`，默认只读。用户选定后安装完整配套技能，定制内容先备份；桌面图标可显示、隐藏、恢复，只操作题有据自己的快捷方式。
- **新版教学一起发布**：基础练习与新功能回顾分开，包含原卷缩放拖动、改字时的预览定位、框选识读推荐、出处与版本历史、未保存提醒。内置示例不用密钥，也不会生成假的 AI 识读结果。

GitHub 首页也已简化，五张展示图都来自同一套实际使用的试卷。此前仅在源码更新的 1.10.9–1.10.13 改进随本版安装包提供，详见 [更新记录](../CHANGELOG.md)。

下载安装包覆盖升级即可，题库、原卷与用户设置会保留。一键安装脚本会核对 SHA-256 并先备份题库；默认不新建桌面图标，已有图标可在收尾时按用户选择处理。

MinerU 暂不可用时，可以练习示例、核对已有题卡、查看出处、搜索和组卷。本版验证了安装收尾、本地操作与正常功能回归，未宣称云识读服务已恢复。

完整安装方式见 [使用指南](使用指南.md)，AI 入口见 [AGENTS.md](../AGENTS.md)。
