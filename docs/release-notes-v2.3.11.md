## 题有据 2.3.11 更新说明

### 更新亮点

1. **录题界面视觉重塑与窗口统一**：
   - **智能分屏与顶部减负**：打开左侧「对照原卷」分屏画布时自动隐藏题卡内重复的原卷缩略图，让题干、公式与底栏操作按钮舒展排成一整行；顶部步骤条收拢为轻量行内面包屑，桌面端工具栏恢复清晰文字标签并修复分屏重开时底图首帧绘制问题。
   - **统一现代设置弹窗与原卷工作室**：录题页点「设置」直接弹出与题库工作台一致的双栏设置弹窗（去掉多余进度条、仅由右上角 `✕`/`Esc` 关闭）；录题原卷窗顶部新增 **`调整范围 ｜ 管理配图 ｜ 框选识读`** 一键互切分段条；升级现代分组「试卷操作」菜单，合并重复编辑按钮并简化「只切图，不转文字」文案。
2. **国内 AI 助手（豆包 / WorkBuddy / MiniMax）一键接入**：
   - 新增 **WorkBuddy、MiniMax Agent、CodeBuddy（`.mcp.json`）** 自动探测与 `tiyouju skill-pack` 一键拖入技能包 `tiyouju-skill.zip`，官网与软件内「帮助 → 连接 AI 助手」提供 3 步交互引导与一键复制指令（清晰区分 0 密钥直用与 MinerU 切图+助手核对两档协作），API 配置显式标注「交给 AI 助手」。
3. **题库工作台细节打磨**：
   - 优化侧栏拖拽分隔线（告别宽绿光柱）并允许将左右侧栏调窄至 `150px` / `180px`；修复工作台「关于」更新检查接口，改进重框弹窗防误触关闭及退出编辑器回流闭环。

### 验证范围

- `ruff check`、`ruff format --check`、`mypy`、`npm run lint`、前端 `node --test`、根目录 `unittest`、Django `core` 单元测试与官网深色主题自适应检查全部通过。
