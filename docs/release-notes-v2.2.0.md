# 题有据 2.2.0 更新说明

## 重点更新与整合

1. **导出 Word 排版像素级对齐打印预览**
   - **题干、选项与表格精准还原（`library_export.py`、`exam-export.js`、`library.js`）**：同步导入前端预览实测尺寸与位置（选项栏数、图宽、表格横向偏移、留白分段），Word 侧补齐题号两栏悬挂缩进对齐正文列、表格行高/内边距/对齐/列宽（含 dense 密表）/边框表头样式、单栏选项行高、考生信息行卷面字体与自然宽度、页首与大题页首落位、页脚样式、相邻块间距「预览相加」模型，以及关闭行末标点溢出边界（`overflowPunct`）。
   - **答题留白与答案区节奏对齐**：答题留白改用固定行高并切分为可跨页断开的单行段，跨页时自动补充「第 N 题答题区（续）」标题，答案区纵向节奏与打印预览保持一致。

2. **按试卷 / 书籍或目录文件夹打包题包分享**
   - **精细裁剪导出（`library_transfer.py`、`transfer_views.py`、`library-transfer.js`、`tiyouju_cli.py`）**：数据备份与迁移支持在「整库」「选定试卷/书籍」「选定目录文件夹（含子目录）」之间切换；自动剔除回收站废题、校验外键一致性，并按题包名自动命名压缩包，接收方可通过现有「备份恢复」合并导入。
   - 同步提供 `GET /api/backup/papers` 接口以及 CLI `tiyouju backup --paper` / `--folder` 参数支持。

3. **OneNote 联动加固与答案编辑细节优化**
   - **多次回跳不失灵（`eagle/index.html`）**：窗口重新回到前台（`focus` / `visibilitychange`）时自动重开一波深链轮询（`armDeepLinkPollingFromFocus`），多次从 OneNote 跳转回题有据均可正常定位。
   - **源码协议入口不弹外置浏览器（`tiyouju_protocol.py`）**：源码运行模式下 `tiyouju://` 协议注册改走窗口启动器且默认不额外弹出系统浏览器。
   - **经典题库页单题编答案停在本题（`library.js`）**：单题入口保存答案解析后停留在当前题目，不再自动跳转至下一道缺解析题目。
