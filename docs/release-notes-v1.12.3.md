# 题有据 1.12.3

本次修复 MinerU 自动录入偶发中断与少切题后无法恢复的问题，并更新审核导航提示。

## MinerU 解析后不再把已读页面当作手工页

扫描件导入时，本机没有文字可用，所以页面先标记为手工页。MinerU 返回文字后，旧流程没有更新页面标记，下一步切题便跳过了这些页上的题目，甚至可能一张题卡都没有。

现在根据 MinerU 实际返回的分页内容更新页面状态：读到文字的页面继续自动切题；没读出内容的页面仍保留手工处理，并明确列出页码。如果一题都没有切出，会标明原因，同时保留原卷和已保存的题卡。

若解析结果已经保存在本机，切题失败后可点“继续 AI 切题”重用现有结果，不必再次上传原卷；也可直接改为手工框题。

## 等待 MinerU 时的数据库锁冲突不再终止整次任务

等待云端时定时保存进度只是辅助状态。SQLite 遇到 BUSY/LOCKED 时，现在只跳过这一笔心跳；下一次心跳会继续尝试。任务取消、解析结果和其他关键写入仍按原有规则处理，非锁冲突错误也会继续报告。SQLite 的常规事务设置保持不变。

## 审核导航与提示

按 N 直接前往下一道仍需核查的题，跳过已经通过的题；到当前范围末尾后会继续从前面查找。快捷键说明和页面提示已同步更新。

- 前端：93 项通过
- 桌面启动器：125 项通过
