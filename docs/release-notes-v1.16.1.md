# 1.16.1：已有题框直接修改题号

基于本地 1.16.0 校正功能，补上已有题框的改号入口；保留 Windows PDF 导出修复。本版本为本地验收包，公开下载状态以 Releases 为准。

## 怎么修改

1. 在“查看整份原卷”里点选题框，重叠时先选具体题目。
2. 点左侧“修改题号”。
3. 在“新题号”输入框中填写号码，例如把 14 改成 4。
4. 点输入框下的“保存题号”，或顶部同名按钮。输入时按 Enter 或 Ctrl+S 也可保存。

保存后回到原卷总览，题框标签和题目列表一起更新。同一道题的跨页、跨栏片段共用题号；不能给其中一个片段单独编号，确属两道题时应使用拆题。

## 保存与保护

- 仅修改题号，保留题目身份、范围、颜色、题文、人工配图、题型和已有识读历史。改号时隐藏移动、缩放、添加和删除题框入口。
- 题号为 1–999 的整数。同组现有题和普通回收站里的题号需要避开，布局历史中的旧题允许让出题号。重复或无效号码会阻止保存并保留草稿。
- 题号未变时不提交保存，也不增加版本。
- 真正改号后需要重新核对。旧入库快照和组卷保持原题号；过期识读建议不采用，不自动发起识读。
- “已保存的调整记录”可以撤销最近一次改号，重新打开后仍可用。若后来修改了题文、范围、审核或识读结果，撤销会拒绝覆盖新内容；审批和已取消任务不自动恢复。
- 使用统一布局版本、完整题目指纹和唯一请求编号。两个窗口冲突、连接中断或同一请求重试不会生成第二道题或覆盖后续成果。

验收使用隔离生成的虚构试卷及数据库；安装包不会附带真实题库、样卷或密钥。
