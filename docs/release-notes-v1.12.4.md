# 题有据 1.12.4

本次改的是一件事：**让界面只说自己真的知道的事**。外加一处「标签与答案」API 配置的重做。

## 试卷列表和审核页的「要看」数必须一致

这是老师截图指出来的又一处自相矛盾。一份 25 道题的卷子，左边列表写「25 题 · 4 张要看」，点进去顶部却是「需要核查 25」「0 / 25 已完成」。

两个地方在数不同的东西。审核页的「需要核查」把**识读干净但还没打勾**的题也算进去——读得没问题，可人还没看过，当然要看。列表只数了黄色和红色（识读有疑问、识读失败），等于宣称那 21 道不用看。

**以审核页为准**，而且不再由两处各自数一遍：后端直接下发「已完成 / 还要看」两个数，列表的窄条、列表那行文字、读完提示、「下一份」按钮全部用同一个来源。这两个数的定义是：

- **不用再看**：打了勾的，或者题库里已经放着和题卡一模一样的版本
- **还要看**：其余已经切出来的题——识读干净的、识读有疑问的、识读失败的
- **两边都不算**：还在识读、谁都没看过的

三档之和恒等于总题数，任何一份卷子都验过。

## 已入库的题不再算「要看」

一份 10 道题的卷子，每道都已经原样进了题库、勾也早就没了，界面上却同时写着「已入库 10」和「3 张要看」——同一句话里自相矛盾。

现在一道题算「不用再看」的条件是：打了勾，**或者**题库里已经放着和题卡一模一样的版本。判据是题库那份的版本和题卡内容逐字对得上，所以入库之后又改过题的，仍然回到「要看」那一栏；正在框、没保存的草稿也不算。

影响到的措辞全部改成同一个口径：

- 试卷列表的窄条只有两段：**不用再看**（绿）和**还要看**（橙），鼠标停上去写明「不用再看 21 · 还要看 4」
- 试卷列表那行文字：全处理完的卷子写「10 题 · 已入库 10」，不再写「已通过 10」这种没打过勾的话
- 审核页顶部的筛选页签由「已通过」改成「已完成」，点进去看到的题数与页签上的数字一致（以前页签写 10、点进去是空的）

顺带修掉一处：**还在识读、谁都没看过的题，不再被算成已经看完**。一份正在读的卷子不会显示成全绿。

## 上传区那行常驻提示去掉了

「先在本机切题；经你允许后，也可使用已配置的云服务。」——云服务配好之后，这行字一直挂在上传框下面，说着一件你早就知道的事。它已经不在了。真到了会把资料发出去的那一步，弹窗里本来就会写清发送范围。未配置云服务时那句「自动判断资料，先在本机切题；未切出的题可以从原卷选取，无需密钥」保留。

## 「标签与答案」的 API 配置改成一家一块

原来这一栏是「一个服务商下拉 + 一个 API Key 输入框 + 一张跨服务商的已保存密钥小表」，填之前得先想清楚该选哪家。现在照「读题与切题」那一栏的形状，DeepSeek、MiniMax、豆包、其他兼容服务各占一块：

- 每块有自己的状态、已保存密钥的遮罩行（带眼睛图标）、新密钥输入框和删除按钮
- MiniMax 那一块直接写明「可以共用读题的密钥」，并给出「改用读题的 MiniMax 密钥」按钮
- 没存过密钥的那家显示「未保存 · 暂无已保存密钥」，不显示删除按钮

好处是填错服务商不再可能：填进哪一栏就是哪一家，保存时一起落盘。删掉一家不会影响其他家，也不会把正在用的那一家打回「未测试」。

## 切题对账整套去掉

1.12.2 会在每次自动切题后做一次对账：把卷面上印着的题号跟真的切出来的题号比一遍，然后点名「原卷上印着第 33、51 题的题号，但现在还没有对应的题卡」，并给一个「在原卷上补切」按钮。**整套已删除**，包括题号扫描、四种结论、「切题不全 / 切题待核对」两个标签和那行横幅。

为什么删而不是修：卷末的答案解析同样印着「33.」「51.」，而文字层里没有任何东西能说明哪一行是题、哪一行是答案。实测一份 25 道题的卷子，答案解析里的两条被当成了漏题。老师看到一次不实的「漏题」，就再也不会相信旁边那句同样重要的「待你终审」——这比不说更糟。

保留下来的只有一句不依赖任何猜测的事实：**一张题卡都没切出来时，任务失败，并写明本地为什么没切出来**。失败行仍把「继续 AI 切题」放在最显眼的位置（复用已存的解析结果，不重新上传、不再花一次额度），并保留「改为手工切题」。

代价说清楚：一份只切出 2 张卡、实际有 24 题的试卷，现在会显示「待你终审」。真要补题时，用试卷操作里的手工切题即可。
