# 题有据 v1.11.0

这次把正式题库改得更适合日常备课：先浏览、再选题，选好的练习可以起名字保存，下次接着做。本轮先做本地升级和验收，暂不发布 GitHub 安装包。

- **找题更清楚。** 列表先显示题目摘要，点“完整题目”查看全部条件、选项和配图。来源、题型和排序放在前面，其他条件收进“更多筛选”；支持最近入库、原卷顺序和分批加载。
- **选题时看得见试题篮。** 可以切换“全部题目”和“已选题目”，批量勾选当前已显示的题并加入试题篮。试题篮可以收起，换筛选后选题仍保留。
- **组卷能保存草稿。** 填写试卷标题、调整选题顺序和打印选项后保存，下次从“组卷草稿”继续。原来选中的版本被更新、撤回或找不到时，会提示处理；不会自动换题或静默漏题。默认不附 AI 参考答案。
- **标签与参考答案单独设置。** 两项默认关闭，使用独立的“标签与答案设置”窗口。需要已接通、验证可用的豆包 Pro API；没有可用豆包就暂停生成，只提供 DeepSeek Pro 接入建议。配置保存和可能计费的测试分开，不自动切换到其他模型。
- **教学跟着界面更新。** “设置 → 帮助 → 只看新版功能”补充题目摘要、试题篮、组卷草稿和独立 AI 窗口的说明。保留已有教学进度；示例不进入正式题库，教学不发起识读、生成或付费测试。
- **桌面图标入口修复。** 优先使用已安装的软件创建图标，支持 Windows 桌面重定向；遇到旧安装或同名冲突时明确报错，创建后核对目标，不覆盖无关快捷方式。

原卷出处、版本历史和人工核对记录继续保留。MinerU 云端识读是否可用，仍以实际账户和真实任务结果为准；本次界面升级不代表该服务已经恢复。
