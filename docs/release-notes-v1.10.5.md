# 题有据 v1.10.5

点“入库”后，按钮上显示进度，入库也快了。

## 入库

- 以前点“入库”后，页面上什么都不变，要等全部题入完才弹出结果；一本书一次入库两三百题时，要等好几秒甚至更久，看起来像卡住了。
- 现在按钮变成“正在入库 40 / 203 题…”，旁边有转圈，每入完 20 题更新一次；入库过程中按钮不能再点。全部入完后弹出结果，和以前一样。
- 中途出错（比如题有据被关掉）时，会说已经入库了几题；没入完的题再点一次“入库”就行，已经入库的不会重复。

## 更快

- 以前每次入库都要把这份资料里所有已通过的题挨个检查一遍，内容没变的也要单独存一次。现在内容没变的题直接跳过。用一本 670 题的必修教材实测：入库 203 题从 7 秒多缩到 3 秒左右；没有新题时再点一次，也只要一秒多。
- 入库的结果和以前一样：内容没变的不出新版本，改过字的出新一版，旧版自动作废。

## 升级

已经装了题有据的，下载新的安装包直接覆盖安装即可，题库和设置都会保留。也可以运行：

```powershell
irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
```

它会下载最新版、核对 SHA-256、先备份题库，再静默安装。
