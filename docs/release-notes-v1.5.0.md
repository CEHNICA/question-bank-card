# 题有据 v1.5.0

这一版继续解决“慢”“黄卡太多”“绿卡不一定对”。同样 12 份真实试卷一起上传：总耗时从约 11 分半降到不到 10 分钟，黄卡从 64 张降到 36 张左右，并让一批原来“绿卡但读错了”的情况被补上或变成写明位置的黄卡。审核界面也重新走了一遍：笔记本和大屏上少滚、少点、少来回找。

## 更快

- **一次上传多份卷时，后面的卷提前解析**：前一份还在读题，后面的卷已经在 MinerU 解析；轮到它时直接读题。进度会显示“MinerU 已解析完 · 等前面 N 项任务读完”。
- **两份卷可以接力读**：一份卷读到最后几道题时，下一份卷就开始读，空出来的名额不再浪费。先上传的卷始终优先。
- **遇到限流不再一下子慢到底**：以前服务商一次限流可能让同时读题数从 6 个掉到 1 个、几分钟都恢复不过来；现在一次限流只少一个，约 20 秒恢复一个。

## 黄卡更少

- 第三次识读在不同位置分别采纳了两次识读的写法时，每一处都有两票支持，不再标黄。
- 同一行几张配图、读者认领的正好是按顺序分给它的那张时，不再提示核对。
- 学生画在选项旁边的草图、识读漏判的配图框、题干里连着写的选项，不再误报。
- MinerU 只在字母大小写上不同（c 和 C 这类形状一样的字母）时，不再当作疑点。

## 更准

- 选择题**漏读选项**（例如只读出 A、C、D）：另一次识读读到了就补上，否则标黄并写明“选项 B 没有读出来”。
- 两个选项读成**完全一样**的内容会标黄。
- 手机拍歪的照片，题目第一行右半截不再被切掉。
- 截图不再带进题目上方的“三、解答题（共 10 小题……）”。
- 第三次识读不再把题号抄进题面；两次识读有分歧时，裁决先看读干净截图的那一次（实测出错的裁决都跟了带配图框的那次读法）。
- AI 没找到某道题的题号、它只能和上一题放在同一张卡里时，那张卡上会直接提示“这张卡里可能还有第 N 题”。

## 审核更顺手

- **按钮不再跑出屏幕**：题卡比屏幕高时，“标记通过 / 改字 / 调整范围 / 配图”贴在窗口底边。
- **改字时原卷不跑**：改字期间原卷截图钉在上方，边看边改；保存那一行也一直看得到。
- 试卷上方的进度收成一行，第一张卡在笔记本屏幕上也能完整露出来；状态行直接告诉你先做什么（“先处理 7 张需核对的卡，按 N 逐张跳过去”）。
- 放大对照窗口里可以直接改字（E）、调整范围（R）、调整配图（F）。
- 用鼠标点了筛选标签后，J/K/Enter/空格马上能用。
- 一份卷全部通过后，会给出“下一份：××（N 张要看）”。
- 选配图归属可以直接按键：S 题干、A–D 选项、X 无关。
- “另一次识读多读了文字”会带上前后文显示，公式按排版显示；提示里有争议的那个字会高亮。
- 配图冲突的说明改成可以直接照做的一句话，不再重复两遍。

## 上传和进度

- 文件拖到窗口任意位置都能上传，拖进来时整页提示“松开即可上传”和上传方式。
- 左侧上传区变矮，“一份试卷 / 一本书、讲义”改成一个开关，能多看到几份试卷。
- 一次传多份时，别的卷在后台读完会弹出提示并可一键打开；列表里标“新”，浏览器标题显示“（2 份读完）”。

## 正式题库

- 组卷预览里可以直接调整题目顺序、移出组卷。
- “撤回”不再和“加入组卷”一样醒目；大屏上题库页面更宽。
- 设置里的版本号显示真实版本。

## 升级说明

覆盖安装即可，题库、原卷和 API 配置保留，无数据库迁移。已有题卡不会被重新识读；新规则对新任务和之后的重读生效。
