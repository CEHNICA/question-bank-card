# 1.19.0 本地验收版

本版重做正式题库的标签体系。本版本用于本机验收，尚未公开发布，也不会自动升级现有安装。

- 正式题库新增稳定身份的知识点、解题方法、自定义标签及标签组。支持别名、颜色、收藏、合并、停用、使用题数、操作历史和撤销。
- 单题和多选题共用即时标签选择器；多选清楚显示全部已有、部分已有或全部没有。标签筛选支持包含全部、包含任一和排除，并可保存常用筛选。
- AI 标签改为明确发起并进入待核对队列。知识点依据已保存题面、选项和配图；方法建议读取当前采用的已保存解析并标明整题或小问。逐条人工采纳前不会写入正式标签。
- 移除设置页中旧的文本目录预览和“新题入库时自动生成标签”控件。新题、题卡打开及人工改标签不会自动调用 AI。
- 旧 AI 标签迁为候选；来源不明或无法唯一匹配的旧标签留在历史标签中。题卡版本、原始题文和审核结论不因标签迁移或编辑而改变。
- 保留 PDF 导出修复及现有题卡和人工内容。

初高中目录范围和标签定义见[正式题库标签目录覆盖表](./正式题库标签目录覆盖表.md)；迁移规则和本机报告见[旧标签迁移映射说明](./旧标签迁移映射说明.md)。本版本不包含公开发布。
