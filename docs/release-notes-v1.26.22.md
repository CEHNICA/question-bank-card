# 1.26.22：自动备份加了开关，也说清楚它到底救什么

**老师问：「这个快照的功能有什么价值吗？怎么感觉用处不大呀。」**

这句话问得对。先把账算清楚。

## 一、它到底救什么、不救什么

**救的（也就是它唯一的价值）：「题库自己坏了」。**

- 软件出 bug，把题库改乱了；
- 升级迁移出错，829 道题被改坏；
- 磁盘写满或写坏，数据库损坏 —— **这一条就在上周真的发生过**：
  磁盘被撑满时 SQLite 报了 `database or disk is full`，题库页全 500。
  那次数据库没坏掉，运气好；坏掉了的话，只有这份备份能救。

**不救的（老师感觉没用，是对的）：**

- **误删的题**：软件有回收站，删错了能捞回来；
- **原卷 PDF**：那是你自己的文件，在你自己硬盘上，跟这个备份无关；
- **两台电脑同步**：那是另一件事（还没做）；
- **硬盘坏了、整台电脑没了**：备份包也在这块盘上，一样没；
  要防这个得自己导一份到 U 盘。

所以它是一张**便宜的保险**：平时一点用没有，出事那天才有价值。

## 二、这一版做了什么

1. **卡片里加了一个开关：「每天自动打一份备份」**
   —— 用不上就关掉，它不会再自动占磁盘；关掉以后「现在备份一次」照旧能手动打。
2. **卡片里用一句人话说清它救什么、不救什么**（就是上面第一节那段），
   不用再猜这个功能是干嘛的。
3. 「设置 → 题面与显示」那一区**不再重复出现**这个开关（一个开关只在一个地方）。

## 三、怎么验的

- 新增后端断言：开关默认开着、关掉时后台不再自动打、开着时照打、
  列表接口报出当前开关状态；
- 新增前端断言：卡片里有这个开关、关掉它会存到开关里并给出说明；
- 后端 2320 条、前端 134 条、shell 107 条全过；
- 真机验过：8 套卷、829 道题完好，备份照旧打得出来。

## 四、给老师的话

- 你的判断没错：**平时它确实用不上**，它只在你「软件出毛病 / 升级出错 /
  磁盘写坏」那天才有用；
- 不想要就把它关掉，**一点影响都没有** —— 手动那份、导出到 U 盘那份都照旧；
- 我个人建议开着（占 840 MB，换一个「库坏了能救回来」的机会）；
  但这是你的机器，你说了算。
