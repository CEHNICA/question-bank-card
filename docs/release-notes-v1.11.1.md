# 题有据 v1.11.1

本轮为本地升级。代码与本机合成资料联测已完成；未推送 GitHub、未发布新安装包，Releases 仍提供此前的正式版本。

- **设置集中在一处。** 录入终审和正式题库共用统一设置页，不需要重复填写；标签与参考答案的功能、执行方式和生成时机也在这里配置。
- **长试题篮也能找到预览。** 修复“组卷预览”入口被长列表挤到窗口下面的问题，试题列表单独滚动。
- **当前助手直接补内容。** 默认由当前豆包工作版或正在操作软件的 AI 助手自己看图、选标签和解题，通过本地 CLI/MCP 写回，不需要豆包 API。标签与参考答案默认关闭，结果单独保存、记录来源，参考答案仍标“未核对”，保留原卷答案和人工核对记录。
- **生成时机可以选择。** 新题录入并入库后自动处理、后期单题、勾选批量都可使用。新题自动处理默认关闭；新版本入库后才排队，不提前给识读初稿生成答案、不因升级扫描历史题。批量逐题、按任务分别提交。
- **独立 API 可选。** 可推荐 DeepSeek，也允许豆包 API 或其他兼容模型；配置保存和可能计费的连接测试分开，不自动借用读题服务。
- **本地工具补齐任务链。** 新增 `features`、`enrich tasks/prepare/submit/auto` 和对应 MCP 工具，返回原卷与配图、知识点目录及任务指纹；题目或配图变化、功能关闭和重复提交时明确拒绝，不把旧结果写到新版本。

32 项 CLI/MCP 测试通过，其中包括合成 PDF 和隔离题库的真实本机 HTTP 写回流程。没有提交用户原卷或调用付费模型；尚未实测付费 API 的数学能力与计费结果，也没有实现或测试自动唤醒桌面豆包。助手模式保留待办，仍需当前助手实际处理并写回；安装桌面助手不等于已接通本机工具。

本次升级不代表 MinerU 云识读已经恢复，新原卷的解析仍以实际服务和账户状态为准。
