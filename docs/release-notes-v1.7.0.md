# 题有据 v1.7.0

这一版主要改了这些：只有文字和数字的表格排成题目里真正的表格；被分页切开的图可以拼回一张；审核时加了“专注”和“全屏”；题号左边的方框就是“核对完打勾”；设置重新整理成对使用者友好的几页；第一次打开有新手引导，还能用示例试卷跟着练一遍。

## 表格排成真正的表格

- **新读的卷子**：数据表、列联表、分布列、填空用的空表这类格子里只有文字、数字和公式的表格，识读时直接写进题干原来的位置，排成细线表格。它们不再当作截图配图，打印清楚，字体和题目一致，也能在“改字”里修改。被分页切成两截的表格，识读时会接成一张。表格里画着图形的仍然当作配图。
- **表格有核对**：识读写出的表格会和 MinerU 自己识别的表格逐格比对。一致的照常是绿卡；有格子不一样，或者 MinerU 没认出这张表，题卡变黄，提示“请对照原卷逐格核对表格”。空格子和格子的顺序不影响比对。
- **已有的题卡**：配图里 MinerU 认出是表格的截图，下面有“转成文字表格”按钮。点一下，表格按 MinerU 识别的内容写进题干，放在原卷上表格前面那句话的后面，截图从配图里移除。被分页切开的表格，点上下任意一截都会转成完整的一张。转完需要重新核对并标记通过；位置不对可以在“改字”里挪。
- **改字里编辑表格**：题干下面有“插入表格”“表格加一行”“表格加一列”。表格每行一行，格子用 | 隔开，第二行的 |---| 表示第一行是表头；预览里直接排成表格。有合并单元格的表用 HTML 的 `<table>`（只认 `tr`、`td`、`th` 和 `rowspan`、`colspan`）。
- 题干里已经有表格时，“如表”“填写下表”这类说法不再算作“缺图”的依据。

## 分页切开的图拼成一张

- 打开题卡的“配图”，先把上半截设为题干或选项的配图，再点下半截，在归属菜单里选“接在上一张图下面（拼成一张）”（按 J）。保存后两块上下拼成一张图，列线按原卷位置对齐。题卡、放大对照、入库和组卷里都只有这一张。
- 接上的那一块在配图窗口里是蓝色虚线框，标签写“接”；给它改选“题干”或某个选项，就又拆成单独的一张。

## 审核

- **专注（默认打开）**：正在看的这道题正常显示，其余题暗下来，题与题之间的空隙也拉大了，一眼能看出这道题从哪里开始、到哪里结束。“正在看的”跟着滚动走：工具栏下面第一张还露出一大截的卡就是它；已经通过、收起成一行的题不抢注意力。按 J/K、点“标记通过”跳到下一张时，滚动过程中不会来回闪。鼠标移到暗下来的题上会稍微变亮，点一下就换成它。工具栏上的“专注”按钮或 Z 键可以关掉；批量删除选择题卡时不变暗。
- **全屏审核**：工具栏上的“全屏”（Q）会收起顶栏、试卷列表和试卷信息，窗口铺满屏幕，只留工具栏（卷名、进度、筛选和开关）和题卡；按 Esc 或再点一次退出。
- **打勾就是通过**：每张题卡题号左边的方框，点一下就是“标记通过”，和“标记通过”按钮、Enter 键效果一样。已通过的题方框是打勾的，再点一下就撤销通过；撤销后的提示条里有“恢复通过”。配图还没处理好的题，点方框会直接带你到配图提示；识读失败或还在识读的题，方框是灰的，鼠标移上去会说明原因。
- **以前的问题**：这个方框原来是“选中准备删除”，点下去顶上会出现“移到回收站”。已经通过的题方框反而是空的，也点不了，和“已标记通过”对不上。
- **批量删除单独进入**：在“工具 → 批量删除题卡…”里进入，方框变成红色圆圈，选好后点“移到回收站”，点“完成”或按 Esc 退出。Ctrl/Cmd 点击、Shift 点击题卡仍然可以直接开始选择。切换试卷或删除完成后，会自动退出选择。只删一张，仍然用题卡上的“更多 → 删除这张卡”。
- **提示条不挡按钮**：“第 N 题已标记通过 · 撤销”这类提示条从屏幕正下方挪到右下角，不再盖住下一张卡的“调整范围 / 配图”按钮。

## 新手教学：用示例试卷练一遍

- **示例试卷**：一份 12 道题的原创示例试卷（含图、表格、数轴、英文题），随软件附带、已经读好，不用填密钥、不花额度，打开就能练。它在试卷列表里标着“练习用”，**不会进入正式题库**（点“入库”只会说明这一点），练完可以在“试卷操作”里删除。
- **跟着做 11 步**：左下角的“新手教学”小卡片告诉你这一步做什么，做对了自动进入下一步：认识题卡 → 放大对照 → 对了就打勾 → 先看有疑点的 → 发现读错的字（第 9 题故意留了一处“5 个单位”读成“3 个单位”，要你对照原卷改过来）→ 改完再打勾 → 补上配图（第 2 题的三角形图故意没配上）→ 核对表格 → 剩下的一起通过 → 入库 → 学会了。
- **指给我看**：每一步都可以点“指给我看”，自动找到要用的那张题卡，把要点的地方圈出来；圈的时候不挡操作。做错了会提示哪里不对（例如改成了“4 个单位”）。也可以“跳过这一步”或随时退出。
- **从哪里开始**：第一次打开时的欢迎窗口里点“用示例试卷学一遍”；还没有任何试卷时，首页也有这个按钮；以后在“设置 → 帮助”里可以“用示例试卷重新学一遍”（会把示例试卷恢复成初始状态）。进度记在这台电脑上，中途换到别的试卷会暂停，回来接着做。

## 新手引导

- **第一次打开**会先出现“欢迎使用题有据”：用三步说清楚怎么用（上传、核对、入库），并检查读题服务的密钥是否已经填好；没填好就有“先去填写密钥”按钮。
- **带我看一遍**：依次把界面上的 10 个地方圈亮讲一句（上传、试卷列表、题卡、打勾通过、改字和配图、筛选、专注和全屏、入库、正式题库、设置）。界面上暂时没有的地方（例如还没有题卡）自动跳过；方向键或“下一步”前进，Esc 跳过。
- 看过一次就不再自动出现，可以在“设置 → 帮助”里点“重新看一遍新手引导”。
- **标题下面不再显示技术说明**（“读题 MiniMax-M3 · 旁证 MinerU 文字 · 有出入时复核……”）。平时那里什么都不写，只有读不了新资料或连不上本机服务时才提醒一句；用哪家模型读题在“设置 → 读题模型”里能看到。

## 设置

- **分页显示**：设置分成“常用”“读题模型”“帮助”“关于”四页，一次只看一页，当前在哪一页一目了然；原来是一整条长页面，顶上的链接只会跳来跳去。
- **常用**：第一行直接说明现在能不能上传新资料；不能时写明缺哪家的密钥。三家服务各写一句是做什么的、哪个必填。下面是“专注”“放大镜”两个开关和快捷键。
- **读题模型**：注明“一般不用改”；改了自动保存，不用再找“保存模型设置”按钮，也不会因为忘了点保存而白改。各家具体的 model_id 收进“高级”。
- **密钥窗口**：去掉“账号池”“替换账号池”这类说法；每家写明必填还是可选、做什么用；输入框为什么总是空的也写清楚了；多账号和加密方式的说明收进“有多个账号？密钥存在哪里？”。
- **试卷操作挪出设置**：改名、处理记录、归档、永久删除都在试卷标题旁的“试卷操作”里；补录、重新切题、调整页序、回收站仍在工具栏的“工具”里。设置里不再有“当前任务”，也不会再出现灰掉却不说原因的按钮。
- 左侧上传框在缺密钥时多了“去填写密钥”按钮。

## 升级说明

覆盖安装即可。启动时会自动给数据库加一列，用来保存 MinerU 识别出的表格；已有题卡的文字不会被改动，旧卷子的表格要点“转成文字表格”才会转换。
