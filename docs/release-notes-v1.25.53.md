# 题有据 1.25.53：窗口按钮认对人；标签按文件夹展开

这一版接在 1.25.38 后面，把老师最近提的三件事一起做完了：窗口右上角的最小化/关闭有时候没反应或白屏、标签管理"看起来像文件夹但不像文件夹"、标签地图右边空一大片。中间几版还整理了题库顶上的数字和答案编辑的对照布局。

## 一、点减号、点叉号，作用在你正在用的那个窗口上

老师原话：「点击右上角的减号，和叉号会没有反应，或者白屏是什么原因」。

### 查到的三个原因

**1. 窗口多开过，后台认错了窗口。** 反复启动、升级会在系统里留下好几个缩成一条的旧窗口。负责执行最小化/关闭的后台线程启动时按"面积最大"挑一个窗口句柄——挑中的常常是其中一个旧窗口。老师点的是眼前这扇，它去操作另一扇，所以看起来"没反应"。

**2. 白屏是淡出之后没关掉。** 关窗时页面先淡出成白，再请后台关窗口。后台没关掉（原因见上），页面就永远停在淡出后的白色上。老师看到的"白屏"其实是页面已经隐藏、窗口却没关。

**3. 启动时窗口可能还是最小化的。** 浏览器会把上一次的最小化状态带回来，启动后只剩任务栏里一条。后台原本不会主动恢复它。

### 改了什么

- **先认当前前台窗口**：没有前台信息时挑"没最小化"的那一个，不再按面积取最大；
- **动作跟随前台**：多开过窗口时，最小化/关闭只落在老师正在用的那一扇上；
- **白屏兜底**：点叉号 1.6 秒后窗口还在，页面自动恢复显示，并再补一次关闭请求；
- **启动恢复**：找到窗口后如果它是最小化的，就恢复出来；两秒后再查一次，防止浏览器又缩回去。

### 实机验过

- 点最小化：窗口从 1920×1080 缩下去（`icon=True`）；
- 点关闭：窗口消失，后台服务随之停止，不留白屏；
- 重新启动：窗口自动恢复成 1920×1080 可见，不再只有任务栏一条。

## 二、标签管理：按文件夹展开、收起

标签本来就是文件夹、子文件夹最容易理解。原来的左侧只显示"当前所在的那一条路径"，子级和顶层同一个缩进，看起来像一堆平级标签。

- 每一层前面有 **▸ / ▾**；点箭头只展开这一层，点名字打开这一层，右边列出这个文件夹的内容；
- 进入某一层时自动展开它上面的文件夹，不会"进去了却不知道自己在树里的哪儿"；
- 一个标签挂在多个上级下只画一次；
- 第一次打开标签管理直接进「知识点」文件夹；切到「全部标签」或「用过的」会记住；
- 「全部标签」按类型分段，段头写数量和名字，段内先摆章节、再摆下一层。

## 三、标签地图：不再挤在 240 像素里

地图视图套用了"未选中标签时收起详情栏"的对齐规则，画布只占左边 240 像素，右边一千多像素全空着。修好后地图用满整幅宽度（240 → 1238 像素）。

另外：展开某个分支后，新节点会移到视野中间（不缩放，保持当前大小）；左侧树的子级按 16 像素逐层缩进。
