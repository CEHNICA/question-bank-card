# 1.26.56 —— 录入与题库工作台分流，Eagle 筛选与右键精简

## 这一版忙了什么

把「还在录入的卷」和「已经进题库的题」分开：录入页只留待完成试卷，做完自动收起；启动默认进入 Eagle 题库工作台。顺手清掉右键与筛选里重复、无效的项，并换上新图标。

---

## 主要改动

### 1. 录入与题库分流
- 录入页改称「录入题目」，侧栏只显示待录入试卷；全部入库后自动归档收起，不再和题库混在一起。
- 归档不再被回收站题卡挡住；卷收起后，回收站里的题仍可找回。
- 桌面启动与命令行启动默认打开 `/eagle` 题库工作台；切题核对仍在 `/`。

### 2. Eagle 右键与筛选
- 题卡右键去掉界面上已有的收藏、试题篮、核验证据、展开解析等重复项。
- 生效筛选条件改到工具栏下方独立一行；智能视图不再叠出两颗相同芯片。
- 移除「疑似重复」视图；题型筛选 code 与入库一致（解答/填空/单选/多选都能筛到题）。

### 3. 品牌图标
- 更新 `assets/app-icon`、安装包/程序用的 `app.ico`，以及前端 `favicon.png`。
