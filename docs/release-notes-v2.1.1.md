# 题有据 2.1.1 更新说明

## 修复与改进

1. **修复高分屏启动画面与图标分辨率偏低问题**
   - 启动窗口（`app_window.py`）启用 Windows 系统 DPI 感知，并按系统缩放比例等比放大启动窗口与进度条尺寸；启动图标改用 Pillow `LANCZOS` 高质量重采样，替换原最近邻抽样缩放；任务栏大/小图标分别按系统指标尺寸加载。
   - 录题欢迎弹窗与正式题库页顶栏图标统一升级为 `256×256` 高清品牌图标（`/app-icon-256.png`）。

2. **帮助系统同步更新至 2.1.x 功能**
   - 更新录题页「设置 → 帮助」、欢迎弹窗、自动切题入门弹窗与快捷键参考（`shortcut-help.js`），补全左右分屏对照原卷画布与双向定位、顶部三步导航、拍照多图调序与 90° 旋转、安全移入回收站、已入库题卡直达 Eagle 编答案以及批量识读断点续读说明。
   - Eagle 题库工作台（`/eagle`）主菜单及快捷键窗新增「工作台使用指南」弹窗，覆盖智能文件夹、右键悬停飞出菜单、统一答案编辑器、OneNote 联动、界面缩放与保真导出说明。

3. **修复批量识读进度统计、已撤回记录拦截与断点续读**
   - 修复 `cutReadingSummary` 将已转文字的切题卡片和受保护原图题漏计导致「已完成」始终显示 0 及进度差额的问题。
   - 修复批量识读接口 `paper_read_cut_questions` 误将已撤回（`withdrawn`）或被替代入库记录当作在用记录拦截的问题，并与单题接口、护栏判定统一口径。
   - 改进 `read_questions` 队列标记时机，仅在题卡真正提交线程池执行时清除 `reread_requested`，确保中途退出重开后未开始的排队题自动续读；并对前端兜底提交与后端批次收尾写库补充 SQLite 锁冲突退避重试。
