# 1.26.2：撤掉一套按钮

1.26.1 的规矩是"标题栏够不着时页面才画按钮"，但有个漏洞：**页面自己不知道
它是在题有据的窗口里，还是在别的标签页里**。在别的标签页里打开题有据，那个标签页
**自己也没有标题栏** —— 老师看到的正是"按钮没了，怎么关、怎么缩"；可页面以为
"标题栏还在"（那是应用窗口的标题栏，不在眼前），就把按钮藏起来了。

现在分得清了：

| 页面在哪 | 眼前的标题栏 | 页面右上角 |
|---|---|---|
| 题有据自己的窗口 | 有（自带三个按钮） | **不画** —— 两套并排会让人不知道点哪个 |
| 题有据自己的窗口，整屏显示（F11）或拖到屏幕边缘外 | 够不着 | **画出来顶上** |
| 别的浏览器标签页 | 那个标签页自己也没有 | **画出来** —— 从那儿关掉软件的唯一出口 |

"我在题有据自己的窗口里"这个标记由启动器给的：它打开窗口时用
`http://127.0.0.1:8768?qbhost=app`，页面记在 sessionStorage 里，页内跳转也不丢。

## 怎么验的

- 前端：三种情况各测一遍（自己的窗口 / 整屏 / 别的标签页），按钮该出现时出现、
  不该出现时不出现。
- 后端 2279、前端 132、shell 150，全过。
