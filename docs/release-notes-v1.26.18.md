# 1.26.18：修掉老师反馈的两处界面毛病

## 一、「删除密钥」压在「测试连接」上

1.26.15 把 API 配置改成"服务商一行式"之后，服务商卡片里那行「删除密钥」是**绝对定位**
在卡片左下角的 —— 而卡片底部正好是「测试连接」那一行。两个按钮叠在了一起。

**为什么平时发现不了**：只有**已经存过密钥**的账号才会出现「删除密钥」这个按钮。默认
状态下所有服务商都是"未存密钥"，按钮根本不显示。存了密钥的人一进设置就能看见。

改成正常排在流程里（右下角），不再绝对定位：

```
┌──────────────────────────────────────────────────────────┐
│ MiniMax API Key        1  ************            [ 👁 ]  │
│ 填写可用于视觉模型的 Key                                  │
│ 已保存 1 个            新的 Key（留空就不改）               │
│                        [ 粘贴 MiniMax 开放平台里复制的 Key ]│
│                        模型名称  [ MiniMax-M3 ]           │
│                        ☐ 我同意这一次测试（会向服务商发一张…）│
│                        [ 测试连接 ]                      │
│                                              [ 删除密钥 ] │
└──────────────────────────────────────────────────────────┘
```

「测试连接」和「删除密钥」现在各归各位，谁也不压谁。

## 二、同一句"配图没在原卷目录里"连着出现两遍

一道题缺了两张配图时，原来会连着出现两句**一模一样**的话：

```
这道题的配图没在原卷目录里。题面和答案不受影响；点「查看出处」可以回到原卷核对，或重新切一次这道题的图。
这道题的配图没在原卷目录里。题面和答案不受影响；点「查看出处」可以回到原卷核对，或重新切一次这道题的图。
```

看着像同一句话重复了两遍，其实缺的是两张不同的图。现在说清是哪一张：

```
这道题的题干配图没在原卷目录里。题面和答案不受影响；点「查看出处」可以回到原卷核对，或重新切一次这道题的图。
这道题的第 2 张题干配图没在原卷目录里。题面和答案不受影响；点「查看出处」可以回到原卷核对，或重新切一次这道题的图。
这道题的选项 B 的配图没在原卷目录里。题面和答案不受影响；点「查看出处」可以回到原卷核对，或重新切一次这道题的图。
```

原话不变，只是加上了是哪一张 —— 题面和答案不受影响这句话照旧。

## 怎么验的

- 复现过按钮重合：往隔离的开发环境里存了一把假密钥（开发库里本来没有已存密钥，
  所以按钮平时不显示），量出两个按钮的矩形确实相交（`overlap=true`），改完再量
  `overlap=false`，界面上也看了；
- 新增前端断言：缺失配图的提示三张图各说一句、互不相同，且分别说清"题干配图"、
  "第 2 张题干配图"、"选项 B"；删除密钥那行不再绝对定位；
- 前端 134 条、后端 2307 条、shell 107 条全过；
- 开发环境里那把假密钥已经清掉，老师的真密钥从头到尾没有读过一次。
