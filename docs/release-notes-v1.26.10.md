# 1.26.10：审计查出的两个真回归，修了

1.26.9 把 API 配置改成"整份平铺在设置页上"之后，请了四个子代理去查：
一是别的题库和 AI 客户端怎么摆 API 配置，二是把我们自己 1.26.9 的代码审一遍。
审出两个真回归 —— 都是我自己引入的，不是老问题。

## 一、离开设置页时，刚填的密钥会悄悄消失（阻断级）

平铺之后，这一页就是 API 配置的所在地。离开这一页的守卫（`prepareSettingsLeave`）
查了模型设置 ✓、查了标签与答案的开关 ✓，**独独漏了新填的读题密钥** ✗。

现象：在 设置 → API 配置 粘了一个新 Token → 点「返回题库」→ 没有应用内那句
"API 配置还没保存"的询问 → 点离开 → Token 无声消失。

（弹窗路径和浏览器原生卸载都查了，只有平铺这条路漏了 —— 因为弹窗关得掉，
平铺的这一页是新加的。）

**现在**：离开这一页时，只要有没保存的密钥，就问一次，和标签与答案的开关用同一套问法。

## 二、弹窗里的「取消」按钮点了没反应（阻断级）

1.26.9 把整份配置抽成一个可搬动的块之后，它从弹窗里搬了出去，成了弹窗的**兄弟**
而不是子节点。而「取消」按钮的接线是加载期求值的 `document.querySelectorAll("dialog [data-close]")`
—— 那一刻它还在弹窗里 ✓，现在匹配不到了 ✗ → 那个按钮**从来没被绑上监听器**。

（对照 1.26.8 的 index.html 就看得出来：那时这个按钮在弹窗内，接线正常。）

**现在**：给按钮一个 id，显式接线。

## 三、顺带修掉的几处

| 问题 | 现象 | 现在 |
| --- | --- | --- |
| 弹窗关掉后设置页上的配置整块消失 | 从设置页打开弹窗再关掉，配置就没了，只能刷新 | 关掉时把配置块还回设置页 |
| 旧书签 /settings#ai、#api 首屏不滚到答案区 | 直接打开或刷新时滚的是空气 | 等配置块挂上来再滚 |
| 勾选行在服务列表没读到时"勾了又弹回去" | 点一下瞬间弹回 | 列表没读到之前不让勾（服务列表到了就放开） |
| 答题侧的勾选行忙闲不分 | 保存中还能勾，勾了被服务端状态覆盖 | 跟着忙闲走 |
| 「共保存 N 个密钥」在平铺时看不见 | 那行还在弹窗标题里 | 挪进配置块，两种摆法都看得到 |
| 临时弹窗会把刚填的密钥清空 | 在设置页填一半，弹窗看一眼就空了 | 有草稿就不清 |
| 仓库自带的浏览器脚本还在点已删掉的 id | 那些 QA 脚本一跑就错 | 全部改成新界面 |

## 四、补的测试

新加了 `test_credential_inline_move.js`（4 组断言），钉住三件事：

1. **整份配置只有一份** —— 设置页摆出来 → 弹窗借走 → 关掉还回来；
2. **离开这一页时没保存的密钥会被拦下**（并能选择放弃还是留下）；
3. **弹窗里的「取消」按钮点得动**；
4. **服务列表没读到之前勾选行不让点**。

假 DOM（`credential-test-dom.js`）也补上了"append 就是移动"的语义 ——
之前它只 push 不换爹，所以"只有一份"这类断言根本写不出来。
