# 1.21.0 本地验收记录

验收日期：2026-10-11。基于 1.20.3 当前工作树，成品版本为 1.21.0。本次没有公开发布、推送远端、执行安装或升级现有用户环境。

## 已实现

- 任何层级标签均可贴题，同类型多父关系保持稳定身份；知识点、方法层级与个人分组分开。
- 共用悬停／聚焦／触屏浮层，箭头浏览、名称即替换当前单条关联；相关方法走添加入口。
- 保存、采纳和撤销局部更新，保留阅读位置、勾选、当前详情与浮层；不匹配题暂留，不计入匹配数量及分页。
- 目录维护支持子标签、增删或移动一条父级、相关方法；循环拒绝，删除父节点保留子节点；历史保护撤销。
- 全部／任一／排除包含后代并按题去重；父级直接关联不推断到某个子级。
- 显式层级模板导入复用旧身份、增补关系，保留改名、个人分组及原有父级；预览显示祖先依赖，不隐式修改旧目录。
- AI 建议保留生成时目录快照，新候选由用户确定父级或明确顶级后采纳；已处理建议不会因改目录重新出现。
- 保存版本、状态核验、原子替换、方法范围合并、请求去重和持久撤销保护原成果。
