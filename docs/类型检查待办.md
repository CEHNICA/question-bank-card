1. 跑 `.\dev.ps1 type` 看当前结果（已进门禁的模块必须零错误）。
2. 要看某个模块的明细：

   ```powershell
   python -m mypy --config-file pyproject.toml --no-pretty backend/core/segment.py
   ```

3. 改完一个模块，把它从 pyproject.toml 的清单里删掉，再跑一次 `.\dev.ps1 type`。
