# 题有据 v1.10.7

试卷在 MinerU 那里等太久时，可以“重新交给 MinerU 解析”。

## 重新交给 MinerU

一份试卷平时交给 MinerU 后 10–20 秒就有结果。MinerU 那边忙或者这一次卡住时，以前只能干等，等 20 分钟超时后再点“重试”。

现在有两处可以让它重新来：

- 在 MinerU 那里等了 1 分钟以上，进度说明下面会出现 **重新交给 MinerU** 按钮；
- 只要还在“MinerU 解析中”，**试卷操作** 菜单里也有 **重新交给 MinerU 解析**。

点了以后，题有据不再等原来那一次的结果，几秒内把文件重新上传给 MinerU，进度又从“正在把文件传给 MinerU”开始。MinerU 很忙的时候，重新上传后也可能要排一会儿队；进度上会写“在 MinerU 排队中 · 已等多久”。

一本书分片解析时没有这个按钮：哪一片出错，可以单独重跑那一片。处理失败的试卷照旧点“重试”。

## 升级

已经装了题有据的，下载新的安装包直接覆盖安装即可，题库和设置都会保留。也可以运行：

```powershell
irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
```

它会下载最新版、核对 SHA-256、先备份题库，再静默安装。
