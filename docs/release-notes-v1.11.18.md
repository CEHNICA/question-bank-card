# 1.11.18：PDF 分页、逐题导航与故障恢复

- 修复紧凑组卷中答题留白整块移到新页、产生空续页的问题。留白可跨页分配，保留所选的总长度；预览与 PDF 使用相同分页结果。公式字体载入失败时明确提示重试，不使用错误字体冒充有效预览。
- 导出设置新增“选择文件夹”，选中后回填路径，保存后用于 Word/PDF；“打开已保存文件夹”负责打开当前目录。
- N 每按一次按当前筛选顺序前进一题，输入文字、组合输入或长按不会误跳。
- 基础操作提示只需看一次，可以选择永久关闭，并在“设置 → 帮助”恢复；真实故障与未保存提醒继续显示。
- 移除批量通过按钮，保留单题核对通过后自动入库；继续手工切题只保留一个主要入口，“继续 AI 切题”移到“试卷操作”菜单。
- 修复继续 AI 切题遇到 MinerU 故障后，重试因已有手工题而跳过解析的问题。重试继续补切，原卷与已有题目、人工修改和入库版本保留。
