# 1.26.1：两套按钮不会同时出现

1.26.0 把窗口按钮放回页面右上角，解决了"整屏显示时标题栏够不着、没法关没法缩"的问题，
但**没管住"标题栏明明还在"这种情况** —— 页面上三个、标题栏上三个，两套并排。
这正是 1.25.90 当初删掉页面按钮的理由（"两套控件并排会让人不知道该点哪一个"），
1.26.0 把它推翻了。

## 现在的规矩

宿主（启动器）一直守着窗口，窗口一变就把"标题栏还在不在"写进
`%LOCALAPPDATA%\QuestionBankCard\data\window-state.json`；页面照着办：

| 窗口的样子 | 标题栏上的按钮 | 页面右上角 |
|---|---|---|
| 普通窗口 | 有 | **不画**（避免两套并排） |
| 最大化 | 有 | **不画** |
| 整屏显示（F11） | 没了 | **画出来顶上** |
| 拖到屏幕边缘外面 | 够不着 | **画出来顶上** |
| 普通浏览器标签页 | 没有 | **不画**（背后没有可操作的窗口） |

窗口在"整屏"和"普通"之间来回切，页面会跟着变（听尺寸变化，不用刷新）。

## 怎么验的

- 真机上：把题有据的窗口撑成整屏 → 页面接口从 `caption: true` 变成 `caption: false`；
  还原 → 又变回 `true`。
- 后端 `manage.py test core`：**2279 项全过**；前端 **132 项全过**；shell **149 项全过**。
