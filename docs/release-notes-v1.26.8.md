# 1.26.8：连接测试那块，逻辑重做一遍

## 原来是什么样

设置 → API 配置 → 标签与答案，最下面那块写着「保存后，测试一次连接」：

- 一个勾选框：「同意发起一次 API 测试」—— 单独占一行，长得**和上面那些功能开关
  一模一样**（「允许 AI 生成标签建议」「补充 AI 参考答案」都是这个样子 ✗）；
- 一个灰着的按钮：「测试连接」。

问题是这块地方**什么都不说**：

1. 勾选框长得像功能开关，老师当成"又一个开关"勾了 ✓ —— 测完它又自己弹回去
   （每次测试都要重新同意，这是对的 ✓），看着像出 bug ✗；
2. 按钮为什么灰着不说：是还没保存？还没填密钥？还是没勾同意？—— 只能猜 ✗；
3. 「保存后，测试一次连接」把顺序写成了前提，可界面上看不出自己现在处在哪一步 ✗；
4. 状态在**上面另一张卡**里（"已测通 / 已保存，未测试 / 缺密钥" ✗），要来回找 ✗。

## 现在是什么样

**一块卡只说一件事**：这次测试的状态，和下一步该做什么。

```
连接测试                                    还没测过
测试只发送软件的合成题和合成图，不发送你的试卷。可能消耗服务额度；
测通后才能生成，生成的答案仍要人工核对。

☐ 我同意这一次测试（会向服务商发一条合成题）      [ 测试连接 ]

这一家还没保存密钥或模型：先在上面填好，保存之后再测。
```

具体改了这些：

| 原来 | 现在 |
| --- | --- |
| 勾选框单独一行，长得像功能开关 | 紧挨着按钮，样式也分开；写明是"这一次" |
| 按钮灰着不说为什么 | 卡片下面那行字直接说下一步做什么 |
| 状态在别的卡片里 | 这块卡自己的徽标：还没测过 / 测试中 / 已测通 |
| 「保存后，测试一次连接」 | 「连接测试」+「测通后才能生成」放在说明里 |

徽标只说**测试的状态**（上面那张卡已经说了服务本身的状态，不重复）；提示行只说
**下一步做什么**。测试之前提示缺什么、有没有未保存的改动；测完提示"已经测通，
可以生成；生成的答案仍要人工核对"。

## 怎么验的

- 前端 `node --test test_*.js`：133 条全过（新增 3 条：徽标只报测试状态、缺密钥时
  说清缺什么、有未保存改动时说清下一步）；
- 手工在真实页面看过四种状态：缺密钥 / 有未保存改动 / 测通 / 助手模式不用它 ✓。
