# 题有据 v1.8.0

这一版主要改了这些：MiniMax 同时读几道题跟着你的会员档位走；改字时题面边打字边排版预览；专注模式在全部通过的试卷上不再乱变暗；新手教学的小卡片打开放大窗口时也一直在最上面；题卡上和打勾重复的“标记通过”按钮去掉了。

## MiniMax 会员档位

- MiniMax 每个密钥能同时处理多少请求，跟会员档位有关，也会随高峰期（MiniMax 说是工作日 15:00–17:30）变化，不是一个固定的数。原来每个密钥固定从 6 个开始。
- **设置 → 常用 → MiniMax 会员档位**里选你的档位：Plus（每个密钥同时读 3–4 道）、Max（4–5 道）、Ultra（6–7 道）、按量付费的 API Key（6–8 道），不确定就选“自动摸索”（默认：从 3 道起，顺利就逐步加到最多 8 道）。档位的数字来自 MiniMax 官方的说明。
- 在档位给的范围里程序自己调：请求一直顺利就加一个，遇到限流（服务商说“太快了”）就减一个，限流过去再慢慢加回来；限流不会让题卡出错。下一份试卷从上一份最后稳定的水平接着读，不用每份都从头摸索。
- 改了档位从下一份新资料开始生效，正在读的试卷不会中途变。

## 改字时实时预览

- 改题干、选项时，下面的预览随着打字立刻排版成保存后的样子（公式、表格都排好），不用等，也不用滚到最下面去找。
- 原卷截图在左边时，预览就放在左栏原卷截图的正下方，原卷和预览上下对照着看；截图在上面一整行或者窗口很窄时，预览放在题干输入框正下方。
- 题干输入框跟着文字多少变高变矮，不再留一大块空白把预览挤到看不见的地方。

## 专注模式

- **全部通过的试卷不再变暗**：原来所有题都收成一行时，总是第一行亮着、其余全暗，鼠标停在哪一行它就半亮。现在只有展开的整张卡才算“正在看”；屏幕上只剩收起的已通过题时，全部正常显示。点开一道已通过的题，就只亮这一道；收起来就恢复。
- **“正在看哪张”更准**：按屏幕上方三分之一处那条线压着哪张卡来算；滚到最上面一定是第一张，滚到最下面一定是最后一张（原来最后一张矮卡前面有一张高卡时，怎么滚都轮不到它）。
- 专注模式下，挨在一起的已通过收起题不再隔得很开。
- 全屏时判断位置不再偏 56 像素。

## 新手教学

- 教学小卡片和“指给我看”的圈一直在最上面：打开放大对照、配图窗口或确认框时不会再被盖住、消失，也照样能点。
- 放大对照窗口里，小卡片挪到右下角，不挡左下角的“改字 / 上一题 / 下一题”。

## 题卡

- 题卡下面的“标记通过”“撤销通过”按钮去掉了，和题号左边的方框重复。通过、撤销都在方框里点（也可以按 Enter / U）。配图还没处理好的题，原来的位置换成“处理配图冲突 / 处理漏图提醒”按钮。
- “题卡上的标记是什么意思”里的说明跟着改了。
