# 题有据 v1.6.0

多选题可以有 E 选项了；题面和审核界面改成更像纸质试卷的样子。

## 识读

- **选择题最多到 E**：原卷印了五个选项时，识读、改字、配图归属（按 E 选）、入库和组卷都支持 E。只有四个选项的题目内容和审批完全不变。
- **题型标注不进题干**：题干开头印的“（多项选择题）”“（多选）”“（单选题）”这类标注会去掉，并直接把题型定为多选题或单选题。
- **已有题卡自动整理**：升级后第一次启动时，题干开头带题型标注的题卡会去掉标注并补上题型；选项 D 里混着“【E】”的（例如“3个【E】4个”）会拆成 D“3个”和 E“4个”。只整理格式，文字、配图、范围不变；原来已标记通过的仍保持通过，已入库的同步更新，不会生成新版本。人已经改成填空题或解答题的，题型不动。

## 界面

- **题面像印刷试卷**：宋体正文、英文和数字用 Times New Roman，公式与文字同高；选项短就一行排开（五个选项也在一行），大屏上题面宽度收在一行约四十字，选项不会散得太开。
- **疑点像用荧光笔划过**：有争议的字用浅黄色荧光笔式底纹，不再是粗框加下划线；提示改成左侧一条色线的页边批注，不再是整块黄框。
- **配色更安静**：暖白底色、中性灰边框，按钮去掉阴影；题卡只用左侧色条和状态标签区分状态，不再给整张黄卡描黄边。题组标签改成细边框小标签。
- **顶部和侧栏**：“录入终审 / 正式题库”改成下划线标签；试卷列表选中色和进度条更轻；键盘提示条只在宽屏显示（按钮上和“?”里都有快捷键）。

## 升级说明

覆盖安装即可，无数据库结构变化。
