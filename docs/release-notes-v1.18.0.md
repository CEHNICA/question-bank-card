# 题有据 1.18.0 本地验收版

本地验收版以当前 1.17.0 源码成果为基础，保留 Windows PDF 导出修复、彩色题框、布局历史和保存后撤销。

## 审核页找题

- 审核工具栏新增“找题”，在当前试卷有效题目中搜索题号、页码、题组以及已保存的题干和选项。`sin`、`SIN`、`\\sin` 可互相匹配。
- 搜索结果不会重排题卡。点击结果会展开并定位题卡；被状态筛选隐藏时会切换到“全部”。原图题支持题号、题组和页码搜索；未识读的图片正文不支持可靠文字搜索。
- 同一浏览器会话内切换页面、试卷或刷新后恢复审核现场。明确点选的目标题优先；已删除或被拆合替换的题目不会误跳到同号题。
- 审核页在没有其他编辑或弹窗时可用 `Ctrl+F` 打开找题。搜索不会自动识读。

## 原卷框选与校正

- 侧栏只显示当前题号、保存状态、片段和裁片预览；不再展示常驻长题目列表。
- 悬停高亮，单击题框即可选择并显示控制点。边角调整大小，拖题号标签移动范围；选择本身不产生待保存修改。重叠区域先让用户选中具体题目。
- 补题时显示十字光标，点击两角固定范围。保存后新题显示虚线草稿；可选择“保存”留在原卷，或明确选择“保存并框下一题”。
- 双击已保存题框返回对应审核卡；保留“查看这题”按钮。从题卡打开原卷后，自动把对应片段居中。普通返回恢复进入前现场。
- 普通调框、改号和补题直接保存；拆题和合题保留一次影响确认。保存、返回审核和撤销均不自动提交 AI 识读。
- 修复无范围变化时合题草稿被误判为“没有修改”的情况；补充快速双击选择题框后直接返回审核的处理。

## 数据保护

继续使用既有布局保存、版本校验、操作历史、结果查询与撤销接口，不新增数据库字段或第二套保存服务。拆合旧题保留历史；已入库版本按操作确认撤回，撤销不会自动恢复审批或入库状态。

## 本地验收边界

本版用于本机验收，不公开发布、不自动升级当前安装，也不修改真实题库。成品和校验值见同目录 `验收记录-v1.18.0.md` 与 `SHA256SUMS.txt`。
