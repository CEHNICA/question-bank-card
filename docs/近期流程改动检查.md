# 切题独立后的流程检查

1.11.6–1.11.11 将切题从 MinerU 解析中独立出来：本机文字提取或手工框题负责得到完整裁片，后面继续使用原有识读、改字、配图、审核和入库流程。

| 环节 | 影响与本次处理 |
| --- | --- |
| 导入与切题 | 默认本机处理，保留原页。教材及检测到多个编号范围的合订卷托底手工，避免跨章或跨卷重复题号被吞并。明确云授权才走原云结构流程。 |
| 识读 | 完成切题后读取已保存裁片，成功直接写入题面。无“采用此读法”中间确认。二次识读对比可关闭。 |
| 重读与停止 | 缺少读题服务时拒绝提交，不清空正文。服务故障且无实际底稿时保留已有内容；停止后的迟到结果不覆盖新修改。 |
| MinerU 转手工 | 试卷操作中直接停止本机等待并打开框题；先使旧任务失效，再本机补齐缺失原页。保留现有题卡、正文、配图与入库版本，不自动识读；重复切换不打断后来的单题重读。 |
| 配图 | 两点确定矩形；双击下一张图中间复制附近框尺寸。草绘可取消，归属需重新指定。原框移动、缩放、跨页和拼图功能继续保留。 |
| 人工审核 | 识读完成仍需对照原卷核对。AI 不自动通过或入库，不撤销人工通过；明确强制授权才允许覆盖人工审核。 |
| 正式题库与历史 | 手工文字题显式重读只生成当前草稿，旧入库快照和原始出处保留；组卷仍固定所选版本。 |
| 导出 | 使用现有 PDF/Word 输出分支，手工来源也能输出。附答案模式中全体题目都无答案或解析时只导出题目卷，避免空的答案页；有答案的混合卷保留原有输出。 |
| 设置与密钥 | 保存成功后的状态刷新在后台进行，不锁住关闭。旧会话响应不干扰重新打开的窗口；实际写入期间仍限制并发操作。应用专用浏览器关闭密码保存，密钥仍由软件加密保存，普通浏览器设置不变。 |
| AI 助手与文档 | CLI/MCP 将绿卡称为“识读完成”；教学文案同步到切题→识读→审核。标签和参考答案保持默认关闭。 |

没有数据库结构迁移。回归覆盖正文保留、人工修改、停止、单读、入库历史、命令行、导出、配图几何和密钥窗口会话；实际点击另用隔离题库验证。测试不会据此宣称第三方云服务可用或识读绝对准确。
