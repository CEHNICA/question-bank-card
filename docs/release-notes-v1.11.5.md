# 1.11.5：无密钥手工录入与本地文字 PDF

MinerU 不可用时，也能保存原卷、手工框出题目与配图，并以原卷图片题审核入库、选题和导出 PDF/Word。识读文字成为可选的后续步骤。

- 导入可选手工框题、本地文字 PDF 或 MinerU 云解析。手工与本地处理不要求密钥，不提交云任务。
- 手工支持多片段、跨栏/跨页、调整阅读顺序；浏览与框选工具分开，Ctrl＋滚轮缩放，空格＋左拖或中键临时平移。保存范围不自动重读，也不清掉人工配图和文字。
- 原图题以真实原卷裁片作为正文，包含页码、坐标和图像指纹。题库、审核、试题篮、PDF 和 Word 都显示完整片段，避免重复印配图或空选项。
- 文字 PDF 本地提取真实文字行和题号坐标；扫描页、乱码页保留原页供手工处理，公式不靠猜测补写。自动范围是待核对初稿。
- 后续单题识读先保存建议，确认采用才转换文字正文；转手工后的迟到识读不能覆盖新范围。已入库的旧版本继续保留。
- 原图题保留原有排版；补成可编辑文字后再全文搜索、重排选项。标签和 AI 参考答案保持默认关闭。
- CLI/MCP 支持新的导入模式和原图裁片；MinerU CLI 的实际能力、限制及测试见 [接口调查](MINERU_API.md)。
- 源码版创建桌面图标的备用方式使用 Windows 原生 Unicode 接口，修复部分 Windows 环境下中文目标路径被拒绝的问题；已有同名图标仍须验证归属后才操作。

Windows 安装包、对应源码、安装脚本与校验文件见 [v1.11.5 发布页](https://github.com/CEHNICA/question-bank-card/releases/tag/v1.11.5)。本机已验证无密钥导入、手工切题与真实 PDF/Word 导出。Doc2X/PaddleOCR 等新增服务仍需数学卷真实对照；AI 规划整页题目组成仍是后续开发项，本版没有接入。
