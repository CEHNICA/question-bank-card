# 题有据 1.18.2

基于 1.18.1，把整卷操作集中到试卷标题旁的“试卷操作”菜单，减少审核页上的入口重复和寻找成本。

- 将“切题与校正”“重新切题”“调整页序”“题卡回收站”统一放入“试卷操作 → 原卷与题卡”。
- 将批量通过放入独立的“批量审核”区域，并改名为“批量通过可入库题目”。点击后先确认影响；只处理符合条件的题，未通过的题仍保留并逐条说明原因。
- 移除审核工具栏重复的“工具”菜单；原卷校正、审核查题、全屏、专注和放大镜各自保持原来的功能。
- 重新切题入口提示先查看预演再确认应用。试卷操作菜单在窄屏或短窗口中可以滚动。
- 保留 1.18.1 最后一个题框删除后的恢复、重画和移除整题流程，以及找题、布局撤销和 Windows PDF 导出修复。

Windows 版发布于 [GitHub Releases](https://github.com/CEHNICA/question-bank-card/releases/tag/v1.18.2)。升级前请备份题库并关闭正在运行的程序。本次只调整操作入口与文案，不自动审核、不自动入库，也不提交 AI 识读。
