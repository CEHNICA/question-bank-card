# 题有据 v1.10.3

这一版只做一件事：题多的资料不再卡。用一本 673 道题的必修教材实测，打开审核页从 7 秒多缩到 1.6 秒左右，打一个勾从 1.5 秒缩到 0.1 秒以内。识读、审核、入库的结果都和以前一样。

## 打开审核页

- **服务端**：以前每张题卡要单独查一次有没有入库，还要把配图检查反复算五六遍，一本书 673 张卡要 3 秒。现在入库记录一次查完，每张卡的配图检查只算一遍，0.5 秒左右。
- **页面**：以前要先把 673 张卡全部排好版才显示第一张。现在先显示屏幕上的几张，往下滚到哪张再排哪张；查找题卡和调整选项列数的方式也改快了。

## 打勾、改字、左边的试卷列表

- 每次打勾、改字、改题型，以及左边试卷列表每 15 秒的自动刷新，都要重新数一遍“通过了几题、入库了几题”。以前一本 600 多题的书每次都要 1.5 秒：打勾会顿一下，自动刷新那一下正好点别的，也要多等一会儿。
- 现在每张卡的结果会记住，只有改动过的那张才重新算，一次只要几十毫秒。任何改动（文字、题型、配图、范围、试卷名）都会让那张卡重新算，不会用到过期的结果。

题有据刚打开时，第一次刷新列表还要把所有卡算一遍（一本书约 1.5 秒），之后就快了。

## 升级

已经装了题有据的，下载新的安装包直接覆盖安装即可，题库和设置都会保留。也可以运行：

```powershell
irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
```

它会下载最新版、核对 SHA-256、先备份题库，再静默安装。
