# 题有据 1.2.0

“题库题卡版”现在正式更名为“题有据”：每一道题，都能回到原卷。

## 本次更新

- 全新的“题有据”名称、应用图标、桌面快捷方式和开始菜单入口。
- 重写项目首页，加入使用真实程序和虚构演示资料拍摄的工作台、放大对照、正式题库与组卷截图。
- 增加可公开下载的原创三页演示卷，方便安装后立即试用。
- 改进配图提示词判断，识别“参照右侧三棱柱示意图”等表达，并减少题型读法冲突造成的误报；这些规则完全在本机运行，不增加 API 调用。
- 继续保留长 PDF 本机分片、失败分片续跑、任务重命名与删除、文件粘贴上传，以及 MinerU/图像识别账号池并行处理。
- 安装包继续沿用原来的内部安装位置和数据目录，覆盖升级不会删除已有题库、原卷或 API 配置；旧品牌快捷方式会被清理。

## 安装

下载 `TiYouJu-Setup-1.2.0.exe` 后运行。安装完成后，桌面和开始菜单中会出现“题有据”。首次处理资料时，按提示配置自己的 MinerU 与 MiniMax API 凭据。

当前安装包未进行商业代码签名，Windows SmartScreen 可能显示提醒。请只从本仓库的 Release 页面下载，并用 `SHA256SUMS.txt` 核对文件。

## 数据与隐私

题库、私人原卷、日志和 API 凭据不会包含在发布附件中。处理新资料会按 README 中说明调用用户自行配置的第三方 API；AI 结果需要使用者对照原卷确认后才能进入正式题库。
