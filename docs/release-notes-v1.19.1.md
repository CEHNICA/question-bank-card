# 1.19.1 本地验收版

AI 标签建议从题卡底部移到右侧，与题面并排核对。题卡空间不足时自动放到题面下方，不挤压阅读区域。

- 移除整栏黄色背景，改为紧凑浅色面板，区分标签名称、类型、范围及依据。
- 新标签的名称、类型和分组收进“修改名称或分组”；展开后载入分组，避免出现空白选择框。
- 建议仍默认不勾选；未选择建议时，采纳与拒绝按钮不可点击。操作只读取当前面板的选择和修改。
- 标签选择与管理窗口使用实色背景。已有标签、审核结论、解析及题面均保持原有保存规则。
- 修复窄屏题卡偏到右侧的问题；已采纳或拒绝的建议标明结果，不会再次进入待处理选择。
- 修复同批建议部分采纳后处理剩余条目被误报版本冲突的问题。

本版本用于本机验收，未公开发布，不自动升级现有安装。目录与迁移规则沿用 1.19.0。
