## 题有据 2.2.10 更新说明

### 更新亮点

1. **核验证据可以翻页了：题目在第 1 页、答案在第 2 页也能核**：
   - 题库工作台（Eagle）点「📄 核验证据」打开的原卷扫描件弹窗，原来只显示这道题所在的那一页。教材、教辅里一道题的答案、解析常常印在下一页 —— 以前要自己另开一份 PDF 对页码，核验只能核一半；
   - 弹窗新增翻页条：**上一页 / 下一页 / 页码直接输入 / 总页数**，并提供「回到第 N 页」一键跳回这道题所在的那一页；翻到别页时原卷上照旧画出题目的橙框与绿框（本题不在该页时不画框，显示整页）；
   - 键盘 **← / →** 直接翻页（弹窗开着时）；页码输入框输入页码回车即跳，超出这本原卷的页码会明确提示「这份原卷没有第 N 页」，不会静默跳到别处。

2. **新增只读接口 `GET /api/papers/<id>/pages`（别名 `/api/documents/<id>/pages`）**：
   - 返回这份原卷实际有的页码清单（`pages` / `count`），供翻页控件判断边界；
   - 口径与 `/api/papers/<id>/pages/<n>/preview` 一致：**能预览的页才是能翻到的页**；
   - 为什么不用现成的 `/api/papers/<id>`：那份要带 structure、question_groups、counts 走一遍，一份 270 页的教材实测 **1.4 MB / 首次 1.6 秒**，只为了知道「有多少页」不值当；新接口只有几 KB。

### 怎么用

1. 题库工作台右栏点「📄 核验证据」，原卷扫描件弹窗上方出现「原卷页」翻页条；
2. 点 **▶** 或按 **→** 翻到答案印在的那一页，对照原卷核验；
3. 看完点「回到第 N 页」跳回这道题所在页。

### 验证

- 后端：`core.test_paper_pages`（页码清单、documents 别名、载荷大小、404、只读、坏数据跳过）；
- 前端：`frontend/test_eagle_evidence_page_nav.js`（翻页控件、翻页逻辑、回到本题页、只有一页时不占地方）；
- 实机：必修第一册（270 页）与高中数学思想方法导引（323 页）两份教材上实测翻页找答案页。
