# 题有据 2.3.20（未签名修复版）

- 更新改为分步操作：检查到新版本后显示「下载更新」，下载完成并通过 SHA-256 校验后显示「安装更新」。下载完成不会自动关闭软件，安装前会再次确认。
- 设置页与更新弹窗同步状态；下载时按钮变灰并显示「正在下载」，禁止重复提交，提供「取消下载」。取消会停止后续分段与重试并清理临时文件；当前网络连接尚未返回时显示「正在取消」。关闭设置页不等于取消下载。
- 修复检查失败却提示已是最新、重新打开设置后状态丢失、弹窗重新启用下载按钮等问题。自动检查开关保存失败会还原并提示。
- 文件夹右键菜单加入「展开全部子文件夹」「收起全部子文件夹」，覆盖自建文件夹、教材、章节、试卷与分组。保留当前文件夹展开，只调整其下面各级目录；其他目录及当前选题不变。标签树显示对应的「子标签」。
- 工作台按空格打开快速审题时，顶栏、题名行和底栏直接以完整样子出现，不再先淡出再淡回。鼠标移出白色卡片后仍只留题干。
- 在「调整范围 / 管理配图 / 框选识读」之间切换，或再点适页、适宽时，当前页对不上的题框不再把原卷缩到右栏右下角。题框就在当前页上时，仍会把这一段滚到中间。
- 保留 2.3.18 的 Windows 安装程序独立启动修复，以及 2.3.19 的表格、图片选项和快速审题改进。

本版未签名，仍可能出现 Microsoft Defender SmartScreen 提示。签名申请与自动签名门禁保持原状。

2.3.16 / 2.3.17 用户如果仍遇到“软件退出但安装窗口未打开”，请从本页手动下载安装包覆盖安装一次，无需卸载原版。2.3.18 / 2.3.19 正在运行的旧更新界面会在升级后获得上述新流程。
