## 题有据 2.3.2 更新说明

### 更新亮点

1. **题库工作台更像 Eagle 的安静整理台**：
   - 查虫中心遮罩修好，不再挡住整页操作；
   - 考题属性可折叠；AI 建议默认安静，后台补标用图标 + 悬停说明，生成建议按钮有明确反馈；
   - 左侧空文件夹不再堆说明文案；顶栏搜索缩短，不再拉满整行。

2. **文件夹拖放与撤销**：
   - 支持手动排序（`manual` / `sortOrder`）、拖拽重排；
   - 文件夹改动可撤销；展开文件夹会滚到眼前；
   - 拖题时有清晰的拖拽影子。

3. **统一毛玻璃悬浮提示**：
   - 文件夹 / 标签 / 考题属性等改走自定义半透明气泡；
   - 名字没被截断就不弹；左栏长名贴在侧栏外侧，不挡下方文件夹；
   - 「全选」旁不再常驻「已勾选 N 题」，悬停再看数量。

4. **顶栏再收口**：
   - 去掉含糊的「当前第几题」与重复的「共 N 题」——左侧文件夹数字已经够用，中间更清爽。

### 验证范围

- 前端契约测试：`node --test frontend/test_eagle_*.js`（含查虫、属性折叠、AI 安静、悬停气泡、展开滚动、跳转收口、文件夹拖排/撤销等新增用例）。
- 发版由 GitHub Actions `release` 工作流在打 `v2.3.2` 标签后自动跑完整门禁、打包安装包与便携版并上传 Release。
