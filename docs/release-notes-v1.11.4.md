# 题有据 1.11.4：按页出卷，直接下载 PDF

本轮为本地改进，尚未推送 GitHub 或发布新安装包；旧发布包的功能以实际版本为准。

- **预览就是一页页 A4。** 逐页核对题号、公式和配图，默认省纸排版，也可选择“尽量保持单题完整”；超长题仍可分页，不裁掉内容。
- **选项可以单独调。** 全卷选择自动、一行四项或两列，个别题覆盖全卷选择，也可让此题另起页；排版选择随草稿保存和恢复。
- **直接下载 PDF。** 使用本机已有 Edge 或 Chrome 在后台生成，无需进入打印窗口或安装额外浏览器；缺浏览器、缺图或排版失败会明确提示。Word、题目与答案 Word 分卷继续保留。
- **失败后继续调整。** 不清空试题篮与排版选择；PDF 和 Word 分别检查公式支持，不因一种格式失败就漏掉题目。

AI 标签、参考答案和自动生成仍默认关闭；导出只使用已保存内容，明确选用的 AI 参考保留“未核对”标记，不生成新答案、不调用云端 AI。教学只介绍入口，不保存真实草稿或下载文件。本轮未新增 CLI/MCP 导出命令。

实际 PDF、Word 兼容性及安装结果以本地验收为准，不宣称所有浏览器、公式和打印设备均已测试；付费 API、云识读及自动唤醒桌面助手未在本轮验证。
