# 1.25.96：「还有活没干」这块面板，被挡在屏幕外面了

老师 10 月 21 日早上 7 点发来一张截图，指着题库页上「还有活没干」点开的那块面板：

> 挡住了，让他在右边展示

截图里左边一列按钮（AI 建议待核对 · 437 题、未标知识点 · 801 题……）**只剩右半截**，右边「答案」栏那颗「补齐缺的参考答案 · 474 题」却完好。

## 一、实测查出来是两个病，不是一个

### 病一：位置 —— 整块面板甩出了屏幕左缘

那块面板原来写的是「贴在『还有活没干』按钮的右边」，而那个按钮住在**吸顶的批量条**里。窗口一窄，按钮被挤到批量条左边，560 像素宽的面板跟着甩出去：

| 窗口宽度 | 面板落点 | 「标签」栏 | 「答案」栏 |
|---|---|---|---|
| 1442 | x = 127 | 完整 | 完整 |
| 1280 | **x = -135** | 只剩右半截 | 完整 |
| 1100 | **x = -141** | 只剩右半截 | 完整 |
| 900 | **x = -143** | 只剩右半截 | 完整 |

**和老师那张截图是一个样子。**

### 病二：层级 —— 「更多筛选」反过来盖住它

这两块面板根本不在同一层：

- 「还有活没干」这块住在**吸顶的批量条**里（层级 20）；
- 「更多筛选」住在**筛选行**里（层级 21）。

整层压着整层。1442 像素宽、更多筛选一展开，面板就被盖住一部分 —— 这个在宽屏上也能复现。

**1.25.18 修过一模一样的毛病**（「更多筛选」面板原来也会甩出屏幕，那次改成贴筛选行左边缘开、宽度不超过筛选行）。这次漏了「还有活没干」这块。

## 二、这一版改了什么

1. **面板自己算位置**，规则只有三条：

   - 贴住「还有活没干」按钮的右缘（宽屏时跟以前一样，位置不变）；
   - 这样摆会跑出屏幕左缘时，**改贴屏幕右缘** —— 这就是老师要的「在右边展示」；
   - 视口比面板本身还窄时，面板按视口收窄，贴着左缘。

   不管窗口多窄、也不管别的浮层开没开，它都**整个**落在屏幕里。

2. **面板挂到最上层**：改挂到题库工作区下（那里不建层叠上下文），层级 58 —— 「更多筛选」和题目详情都压不过它了。

3. **顺带修掉一个真问题**：面板宽度原来按 `100vw` 算，**把竖滚动条也算进去了**，比可用宽度宽十几像素 —— 页面上有滚动条时，右边会出屏。改成按可用宽度算。

4. **补了一条会算位置账的测试**（`frontend/test_library_todo_panel_position.js`）。

   它把位置规则抽成一个纯函数真跑一遍，并写成**性质**而不是几个例子：不管视口多窄、按钮在哪儿，面板整个都得落在屏幕里。

   同时钉住：层级、挂载位置、收起时的显隐（面板搬出了折叠板，收起不再自动隐藏）、以及**面板搬家后那几处选择器** —— 它们原来带 `#libraryTodos` 前缀，搬家后会一个都圈不到：按钮锁不住、排队时的秒数不刷新。

5. **12 条变异全部被挡住**：去掉「贴屏幕右缘」那条分支 / 去掉「别顶出右缘」的保险 / 面板太宽时不收窄 / 样式改回 `100vw` / 改回「贴在按钮右边」/ 层级降到 30 / 搬回折叠板里 / 去掉收起时的隐藏（重画和点收起各一条）/ 去掉窗口变化时的重摆 / 选择器加回旧前缀 / 位置算错。

6. **顺带改了使用指南里一处过时的话**：它还写着「筛选栏上常驻『AI 建议待核对』和『未标知识点』两个入口」—— 那在 1.25.20 就搬去「还有活没干」里了。
