# 题有据 v1.9.0

这一版有两件事：

- **可以完全免费地用**：看图读题新增魔搭（每天几百次免费），再加上免费的 MinerU，就能一分钱不花处理试卷。实测魔搭读得和付费的 MiniMax 一样准。连看图读题的服务都不想注册，可以选“AI 助手读题”，只要 MinerU。
- **AI 助手（豆包、Claude、Codex、Trae……）也能用题有据**：一行命令安装，用随软件附带的命令行 `tiyouju.exe`（或 MCP）上传试卷、逐题对照原卷核对、改字、处理配图、打勾、入库。AI 打的勾和人工通过分开记，等你抽查。

## 完全免费

- **新的看图读题服务：魔搭**（ModelScope）。
  - 默认模型 `Qwen/Qwen3.5-35B-A3B`，每天免费几百次，大约够读 4–6 份卷子。要绑定实名的阿里云账号（支付宝扫码）。
  - 实测每道题约 3.5 秒，准确度和付费的 MiniMax 相当。
  - 和 MiniMax、硅基流动一样，在“设置 → 常用 → 填写或更换密钥”里填，最多 8 个账号；模型 ID 在“读题模型”里可以改。
  - 魔搭只保证同时读 1–2 道题，遇到限流自动放慢。
  - 也试过智谱的免费模型，没有采用：GLM-4.6V-Flash 中午四次里有三次回“访问量过大”，另外两个免费模型读错得多。硅基流动目前没有能读题的免费模型。详见 `docs/免费方案调研-2026-10.md`。
- **谁来读题**：选的那家没填密钥时，自动用已填密钥的那家：MiniMax → 魔搭 → 硅基流动。设置页直接显示实际在读的是哪家。复核优先找另一家：魔搭 → 硅基流动 → MiniMax；只填了一家就用同一家读两遍。
- **额度用完不出红卡**：
  - 只填了魔搭、当天额度用完时，还没读的题先用 MinerU 识别的初稿，标黄并说明原因；可以直接对照原卷改字，或者第二天点“重新识读”。
  - 出过问题的服务先歇 3 分钟，这期间不再一题一题地等它重试；下一份卷子开始时又会先用它。
  - 也填了付费服务时，这道题自动交给另一家接着读，卡片上记的是实际读题的那家。
  - 题目本身的问题（服务明确拒收这道题）照旧报错，不换家。
- **AI 助手读题**（“设置 → 读题模型 → 谁来读题”）：
  - 不调用任何看图读题服务，只要 MinerU。
  - 题卡先用 MinerU 识别的文字做初稿：按卷面从上到下排，公式转成 `$...$`，表格转成文字表，选项自动分开；题目写着“如图”、截图里又只有一张图时，自动配上。题卡标黄，注明“MinerU 初稿 · 未核对”。
  - 然后由豆包等 AI 助手通过 `tiyouju` 对照原卷截图逐题核对、改字，或者你自己核对。改过字，“初稿”的提醒就去掉。
- **设置页**：
  - “常用”里多了“完全免费怎么配？”，MinerU 和魔搭的申请网址都在里面；还不能上传时自动展开。
  - 填密钥的窗口里，免费的魔搭排在付费服务前面，旁边有申请链接。
  - 缺密钥时直接说缺哪一家，并提示有免费的。
- **MinerU Token 过期**：提示里写明 Token 14 天过期一次，以及去哪里换。
- 有的服务一次最多只回答 1024 个 token，题有据会自动按它的上限再问一次，并记住这个上限。
- 填空的横线：魔搭有时把空写成 `$\underline{\hspace{2em}}$`，现在统一显示成 `____`。
- **英文题目**：英文句子以前被当成公式排版，单词连在一起变成斜体；现在单词照常显示，只有句子里的数学（18°C、x + 1 = 3、AB）排成公式。

## 让 AI 助手帮你用

- **一键安装或升级**：
  ```powershell
  irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
  ```
  它会找到最新版，下载安装包，用 GitHub 给出的 SHA-256 核对，然后备份题库、关掉正在运行的题有据、静默安装、重新打开。已经是最新版时，它会直接说明。国内下载慢，可以把 GitHub 加速地址设到环境变量 `TIYOUJU_MIRROR` 里。
- **命令行 `tiyouju.exe`**：和题有据装在同一个文件夹，共 16 个命令：
  - 软件：`status`、`start`、`config`
  - 试卷：`papers`、`upload`、`wait`
  - 题卡：`cards`、`show`、`fix`、`figures`、`approve`、`unapprove`、`reread`
  - 入库和题库：`publish`、`library`
  - 给支持 MCP 的 AI 用：`mcp`

  `show` 会把这道题的原卷截图、标了编号的候选图、现在的配图都存成图片，AI 打开图片对照文字。`--json` 输出纯 ASCII 的 JSON，任何终端都不会乱码。

  `status` 缺密钥时会列出缺哪一家、去哪里免费申请，AI 转告你，由你自己填。`config` 看或改读题方式（例如 `config --reader assistant`），不碰密钥。
- **MCP 服务器**：`tiyouju.exe mcp`，工具和命令一一对应。`show_card` 会直接把原卷截图作为图片交给 AI。
- **说明书**：仓库里新增 `AGENTS.md`、`skills/tiyouju/SKILL.md`（安装、处理一份试卷的步骤、逐项核对的要点、什么时候必须停下来问人）和命令手册。README 加了“让 AI 助手帮你用”一节，里面有可以直接对 AI 说的话。

## AI 通过和人工通过分开记

- AI 打的勾记成“AI 通过”：
  - 方框是虚线，题卡左边是虚线条，标签写“豆包 已通过 · 待你核对”（显示的是 AI 的名字）。
  - 这样的题卡不收起，方便你看。
- **你来确认**：点一下方框，或者按 Enter、在放大窗口点“确认通过并下一题”，都会变成你的通过；按 U 撤销。
- 有 AI 通过的题时，筛选里会多一个“AI 通过”。“全部通过”的提示里也会说明其中几题是 AI 通过的。
- AI 通过的题照常能入库，题库里标着“豆包 审核”。题库多了“全部 / 人工核对 / AI 审核”筛选。你之后确认过的题，入库版本会自动改成人工核对，不会多出一个版本。
- **AI 不能越权**：
  - AI 打勾不会覆盖人工通过，也不能撤销人工通过。
  - 命令行不会去改人工通过的题，除非使用者明确让它改。
- AI 改过的字，题卡上写“AI 助手改过 · 未人工审核”，不再说成“已人工修改”。AI 处理的配图也写着是哪个 AI 设置的。
- 以前的通过都算人工通过。
- 命令行不提供删除题卡、撤回入库这类改不回来的操作，也从不碰密钥。
