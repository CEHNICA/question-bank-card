# 题有据 1.25.0：标签不再有分组，只有父标签和子标签

本版把标签里那套「分组」整个去掉，只留一条路：**教材章节是父标签，具体标签挂在它下面，还能再往下挂自己的子标签。**

原来一个标签可以同时塞进好几个分组，于是同一个知识点被摊在好几处，分组名和章节名各说各话。现在一个标签的位置只有一条路可走。

## 升级后你的标签是什么样

- 17 个章节分组自动变成父标签，你的 282 个标签一个不少。
- 「历史标签」那批旧标签不参与转换，仍旧单独一个入口。
- 初中、高中都教的三个知识点（函数图象、平面直角坐标系、统计图表），两边章节下都找得到，不必为同一个概念建两份标签。
- 升级前会自动备份；万一要退回，目录还原得回来。

## 标签管理页怎么看

左边从上到下三块：

1. **四类入口**：知识点、解题方法、自定义、历史标签。点当前所在的那一类会逐层往上退：先退出正在看的标签，再退出这一类。
2. **顶层标签树**：只展开通往你正在看的标签的那条路，其余收着，免得侧栏变成第二棵完整的树。
3. **快速查看**：全部标签、收藏。

中间每一行右边写着这个标签**本级几题、含下级几题**；点它就跳到题库去看这些题。

## 给标签挑位置

新建或编辑标签的窗口里，「所属分组」整个去掉，只剩 **上级标签（可多选）**。留空就是顶级标签。选标签的窗口、批量整理标签、AI 建议里的新标签，追加模板的章节选择器，都是同一套。

选标签时点一个章节，看到的是**它自己加上它下面所有层级**，不是只看到直接挂着的那一层；每一行下面还会写出这个标签归在哪条路上。

追加模板时选的是章节，导入后章节直接成为父标签；撤销会把章节父标签和层级一起还原。

## AI 任务失败提示不再骗人

以前一道题 AI 标签没跑成，旁边那句「标签与答案 API 尚未配置并通过测试」会一直摆在那儿——**那是当时失败的原因，不是现在的状态**。你后来把服务配好了，这句话还在，人就会反复回去检查已经配好的东西。

现在写成过去时，并按当前能不能用分别说：

- 已经配好了：告诉你这批活上次没跑成，以及整批落下的活在哪儿补（题库页的「补齐缺的知识点标签」，建议先用「只处理当前这批」试几十道）。
- 还没配好：才让你去设置里配。
