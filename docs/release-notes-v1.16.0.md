# 1.16.0：原卷彩色题框与人工校正

本次基于已发布的 v1.15.0，保留 Windows PDF 导出修复。1.16.0 当前为本地验收版，下载与公开发布状态以 Releases 为准。

## 检查整卷

在试卷操作菜单选择“查看整份原卷”。六种浅色表示题目归属，同题的题干、选项、配图及跨页片段使用同一颜色。颜色随题目保存，改题号和移动范围后不变。颜色循环使用，侧栏中的题组与题号用于区分具体题目。

侧栏显示全卷题数、本页题数、待核对题数，以及每道题的页码和核对状态。多片段按一道题计数。白色区域保留原纸颜色，可人工查找遗漏；页眉和正常留白也会呈白色。

默认左键只选题。重叠区域弹出候选列表，小范围优先；选定后高亮整道题。右键按住平移，中键和空格加拖动继续可用；Ctrl 加滚轮缩放，“适页”显示完整页面。

## 调整与补题

选题后点击“调整当前题”。只有当前选中的片段显示控制点，拖题号标签移动，拖边或角缩放；框内部只用于选择。移动不足 4 个屏幕像素不改变范围。方向键细调，Shift 加方向键扩大步长。Esc、指针取消或窗口失焦恢复本次拖动前的范围。

“添加范围片段”后，在原卷点左上角和右下角，形成一个片段。可跨页追加，最多十二段；侧栏可前移、后移或移除，顺序决定裁片阅读顺序。草稿支持 Ctrl+Z 撤销、Ctrl+Shift+Z 重做，切换页面保留草稿。切换题目或关闭时提示处理未保存内容。

“补一道题”使用同样的画框操作，核对题组、题号、题型及裁片，再点“预览并保存”“确认保存”。新题保存为待核对的原图题。

调整已有题只保存范围，保留题文、人工修改、配图和题型，并取消旧审批，提示重新核对。范围没有变化时不提交。成功后留在原卷总览，保持页码、缩放和平移位置。

## 真正拆题与合题

拆题默认建立两个结果，第一个继承原范围，第二个为空。可增加到十二题，分别缩框、画框或把已有片段转给其他结果。每个结果必须有独立题号和有效范围，预览全部裁片后一次保存。

合题先选一题，再点击“合题…”，勾选同一题组中的其他题。按选择顺序合并片段，可移除重复片段和调整顺序。默认使用首先选择的题号，允许修改，不自动重排其他题号。最终最多十二段，超限需先整理。

拆合后产生新的题目身份，原题成为结构历史，旧题文及识读记录保留。新题直接显示原图，不猜测旧文字的分配方式。已入库源题的当前有效版本在确认拆合时撤回，历史快照、图片和旧组卷引用保留；旧组卷中的撤回题需人工重新选题。

“重新识读当前题…”是独立操作。拖动、保存、补题和拆合均不自动识读。

## 保存记录与撤销

打开“已保存的调整记录”可查看保存前的原图与题文，并撤销最近一次有效保存。关闭或重新打开软件后记录仍存在；本版已保存操作不提供重做。

撤销恢复范围、人工内容和可见题目集合，始终递增版本。审批、入库及已取消的任务需要重新确认，不自动恢复。操作后若题文、范围、配图、审核、入库或识读结果发生变化，撤销被阻止，避免覆盖后续成果。

普通回收站不能单独恢复拆合历史中的部分题目。归档保留历史且只读；实际页序变化使旧坐标撤销失效，界面说明原因。

## 一致性与验收方式

新旧范围保存和补题入口使用同一事务服务，检查整卷布局版本、源题版本及完整状态指纹。唯一请求编号支持提交结果查询和安全重试；同编号不同内容拒绝。拆合、旧题撤回、任务取消和操作历史要么全部提交，要么全部回滚。过期识读结果不能写回改变后的题目。

验收仅使用隔离生成的虚构试卷和数据库，不调用云服务。新增后端与前端回归，并提供 `tools/check_question_layout_browser.py` 检查旧库升级、真实鼠标防误触、跨页草稿、补题、拆合、持久撤销和两个窗口冲突。Windows 打包后重复实际界面验收，并单独回归 PDF 文件导出。
