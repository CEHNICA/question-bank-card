## 题有据 2.3.18 更新说明

**本版为未签名修复版，Windows 仍可能显示 SmartScreen 提示。**

- 修复更新下载完成后旧软件退出、安装程序却被一起结束的问题。安装程序现在可独立于旧软件的后台进程管理继续运行，普通后台服务仍会随软件退出而清理。
- 如果 Windows 阻止安装程序独立启动，保持软件打开，明确提示失败及已下载安装包的路径；不再回退到会被旧软件一起结束的启动方式，也不再误报已开始安装。
- 增加真实 Windows 跨进程回归，验证旧软件退出后的安装程序存活、普通子进程清理和系统拒绝独立启动时的错误处理；纳入持续集成及发布检查。

### 从 2.3.16 / 2.3.17 升级

旧版更新器本身含有此问题，下载新版并不会先修复正在运行的旧更新器。请从官网下载后手动运行 2.3.18 安装包，沿用原安装目录覆盖安装，无须卸载。安装到修复版后，后续更新会使用新的进程交接逻辑。

### 验证边界

进程回归使用真实 Windows Job 和隔离的测试进程，不读取真实题库或笔记，不运行会按名称结束真实题有据的安装器。构建后另行检查冻结产物。系统安全软件拦截及其他电脑的环境问题仍需结合当地日志排查。
