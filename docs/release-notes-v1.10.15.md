# 题有据 v1.10.15

按照 2026-10-02 查阅的 MinerU 官方 API 管理页更新接口限制和故障说明，减少旧文档导致的错误提交和误判。

- **长试卷自动分片**：精准解析按每份最多 200 页处理；教材保持每份 100 页，题目仍能回到原卷页号。
- **额度说明更准确**：每天 1000 页是最高优先级额度，超过后可能排队更久；Token 到期日以管理页实际显示为准。
- **异常返回能说明原因**：检查上传地址、批次编号和解析结果；区分 Token、任务额度、文件限制、排队和服务错误。
- **保存配置不误判服务状态**：停用旧的未公开 Token 预检请求，只做本机格式检查与加密保存；实际可用性以识读任务返回为准。

当前官方文档存在新旧页面限制不一致的情况；本版选择当前 API 管理页的较保守限制。免登录 Agent 接口只有轻量 Markdown 结果，不能直接代替本项目依赖的题目坐标和结构化解析，未自动切换。

覆盖安装会保留题库、原卷与用户设置。本版通过隔离环境中的自动测试及本机安装检查，未上传用户试卷，未宣称 MinerU 识读服务或个人账户已恢复。

详细调查见 [MinerU 接口说明](MINERU_API.md)，安装与使用见 [使用指南](使用指南.md)，完整改动见 [更新记录](../CHANGELOG.md)，AI 上手入口见 [AGENTS.md](../AGENTS.md)。
