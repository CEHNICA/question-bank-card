# 题有据品牌标识

采用青绿色翻页书本与深蓝色“题有据”字标。正式标识使用透明背景，不包含宣传海报的纸张纹理、装饰线和 Windows 版本标签。

- `../../../assets/app-icon.svg`：可编辑的书本矢量原图。
- `../../../assets/app-icon-small.svg`：小尺寸轮廓；简化渐变和细部，便于在任务栏显示。
- `../../../assets/app.ico`：Windows 图标，包含 16、24、32、48、64、128、256 像素版本。
- `../../../assets/app-icon.png`：256 像素启动画面用图。
- `../../../frontend/favicon.png`：64 像素浏览器与应用页头用图。
- `app-icon-1024.png`：1024 像素透明图，用于宣传与头像素材。
- `logo-lockup.svg` / `logo-lockup.png`：浅色背景使用的横版书本与字标。
- `logo-lockup-light.svg` / `logo-lockup-light.png`：深色背景使用的浅色字标。
- `wordmark.svg`：单独字标。
- `book-monochrome.svg`：单色版本。

字标以 Noto Serif SC 850 字重转为矢量路径，查看文件时不需要安装字体。软件名称与原有数据目录保持一致。更新品牌时，应同步替换上述派生资源；不要重新使用旧版题卡连线图形。
