# 1.26.0：窗口按钮回来了，合并的规矩也说明白了

这一版是回應两件事：**右上角那三个按钮没了**，和**合并到底是并集还是怎么着**。

## 一、窗口按钮

### 原来是怎么回事

1.25.90 把窗口从"整屏无边框"改回"普通窗口"，标题栏自带最小化/最大化/关闭三个按钮，
页面自绘的那两个（最小化、关闭）就删掉了 —— 理由是两套控件并排会让人不知道该点哪一个。

**这个判断在多数情况下是对的，但漏了一种情况**：窗口拖到屏幕边缘、最大化、整屏看题时，
标题栏不在眼前，页面上又没有别的入口。老师看到的就成了"按钮没了，我怎么关、怎么缩"。

### 现在怎么办

页面右上角**又放了一份**：最小化、最大化、关闭，样式和 Windows 标题栏一样。
真正操作窗口的仍然是启动器 —— 网页把请求写进一个控制文件，由启动器去动真正的窗口句柄
（浏览器没有"最小化/关闭本窗口"的脚本接口）。

**只在标题栏够不着的时候才出现**（1.26.1 改的）：宿主（启动器）守着窗口，窗口一变
就把"标题栏还在不在"写过来；页面照着办：

- 普通窗口、最大化 → **标题栏自带三个按钮**，页面不画（两套并排，老师会不知道该点
  哪一个 —— 1.25.90 删掉页面按钮就是这个理由）；
- 整屏显示（F11）、窗口被拖到屏幕边缘外面 → 标题栏整个够不着 → **页面右上角那份顶上**；
- 普通浏览器标签页 → 背后没有可操作的窗口，不显示。

## 二、合并的规矩：不是并集，是"认得出就当成同一个，认不出的两个都留着"

并集的意思是"两边都有的都留下" —— 那会把同一道题在题库里变成两张卡。题有据不这么做：

| 情况 | 认得出吗 | 怎么办 |
|---|---|---|
| 同一套原卷（原文件 sha256 一样） | 认得出 | 当成同一套卷，逐题比 |
| 同一套卷、同一个题号、题干也一样 | 认得出 | **还是那道题**：本机空着的补上，两边都有的保留本机的 |
| 同一套卷、同一个题号、**题干明显不是同一道题** | **认不出** | **两道都留着**：备份里的那道放到本卷末尾的空题号上，报告里说清"原来第几题、放到了第几题" |
| 同一道题、两边都有解析 | 认得出（同一个入库版本） | **两个版本都留着**（题有据的解析本来就是一串版本） |
| 同一个入库版本号（v1）但内容不同 | 认得出（同一个位置） | **保留本机的**，报告里说一声 |
| 对方多出来的入库版本（v2、v3…） | 认得出（不同的版本） | 带进来，解析版本一起带 |
| 标签 / 题上的标签 | 认得出 | 取并集 |
| 通过/审核状态 | —— | **不动本机的**。"通过"是人的决定，合并不替人做主 |

**"题号一样但题干不同"以前是悄悄跳过的** —— 界面却写着"两道都留着"。现在代码和界面
一致了：两道都留着，备份里的那道另给一个题号。

## 三、顺带修掉一个会"悄悄丢题"的坑

题目的主键是**整数自增**（`core_question.id`）—— 两台电脑各自从 1 开始编，对方的
第 42 题和本机的第 42 题根本不是同一道题。搬题时照抄编号，撞上了就会被当成
"这个编号已经有了"而**跳过** —— 那道题就悄无声息地没了。

现在：

- 编号在本机没被占 → 沿用（题组之间的指向不用改）；
- 被占了 → 由数据库另编一个，并把指向题组的那些关系改到新编号上；
- `source_key`（这台机器给这张卡的身份）一律重新生成；
- `core_librarytagrelation` 的主键也是整数，同理另编号。

演练里加了一条：**乙机有一套本机没有的卷子**（它的题目编号从 1 开始编，和甲机全部
撞车）→ 整卷 2 道题一道没丢地搬了过来。

## 四、怎么验的

- 后端 `manage.py test core`：**2277 项全过**（新增：题号冲突两道都留着、编号撞车
  不丢题、窗口三个动作、页面问"背后有没有桌面窗口"）。
- 前端 `node --test test_*.js`：**132 项全过**。
- 界面（开发环境，真桌面模式）：右上角三个按钮出现，点了会真的写控制文件；
  普通浏览器标签页里不出现。
- 两台电脑的实盘演练：乙机独有卷子的 2 道题（编号和甲机撞车）整卷搬过来；
  预览说补 2 道、真合并补 2 道；本机已有的答案一道没被覆盖；撤销后回到合并前的样子。

## 五、装的时候又碰上 360

这一版的安装包一开始装不上：退出码 1、连日志都来不及写。查下来是 **360 安全卫士**
又回来了（上次卸过一次），它的"主动防御"把安装包解压到 `%TEMP%` 的文件当木马清掉了
（右下角弹的那条"已为您清除木马文件"就是它）。退出 360 之后一次就装上了。
