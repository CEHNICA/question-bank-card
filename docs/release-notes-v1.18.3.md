# 1.18.3：API 配置引导与可选答题服务

基于 v1.18.2。安装包需要手动运行后才会更新本机程序。

## 现在怎么配置

打开“设置 → API 配置 → 配置 API”，直接进入共用窗口。外层不再重复列出四家服务的填写状态。

1. **MinerU：云端自动切题必填。** 负责识别整份试卷和划分题目，按照窗口链接生成 Token 后粘贴。
2. **选择一家看图读题服务。** 推荐魔搭；可以换用已有的 MiniMax 或硅基流动。窗口只展开所选服务的密钥框，新密钥点“保存密钥”保存；选择服务自动保存。

只手工框题、审核原图或使用本地解析时，可以跳过 API 配置。第三方额度、有效期和费用以本人服务商账户为准。

## 标签与答案

“标签与答案 · 可选”保留两项独立功能开关和处理时机。读题侧已保存魔搭、MiniMax 或硅基流动密钥时，可以明确点击复用，无需重复粘贴；已有独立 DeepSeek、豆包 API 或其他兼容配置仍可继续使用。

复用会切换当前答题服务，复制读题侧第一个账号。其他服务的已保存密钥和模型配置保留。以后更新读题密钥时，在答题页重新点击复用才更新，不是自动关联。复用与保存均不启用生成开关、不提交测试或题目。

模型和 API 地址默认折叠。答题 API 需明确同意用合成题测试连接，通过后才允许生成；不会提交真实试卷进行测试。生成结果仍需人工核对。

## 草稿与密钥保护

- 切换服务或配置分区保留新密钥草稿，并隐藏任何临时显示的明文。
- 各服务未保存的模型和地址草稿也会保留，一次保存同时提交这些改动。
- 保存或复用失败显示实际错误。答题页新密钥失败后清空，需重新填写再保存；非密钥选项保留。
- 磁盘写入失败时恢复旧密钥和原配置，以新版本拒绝旧异步结果并要求重新测试；恢复也失败时保持 API 暂停，不冒充已保存或已测通。
- 密钥仍由用户填写并使用当前 Windows 用户的加密能力保存，不写入题库或公开源码。验收只使用隔离虚构配置。

## 验收范围

本地验收通过 215 项后端测试、83 个前端回归测试文件，以及源码和打包成品各 9 组浏览器检查；Windows 打包与隐私检查通过。冻结版程序使用虚构试卷实际导出 PDF，预览和导出均为 1 页。真实服务账号、额度和实际数学识读能力未通过本次离线验收。

## 已知问题

在本次 en-US Windows 验收环境中，旧的桌面快捷方式检查不能正确读回中文名称“题有据.lnk”，因此快捷方式辅助程序报告校验未通过。快捷方式读写组件沿用旧实现，本次 API 配置修改没有改动这部分。当前可从开始菜单打开程序。
