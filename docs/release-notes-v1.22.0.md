# 题有据 1.22.0：标签地图

本版为正式题库增加可操作的标签地图，直接使用现有标签目录和题目关联。分级标签可以逐层浏览和校正，标签关系与题目关联继续由现有保存、历史和撤销服务保护。

## 从哪里进入

在正式题库顶部打开 **标签管理 → 标签地图**。列表与地图使用同一份目录，随时可以切回列表，个人分组继续独立管理。

在题目上点击或悬停标签，再点击 **查看标签地图**，会以这条标签为中心显示附近的父级和子级。右侧标明对应题号、来源和这道题当前使用的标签；返回题库恢复进入前的阅读位置。

## 地图怎样使用

- 选择知识点、解题方法、自定义或历史标签。初始显示主要节点，点击节点旁的展开按钮逐层展开，支持按名称、别名和说明搜索定位。
- 点击节点只查看信息，不贴标、不改变归属。选中信息显示本级题数和包含下级的题数；“查看题目”按此标签及其下级找题，多条父级路径不会重复计算一道题。
- 空白处拖动浏览，使用缩放和适合画布调整视野。移动节点只整理本次画面的位置，不改变父子关系。
- 添加子标签、编辑名称、设置父级和相关方法使用原有保存、版本核验、操作记录与撤销服务。节点可以有多个父级，同一个标签只显示一次；禁止形成循环。
- 相关方法使用单独的虚线关系，不参与知识点继承筛选，不表示某道题已经采用这种解法。
- 从题目进入时，选中同类型的有效节点后，可明确点击“将本题这条标签改为……”即时替换；其他题目标签保留。单纯浏览不会替换。跨类型方法仍使用题目中的“添加标签”。

任何层级的有效标签都能贴题，增加子标签不会使旧题关联失效。空目录可以从头创建，不自动导入模板；AI 候选不混入正式结构，浏览和整理目录不自动调用 AI。
