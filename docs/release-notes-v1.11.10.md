# 1.11.10：两点配图、同尺寸复制与完整录题流程

配图点一个角，移动鼠标，再点另一个角固定框，不用一直按住鼠标。双击下一张图的中间，可复制附近框的大小，再指定题干或 A–E；适合四张大小相同的选项图。原框拖动和缩放、Ctrl＋滚轮、空格＋左拖或中键浏览继续保留。尚未固定的框可以用 Esc 取消，不会误保存。

修复密钥保存或删除完成后，慢状态刷新仍锁住“关闭”、取消和 Esc 的问题；快速关闭再打开时，旧响应与延迟焦点不干扰新窗口。真实的密钥写入期间仍防止并发操作。

应用专用 Edge/Chrome 窗口关闭密码保存和自动登录，API 密钥仍由应用加密保存。普通浏览器的设置不变；嵌入其他 AI 客户端浏览器时，网页只能提示不自动填充，客户端自己的密码弹窗不由本应用控制。

本版同时汇总此前本地改进：自动尝试本机切题，未切出的题手工补齐；完成切题后自动识读，成功直接进入改字、配图、审核和入库，没有“采用此读法”步骤。二次 AI 对比可关闭，标签和参考答案继续默认关闭，软件启动默认最大化。

检查最近改动的下游影响，修复手工文字题无服务重读可能丢失正文的问题；显式重读沿用普通文字题流程，保留旧入库版本和人工权限保护。CLI/MCP 的绿卡称为“识读完成”，不再把单次识读宣称为多次一致。教材、讲义及检测到多编号范围的合订卷在本机保留原页，避免重复题号被错误合并；明确允许云解析时仍可走原结构流程。

自动写回与停止仍保护人工修改、审核和历史入库内容。验证涵盖隔离回归、真实界面点击和本地安装核验；不以这些检查声称第三方云服务当前可用或识读绝对准确。
