# 1.25.74 → 1.25.90：把「题库目录」和「桌面窗口」这两件一直别扭的事改顺

这一段共 16 版（1.25.75–1.25.90），主题很集中：**老师反复指着同一个地方说"这里看不清 / 这里点不动 / 这里字被挡住"，于是每一版都去把那一处真正的原因找出来改掉**，而不是调一调颜色就收工。

## 一、目录：为什么长名字一直被挡住

老师从 1.25.83 起连续提了几次"字被挡住"。前几次改的是表面（字号、字重、颜色、缩进 14→18px、给每行加 tooltip、加一条拖拽手柄让面板能拉宽），都没解决。1.25.89 才查到真正的两层原因：

1. **名字原本是「一行 + 省略号」**，13–15 字的标签（"两边之和大于第三边"、"二次函数与一元二次方程、不等式"）永远只露出前十来个字；
2. **缩进会翻倍累加** —— 这是根子。目录里的子行是**嵌在父行里面**的，父行的 `padding-left` 已经把子行推过一次，代码却又按「绝对深度 × 18px」再设一遍内联缩进。于是实际缩进是 18 → 54 → 108 → **180**px。240px 的面板里，第四层只剩几十像素，折行后一个字一行。

改成：每层只加**一格 18px**（靠嵌套自己累加），名字**放不下就折行**。实测层级缩进 54 → 72 → 90 → 108，长名字折两行完整显示，全目录 23 个可见项没有一处截断。

## 二、目录：层级看不出来的几次调整

- **1.25.83 / 1.25.84**：深度 0 的章根加粗，字号 13px、颜色 `ink-2`；子标签字重降到常规、颜色 `muted`；章根底下那条虚线删掉（它让长名字显得更挤）；同时**不再默认展开**所有有题的章（14 章里 11 章自动展开，整屏"还有 X 个没用到的"刷下来）。
- **1.25.86**：子标签不再画左边 4px 色条。章根和子标签的色条连成一条贯穿的长带，正好压在「▸」「1」上。
- **1.25.87**：右边缘加 6px 拖拽手柄，宽 200–480px 可调，写进 localStorage，主区网格跟着同一个变量走。
- **1.25.88**：选中态不再把字染成饱和的 `--directory-color`（与 14% 同色底叠加后对比度只有 3:1），改用深灰字色；浅蓝底仍提示"当前筛的就是它"。

## 三、答完一道题，别让老师自己找下一道

题库里 474 题没写答案。1.25.82 起：从右侧面板「为本题写答案」进去、写完保存之后，编辑器**自动跳到当前可见列表里下一道没有正式解析的题**并打开——直接接着写下一道，不用回到列表找。只对单题入口生效，出卷草稿、批量补解析那种一次处理多道题的流程不走这条，不会打断出卷。

配套的两版：**1.25.81** 保存按钮在老师没改过 AI 初稿时改叫「采纳 AI 解析并保存」（并说明会同时贴上知识点标签）；**1.25.80** 目录里的"本级 0 题"改成"含下级 N 题"，整列"0 题"让人以为全空。

## 四、窗口：改回普通浏览器窗口（1.25.90）

桌面版以前是**整屏无边框**打开的（浏览器 kiosk 模式），页面右上角自绘了「最小化」「关闭」两个按钮。代价是窗口**不能最大化、不能拖边框改大小、不能最小化到任务栏**——没法一边开题库一边对照别的资料。

现在改回普通窗口：标题栏上有系统的**最小化 / 最大化 / 关闭**三个按钮，能拖边框改大小。页面不再自绘那两个按钮（两套控件并排只会让人不知道该点哪个），顶栏从五列回到四列。

真机 Win32 实测：启动参数不再带 `--kiosk`；窗口样式 `WS_CAPTION` / `WS_THICKFRAME` / `WS_SYSMENU` / `WS_MINIMIZEBOX` / `WS_MAXIMIZEBOX` **全部为真**；最小化→还原、最大化实测都按预期翻转。

顺带记录一个坑：这款 Edge 的 app 窗口**会忽略** `--start-maximized`，写死 `--window-size` 又会在小屏笔记本上超出屏幕，所以两个参数都不传，交给浏览器给默认大小。
