# 题有据 1.12.7

这一版只做两件事：**把一屏让给题目**，和**把「找不到 / 不知道」这类毛病修掉**。上一版到这一版之间没有改过任何题库内容，已有题库、草稿、试题篮都不受影响。

## 一屏里，题目拿到多少

| | 改前 | 改后 |
|---|---|---|
| 题库页第一道题距顶 | 434 | **94** |
| 一屏里属于题目的像素 | 334 | **674** |
| 题库题面可用宽 | — | 1128 → **1268** |
| 录入终审第一道题距顶 | 340 | **253**（全部处理完的那份卷） |
| 答案解析页正文距顶 | 232 | **100** |

做法：顶栏只留 ☰ 和品牌（导航、工具、试题篮、操作说明收进左侧抽屉）；查找和筛选搬进左侧 212px 吸顶栏；题面右边的空白收到 20px 以内；录入终审顶部那三条说同一件事的横条收成一条；答案解析的说明文字降级成按钮悬停提示，只留「需要你去做什么」的那一句。

## 顺手修掉的真问题

- **点顶栏中间空白处会跳回首页。** 抽屉把导航搬走后顶栏只剩一个格子，那个「回首页」的链接被撑到了整条顶栏那么宽（1434px）。现在只占内容宽。
- **专注模式下点「试题篮」只出标题、不出列表。** 专注模式那条规则把篮面板和侧栏一起藏了，但篮上一轮已经搬进抽屉 —— 于是抽屉里的篮也被藏掉。侧栏照藏，篮不藏。
- **点抽屉里的「试题篮」要点两下。** 它是折叠项，而同一个抽屉里其它行点一下就出内容，行为不一致看着就像坏了。现在取消折叠，内容直接跟在标题下面。
- **篮是空的时候那一组还显示「试题篮 0」。** 判空看错了地方。
- **导入失败时同一句话说两遍。** 上面一行小字，下面那条红条又把它包在「自动切题没有切出任何题目：」后面重说。红条带三个能点的按钮，重复的那行让位。
- **「识读未完成题目」没配密钥也让你点**，点下去必然失败；失败后这句话既进红条又弹一个 toast，而那个 toast 正好压住题卡的「改字 / 调整范围 / AI 识读这题」。现在没密钥就是灰的、原因直接写在面板上；失败只留红条一处；所有提示条不再挡住下面的按钮。
- **「更多」小窗口点外面不关。** 现在点外面关、Esc 关（焦点回「更多」）、同时只开一个。
- **导出 Word/PDF 之后不知道存哪。** 换一张留下来的卡片：文件名、题数、位置，还能一键打开文件或文件夹。存到指定文件夹时后台会回一张凭据，前端以前校验完就扔了，现在用它。
- **导入照片后无法自动切题。** 自动切题以前要求 MinerU **和** 一家看图服务同时配好，但 MinerU 自己就干识别+切题，看图服务只在切完之后「AI 识读这题」时才用得上。两件事绑在一起，等于因为没配看图服务把 MinerU 的切题能力也一起关掉，导入照片必然「处理失败」且看不出缺什么。现在拆开了。
- **照片的失败提示说错了话。** 照片本来就没有文字层，提示却写「本地文字层没有可靠题卡」，读起来像材料坏了。
- **列表里那根 3px 空灰进度条。** 没有题时进度条函数返回空壳元素，而元素自带灰底，失败的卷就多画一根像坏掉的条。
- **设置页说「已填写」、密钥窗口说「共保存 0 个」。** 这台电脑上确实有两份密钥来源：旧的 Windows 环境变量（真的在生效）和新密钥库（空的）。现在两边都说清「生效的是哪一份」，判定逻辑一个字没动。

## 安装

下载 `TiYouJu-Setup-1.12.7.exe` 后运行即可，会覆盖安装并保留你已有的题库、草稿、试题篮和密钥。SHA-256 见发布页。
