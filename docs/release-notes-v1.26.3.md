# 1.26.3：页面不再自绘窗口按钮

1.26.0 到 1.26.2，页面右上角一直有一份自绘的"最小化 / 最大化 / 关闭"。
起意是好的（标题栏有时够不着），但**它和浏览器标题栏上那三个按钮并排**，老师
看得眼花 —— 两套控件摆在一起，反而不知道该点哪一个。1.25.90 当初删掉页面按钮
就是为这个理由，是后来又加回来的。

现在**彻底撤掉**：宿主窗口本来就是普通的浏览器窗口，标题栏自带那三个按钮，
一个都不缺，页面不必再画。

一并撤掉的还有为它专门做的那些东西：

- 页面上的三个按钮、配套样式、图标；
- `POST /api/window/minimize|maximize|close` 与 `GET /api/window/available`；
- 启动器读控制文件、执行窗口动作的那条通道，以及"标题栏还在不在"的状态文件；
- 两个探针脚本。

**没有少任何功能**：最小化、最大化、关闭一直都在标题栏上，浏览器自己就能做，
本来也不需要页面代劳。

## 怎么验的

- 后端 `manage.py test core`：**2271 项全过**（少了 8 项：撤掉的窗口控制接口那组）；
- 前端 `node --test test_*.js`：**132 项全过**；
- shell **39 项全过**；
- 真机上：应用窗口右上角只剩浏览器标题栏那一套，页面顶栏右边不再有按钮。
