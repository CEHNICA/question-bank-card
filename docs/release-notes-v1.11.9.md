# 1.11.9：切题完成后直接识读、审核

手工切题替换原卷解析和找题目范围这一环节，后续沿用原来的识读、审核、配图和入库流程。连续保存只存题目范围，最后完成切题后自动识读已保存的裁片；成功后直接生成正常文字题，不再要求点击“采用此读法”。识读错误可以改字或单题重新识读。

原卷裁片、来源和识读记录保留。自动写回保护等待期间的人工改动、人工通过和已入库版本；识读本身不会自动审核或入库。旧版保存的有效识读结果在满足安全条件时直接转换，不重新调用服务。

本地软件启动时默认最大化。二次 AI 对比开关和独立的密钥保存、删除操作继续保留。

这是供用户先检查的本地版本。离线验收使用模拟识读和隔离题库，不证明云服务当前可用或识读精度。
