## 题有据 2.3.0 更新说明

### 更新亮点

1. **电子版 Word（`.docx` / `.doc`）双轨直读与答案解析同拆**：
   - 支持直接读取 `.docx` 题干、原生公式、常见 MathType 公式与内嵌图片（本机装有 Word 或 WPS 时自动静默转换兼容 `.doc`），免 OCR 零误差入审核；
   - 后台优先调用本机 Word 或 WPS 静默生成原貌 PDF 留作「📄 核验证据」，未安装办公软件时自动降级网页预览兜底；
   - 自动剥离紧跟题后的【答案】【解析】或卷尾参考答案章节（含解析配图）并归位至对应题目，疑难公式与矢量几何图诚实标黄提示。

2. **题库工作台（`/eagle`）连续虚拟滚动与公式渲染缓存**：
   - 可视区外题目自动回收以降低浏览器内存占用并缓存已渲染的 KaTeX 公式，千题万题连续滚动依旧顺滑不卡顿；
   - 顶部实时显示当前第 `X` / 共 `N` 题定位并支持输入题号秒跳，跨可视区的筛选全选与批量整理手感保持不变。

3. **本地离线查重、「一题多源证据归档」与变式题组**：
   - 纯离线毫秒级检测库内重复原题与同源变式题，同时在「录题审核页」和 `/eagle`「全库查重整理」提供提醒与对比处理；
   - 合并重复题时保留题库内干净的唯一题目，并将历次新卷原貌与学生手写错解截图追加进「📄 核验证据」多标签栏；
   - 支持将换皮题互绑为「变式题组」，出卷时可一键替换平行变式。

4. **正规考卷赋分、A3 横向双栏镜像密封线与按卷用题历史**：
   - 组卷支持单题及分节赋分与总分自动统计，新增「标准 A3 横向双栏（正反奇偶页自动镜像密封线）」版式，屏幕预览、PDF 与 Word 三端呈现一致；
   - 按卷自动合并记录已用题目历史（反复微调导出不刷假记录），并支持一键排除近期已用题防止撞车。

5. **SQLite FTS5 全文秒搜与万题级按需数据流**：
   - 新增基于 SQLite FTS5 的中英文与公式全文索引并在入库/改题/删题时自动同步；
   - 当正式题库超过 2,000 题时自动切换分批按需加载、服务端全文检索与跨页全选匹配，大题库依旧秒开秒搜。

### 验证范围

- **代码规范与类型检查**：`ruff check backend tools`、`ruff format --check backend tools`、`npm run lint`（ESLint）与 `mypy` 通过，且 `manage.py makemigrations --check --dry-run` 无待生成迁移。
- **前端测试**：`npm test`（`node --test frontend/test_*.js`）全量通过，覆盖虚拟滚动、查重与变式交互、考卷赋分与 A3 版式及万题按需分页流。
- **桌面启动与打包测试**：`unittest` 覆盖启动器、备份、打包与快捷方式检查通过。
- **后端核心测试**：`manage.py test core` 与 `QB_EXPORT_BROWSER_TEST=1` 真机浏览器 PDF 导出专项校验通过，覆盖 Word 双轨直读、查重合并与多源证据归档、赋分/A3 双栏导出与用题历史，以及 FTS5 全文检索与快照备份。
