## 题有据 2.3.13 更新说明

### 更新亮点

1. **应用内更新 6 路并发加速与实时下载进度条**：
   - 将桌面端自动更新改为支持 HTTP `Range` 的 6 路并发分片下载（严格校验 `tiyouju.com` 官网来源与整包 `SHA-256`，兼容单流回退），并优化官网 R2 边缘直吐往返延迟，下载速度大幅提升；
   - 工作台与经典设置页的「关于与更新」及右下角更新浮窗同步展示实时进度条、下载百分比、已下载/总大小、下载速度与预计剩余时间。
2. **「关于与更新」附上官网入口**：
   - 在桌面端设置「关于与更新」与更新浮窗附上官网链接 `https://tiyouju.com/`，方便随时跳转官网查看说明或直接下载安装包。
3. **小窗口主菜单滚动与设置角标排版修复**：
   - 修复界面缩小或放大缩放后工作台主菜单滚动不到底的问题；
   - 修复检测到新版本时主菜单底部「偏好与系统设置」在有绿色更新角标时被挤成竖排单字的排版问题。

### 验证范围

- `ruff check`、`ruff format --check`、`npm run lint`、`backend` 根目录与 `core` 单元测试、前端全部 `node --test` 用例通过。
