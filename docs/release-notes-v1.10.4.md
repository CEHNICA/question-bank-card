# 题有据 v1.10.4

修一个问题：页面上明明有绿卡，点“批量标记绿卡通过”却提示“已将 0 张绿卡标记通过”，这些题也就入不了库。

## 原因

有些题卡是旧版本检查过配图的：当时认为“原卷可能有图没有被找到”（有一张候选图没分清归属），记成了黄卡。新版本的配图检查已经把那张候选图判为无关内容自动排除，所以页面上显示“已自动排除疑似多余图”、绿卡。但“批量标记绿卡通过”只看数据库里记的颜色，仍当它们是黄卡，一张也没标。用一本 670 题的必修教材实测，有 26 张这样的卡。

## 现在

- 批量标记绿卡通过时，先按现在的配图检查重新看一遍：页面上是绿卡的，都会标上；标上的同时把新的检查结果存下来，以后数据库里也是绿卡。
- 真正还有疑点的黄卡（比如两次识读不一致）照旧不会被批量标上。
- 左边试卷列表里“还有几张要看”的数字，也按页面上的颜色算（1.10.3 里这个数字可能把这类卡算成黄卡）。

## 升级

已经装了题有据的，下载新的安装包直接覆盖安装即可，题库和设置都会保留。也可以运行：

```powershell
irm https://github.com/CEHNICA/question-bank-card/releases/latest/download/install.ps1 | iex
```

它会下载最新版、核对 SHA-256、先备份题库，再静默安装。装好后再点一次“批量标记绿卡通过”，然后“入库”。
