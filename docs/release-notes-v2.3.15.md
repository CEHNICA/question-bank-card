## 题有据 2.3.15 更新说明

### 更新亮点

1. **修复应用内更新退出后不安装及重复下载**：
   - 修复安装程序 `StopRunningAppProcesses()` 使用 `taskkill /T` 误杀从主程序拉起的安装子进程的问题，并改为 `/SILENT` 展示安装进度与装完自动重启新版软件；
   - 重新点击更新时先核对本机临时目录已下载安装包的官网 `SHA-256`，校验一致直接进入备份与安装，不再重复下载。
2. **OneNote 一次带图建页与选中预渲染**：
   - 「记笔记」建页时将题面图渲染与 OneNote COM 分区查找并行执行，并在题库选中未建页题目后于后台悄悄预渲染题面图，减少「先出文字、后出图片」的割裂感。
3. **修复主菜单被底部任务栏遮挡，新增 `F11` 全屏快捷键**：
   - 桌面窗口启动按显示器工作区大小钳制并结合 `screen.availHeight` 动态约束主菜单底边，防止「偏好与系统设置」被 Windows 任务栏遮住；
   - 支持按 **`F11`** 或工作台 ≡ 主菜单「全屏显示」按钮一键切换软件窗口全屏。

### 验证范围

- `ruff check`、`ruff format --check`、`npm run lint`、根目录 `unittest`、Django `core` 单元测试与全部前端 `node --test` 用例通过。
