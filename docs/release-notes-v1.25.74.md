# 题有据 1.25.74：目录、筛选、标签三件事改顺

上一版（1.25.62）把教材目录搬进了题库。这一版围绕它把标签系统和筛选系统改顺，一共十二个小版本（1.25.63–1.25.74），逐条都验过。

## 一、目录：跟着题目走，不是空架子

- **题数跟着筛选走**：筛选了来源、题型、答案，再翻目录，章节后面的题数和右边列表一致。例：筛到某份卷子后「初中 · 函数 13」变 8、「方程与不等式 7」变 4；
- **解题方法也能翻**：目录顶部有分类切换，知识点 202 / 解题方法 58 / 自定义 1；方法和知识点一样可以一层层点进去；
- **学段切换**：全部 / 初中 / 高中，两边章节不再混在一起；
- **默认展开有题目的章**：空章节不再刷一整面"还有 X 个没用到的"；章节里子标签全空时，连"还有 N 个没用到的"也不画。

## 二、颜色 = 这一组的视觉标识

Eagle 的"颜色 = 这一章的色"做法，全部接通：

- 目录每行左边 4px 色条；选中那一行底色跟着走；
- 顶部筛选条件条「标签：xxx ×」是同色软底；
- 详情里、卡片正文里的标签是同色描边 + 软底；
- 改一次颜色，四处一起变；
- 颜色先看标签自己设的；没设找最近的同名祖先；都没有按学段 / 类型从调色板取（初中一色、高中一色、解题方法一色、自定义一色）。

## 三、题目上加标签 — 不用弹窗

「＋ 添加标签」就在题目旁边，输入框出来：

- 边输边匹配；下面 8 条候选，按名字 / 别名 / 路径打分；
- 已经贴在本题上的不再列出来；
- 上下键、回车、点选都能直接贴上；
- **回车就能建一个新标签**：目录里没有这个名字，回车建出来并贴上；建在当前选中章节下，学段跟着章节走；没选章按顶级建；同名标签已经贴在这道题上时，提示"已经贴在这道题上了"，不会再建一个；
- 父子两颗粒粒同贴时父收起，子标签顶位。

## 四、按 Ctrl+Z 撤销最近一次标签改动

跟点详情里"撤销"按钮同一条命令；文字输入框里仍然是浏览器原生的"撤销改字"，不抢它；帮助里挂着这条。

## 六、标签可以拖：拖一颗到另一颗上 = 把它挂为子标签

- 详情里每颗标签按住拖到另一颗上松手，被拖的那颗成为后者的子标签；父子都贴在本道题上时，父收起、子顶位；
- 不同类型（知识点 vs 解题方法）拖不动；拖成自己的后代会拦住提示；
- 走的是目录的 `add_parent` 操作，保留其它上级，可在操作记录里撤销；
- 卡片正文里的标签行也按同样规则收起。

## 七、标签地图默认收起空标签

工具栏多了一颗"只看用到的"（默认开），整个子树没题目的标签全部收起来；状态栏报告"收起 N 个还没题目的标签"；要看完整结构就关掉它。

## 八、筛选条上的小毛病

- 「全部 807 / **有答案 0** / 无答案 807」「全部题型 807 / … / **判断题 0**」中间夹一个 0，0 项按钮变成淡灰，不再和正文平级；
- 「有答案」「无答案」加了悬停说明：「有答案 = 题库里保存了答案解析；上传和切题不会自动加答案」。

## 九、顺带修的真 bug

- **"目录"开关点不动**：上次关掉以后，localStorage 记了 "0"，下次进来不自动开 → 监听没绑上 → 再点没反应。把监听挪到初始化末尾，不管状态如何都先绑好；
- 修复了一直没察觉的开发态好用、用户态坏的开发偏好。
