## 题有据 2.3.19 更新说明

**本版为未签名修复版，Windows 仍可能显示 SmartScreen 提示。**

- 修复题库工作台把 Markdown 表格逐行显示成竖线文字的问题，题卡现在使用公共表格排版；兼容表格各行之间有空行的识读结果。
- 保留表格中的空白格、数字、公式和题目原文，编辑定位与 Word 导出沿用同一解析结果。相邻独立表格和普通绝对值表达式不会因空行兼容而被强行拼接。
- 缩小图片选择题的选项卡和缩略图，按题卡宽度排列为四列、两列或一列；保持图片比例与完整内容，点击或用键盘激活缩略图可查看原图。
- 合并快速审题改进：弹窗加宽至 1200px，鼠标移开后隐藏外框与辅助区域，只保留清晰题干；移回后恢复，触屏保持完整界面。
