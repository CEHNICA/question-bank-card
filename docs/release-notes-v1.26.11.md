# 1.26.11：按调研结论补的两件事

上一轮派了四个子代理去查别的题库和 AI 客户端怎么摆 API 配置（Cherry Studio、Chatbox、
LobeHub、NextChat、kaogong-shuati 考公题库、jikao-project 成考助手，以及你自己那个高中
数学题库）。查完有两件事值得直接抄，这一版就做了。

## 一、每家服务商自己身上写明"存没存密钥"

**之前**：勾选行上只有厂家的名字，想知道哪家配过密钥，得一家一家点开看。

**现在**：名字后面就写着状态。

```
可复用看图读题密钥   ○ 魔搭 未存密钥   ● MiniMax 已存 1 把   ○ 硅基流动 未存密钥
独立答题服务         ○ DeepSeek 未存密钥   ○ 豆包 API 未存密钥   ○ 其他兼容服务 未存密钥
```

抄的是 kaogong-shuati（每个智能体卡片写明"已启用/未启用"）和 Chatbox（服务商列表尾部
一个绿点）。老师一眼就知道该配哪家、哪家的额度还没用。

## 二、测试连接失败时给一张能照着做的排查清单

**之前**：失败就把服务端那句话原样丢出来（比如"API 未通过所选合成数学/图像与思考响应
测试"），看不出下一步该干什么。

**现在**：那句话照旧给，下面再跟一段可以自己动手查的清单：

> 可以照这几条自己查一遍：① 密钥是不是复制完整、有没有多余空格；② 账户余额是不是够；
> ③ 服务商有没有选错；④ 密钥是不是过期了。

抄的是 Chatbox 的失败文案（"请确保 Key 复制完整、没有多余空格、余额充足、匹配服务商、
Key 没有过期"）。原来的报错不删 —— 清单是加在后面的。

## 三、有一件事调研提了，但我判断不做

调研里最接近题有据的项目（kaogong-shuati）做到**每个任务一张卡、各配各的密钥**：它的
识图转写员用智谱、行测解析用另一家。

看着像是应该照做，其实不用 —— 它分家是因为**识图必须多模态、文字任务用纯文本模型**
（读题费和数学题对不上）。题有据早就是分开的：「看图读题」一家（要多模态）、
「生成标签和答案」一家（纯文本更划算），**已经是这个调研结论本身了**。

再把"生成标签"和"生成参考答案"拆成两家，没有实际好处：两件事都是纯文本，同一家更省事，
多一个下拉框只会让老师多点一次。所以这一版**不拆**。
