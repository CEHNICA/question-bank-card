# 1.26.59 —— 回收站下架修全、入库不自动归档、右键菜单收短

## 这一版忙了什么

删资料进回收站时，题库里的入库题会按整份资料一起下架，不再只撤前端碰巧加载到的那几道。录入页入库完成后不再自动归档，归档改由人自己点。题库工作台的右键菜单把排序、复制、更多等长列表收进悬停飞出，标签分区文案改成「子标签」。

---

## 主要改动

### 1. 资料进回收站：按 document_id 整份下架
- `withdraw-batch` 支持 `document_id`：扫该资料下全部 `published`，不只依赖前端当前页的 id 列表。
- 成功响应固定带 `ok:true`，避免 Eagle 把 HTTP 200 误报成「下架试题失败」。
- 恢复资料时，伴随下架的入库题一并恢复。

### 2. 入库完成不再自动归档
- 录入列表继续展示已全部处理完的卷；需要收起时再点「归档任务」。
- 完成提示改为引导手动归档，不再静默把卷从列表拿走。

### 3. 题库左栏：标签放到「最近浏览」下面
- 文件夹树根顺序调整，标签管理分区紧跟最近浏览。

### 4. 右键菜单统一悬停飞出
- 排序方式、题目「复制 / 更多」、标签「筛选 / 管理」、试卷与文件夹的次要动作，悬停再展开，主菜单不再整段撑开。
- 标签分区展开/收起文案使用「子标签」，不再误写成「子文件夹」。

### 5. 导出与其它修复（随本版一并发布）
- 导出 Word / 预览对齐相关修正（字号字重、答案块节奏、表格列宽、配图尺寸等）随此前未推送的提交一并进入本版。
- OneNote 联动与识读重试进度等小修一并带上。
