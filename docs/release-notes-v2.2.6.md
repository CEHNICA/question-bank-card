## 题有据 2.2.6 更新说明

### 更新亮点

1. **每道题目都有「身份证 / 定位码」**：
   - 每张入库题卡与右侧栏均展示清晰短定位码（如 `Q-950683dc`）及「📋 复制给 AI」按钮，可一键复制完整题目位置并直接粘贴进工作台搜索框定位；
   - 新增 `tiyouju locate <定位码或粘贴位置>` 命令（并更新 `tiyouju skill` 指南），发给任意 AI Agent 即可直接秒查原题干、选项、标签与本机原卷图片。

2. **去网页端「助手模式」直连模型 API**：
   - 设置页与工作台不再保留容易误导的「转交助手待办（不调 API）」单选开关，界面点击生成一律直接调用已配置的模型 API；外部 AI Agent 则直接通过 `tiyouju` CLI 协作。

3. **无标签题目后台并行慢跑 + 单题插队排到最前 + 排队交互修复**：
   - 新增「无标签题目后台自动慢跑（`后台补标`）」开关与独立 **3 线程并行后台队列**，在后台温和补全尚无标签题目的候选建议；
   - 在工作台点单题「生成标签 / 优先插队」会自动排到队列最前面（已有后台队列任务也会原地提权插队）；
   - 修复原排队卡片「提示点重新生成但按钮却禁用成 `⏳ 排队中…`」的矛盾，改用紧凑进度条并提供随时可点的「⚡ 优先插队 / ↻ 取消并重试 / × 取消」。
